# dsh-law · 深法工作台

**DeepSeek Harness 的本地法律工作台插件**。首页参考全国法院“一张网”的工作台逻辑，把待办提醒、月历排期、案件概览和最近动态放在同一屏；案件对话统一交给 DSH 原生会话，并自动使用用户预设的「法律模式」。零 npm 依赖，数据完全本机。

GitHub 项目名为 `dsh-law`；为兼容现有安装与数据目录，DSH 插件 id 和 npm 包名继续使用 `dsh-lawbench`。

```
办案首页 → DSH 法律对话 → 案件看板 → 日程期限
```

## 安装（DSH 插件）

```bash
# GitHub（推荐）
dsh plugin --profile web add github:wesky820/dsh-law
# 或 npm 发布后
dsh plugin --profile web add dsh-lawbench
# 本地开发
dsh plugin --profile web add link:/path/to/dsh-lawbench
```

然后重启 `dsh web`（插件在宿主启动时加载）。GUI 侧边栏会出现「⚖ 深法工作台」入口：点击在会话区打开工作台，工具栏可「在标签页打开」。

**模型和 API**：工作台不再维护第二套 API Key 或模型配置。每个案件会绑定一个以案件文件夹为工作目录的 DSH 原生会话，并自动使用 DSH 的「法律模式」（preset id: `law`）。模型列表、模型切换、技能、命令、工具和权限策略全部来自 DSH；要新增服务商或模型，请在 DSH 设置中配置。

旧案件如果绑定的是空白标准模式会话，工作台会直接切换为法律模式；如果旧会话已经有对话，则保留原会话历史，自动新建并改绑一个法律模式会话。

## 独立运行（仅案件管理，可选）

```bash
npm start          # 或双击 start.command
# → http://127.0.0.1:8898 （数据目录：<项目>/data）
```

独立地址可查看和管理案件、看板与日程；DSH 对话、模型、技能和命令必须从 DSH 侧边栏打开插件后使用。

## 功能

- **办案首页与工作日历**：在办案件、临期/逾期、门禁审批、AI 流程提醒、最近动态同屏呈现；日历支持年/月/日跳转、点击日期新增、按案件登记日程或法定期限并直接删除
- **咨询与收案**：咨询可以先作为独立工作空间接待，待信息完整后再决定是否转入正式案件流程
- **可控 AI 模式**：每案可选全流程辅助、咨询接待、按需协作，或完全关闭自动辅助；自动提取与首页提醒也可分别关闭
- **DSH 技能与命令**：每案独立绑定 DSH 会话；“技能与命令”面板支持分类、搜索和点击插入，输入 `/` 会出现即时建议，执行结果直接回显在工作台
- **DSH 单一对话与模型切换**：只使用本案 DSH 法律模式会话，模型切换器动态读取 DSH 原生模型目录，不存在插件内第二套模型
- **可调工作区**：主导航、案件栏与案件雷达均可拖动边缘改变宽度，可分别收起；双击边缘恢复默认，也提供紧凑、标准与专注对话预设，选择在本机浏览器中持久保存
- **四套法律主题**：人民法院“一张网”、逆转裁判、风骚律师与 Suits 四套完整皮肤；逆转裁判主题可随时触发经典“异议！”场景
- **DSH Remote**：工作台复用当前 DSH 已安装的 Remote 插件，显示入口与设备状态，生成一次性配对链接，并可直接打开 `/m` 手机端；当前 DSH 版本禁止监听 `0.0.0.0`，请在 DSH 设置 → 插件 → Remote 开启官方“自动公网隧道”（推荐），或填写可信的 `publicBaseUrl`
- **本地案件目录**：创建案件时可自动生成 `收案与委托 / 客户材料 / 证据 / 法律检索 / 文书草稿 / 定稿与提交 / 庭审 / 结案归档` 八级工作目录；删除案件记录不会删除文件夹
- **对话主界面**：每案独立 DSH 原生对话，左侧案件/咨询列表与右侧案件雷达实时更新
- **实时看板**：六列流水线（待接案 → 调查取证 → 策略制定 → 文书起草 → 待定稿送审 → 已结案），拖拽换列，SSE 实时推送，多窗口同步
- **AI 材料上板**：AI 从对话自动登记证据（三态流转）、主张（可关联证据与证明目的）、期限（自动算届满日，逾期/临期徽章）、日程、检索记录、会话纪要、文书（版本链）；每次登记实时出现在看板卡片与材料流
- **案件档案工作区**：宽屏案件详情，集中编辑名称、案号、法院、承办法官、摘要和阶段；概览/证据/主张/期限日程/文书/检索/纪要/门禁八个分区，并展示进度、AI 策略、当事人、文件目录与阶段时间线
- **门禁治理**：接案/策略/定稿/结案由 AI 提交申请，律师人工审批
- 逾期期限红标、7 日内临期黄标、待批门禁紫标，顶栏实时统计

## 架构

```
lib/index.js      宿主半（cordis 插件）：进程内拉起工作台 + /api/dsh-lawbench 路由 + 系统提示播报
lib/client.js     浏览器半：侧边栏入口（自愈 MutationObserver）+ 会话区 iframe（同源镜像）
cordis.patch.yml  profile bundle 补丁（插入插件行）
server/           工作台服务（零依赖：原生 http + SSE；案件、看板、日程与材料数据）
public/           四视图前端（原生 JS，无构建步骤；相对路径，可挂任意前缀）
```

路由：`/api/dsh-lawbench/info`（状态）、`/api/dsh-lawbench/workbench/`（同源镜像代理，SSE 透传）。同源 iframe 还通过 DSH 官方 `session.*`、`skill.list` 与 `commands/*` 接口连接原生会话；全部带 loopback 护栏。

数据目录：插件模式 `~/.dsh/dsh-lawbench/`（案件与本地材料）；独立模式 `<项目>/data/`。DSH 对话由 DSH 自身持久化。工作台与 DSH 都保持监听 `127.0.0.1`；只有用户明确启用 DSH Remote 的官方自动隧道或自备隧道后，手机端才可通过一次性令牌配对。

## 常见问题

- **侧边栏没有入口**：重启 `dsh web` 后生效（插件在宿主启动时加载）
- **模型不可用或鉴权失败**：在 DSH 设置中检查对应服务商、模型和凭据；工作台不单独保存密钥
- **看不到技能或命令**：确认是从 DSH 侧边栏打开，而不是直接访问 8898 独立地址；首次进入某案时会自动创建并绑定 DSH 会话
- **Remote 显示“需要设置安全的远程入口”**：当前 DSH 版本明确禁止 `--host 0.0.0.0`；请在 DSH 设置的 Remote 插件项开启“自动公网隧道”，或配置自己的 `publicBaseUrl`，用完后在 Remote 面板停止配对
- **端口冲突**：自动顺延 8898→8908；插件行可配置 `port`
- **与 DSH 法律模式的关系**：办案业务数据仍由本插件保存；每个案件会话自动使用 `law` preset，并可调用其中安装的法律工具和技能
