# DSH Desktop

[![License](https://img.shields.io/github/license/marcon0203/dsh-desktop)](LICENSE)
[![Release](https://img.shields.io/github/v/release/marcon0203/dsh-desktop)](https://github.com/marcon0203/dsh-desktop/releases)
[![Build](https://github.com/marcon0203/dsh-desktop/actions/workflows/build.yml/badge.svg)](https://github.com/marcon0203/dsh-desktop/actions)

一个为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 打造的桌面客户端：
交互完全沿用官方 Web 版（该有的功能一个不少），外观则是我们专门定制的一套界面，
有浅色和暗色两套主题，玻璃质感，支持明暗自动切换。

## 使用

1. 下载并启动客户端
2. 它会自动找到（或拉起）本机的 DeepSeek Harness 服务，然后进入主界面
3. 如果缺少运行组件，启动页会提供一键安装

## 说明

- 交互与官方 Web 版一致，数据、会话、插件生态完全通用
- 界面为定制设计（玻璃质感、大圆角、紫色调，明暗双主题）
- 开源项目，欢迎反馈与贡献
