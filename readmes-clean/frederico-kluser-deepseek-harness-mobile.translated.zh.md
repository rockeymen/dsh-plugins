# dsh-守卫-信使

**在手机上使用您自己的 DeepSeek Harness - 整个 Web UI，进行实际编码 - 无需将绑定扩展到环回之外：隧道在 `127.0.0.1` 结束（本地访问直接打开），只有那些拥有 `?key=` 链接（机器人发送的）密钥的人才能通过隧道进入 - 您可以通过 Telegram 打开和关闭访问。**

### 财产·如何
- **属性**：**绑定永远不会扩展** · **如何**：`assertSecureBind` 拒绝 `0.0.0.0`/`::` **加载**，有噪音故障 (`src/config/bind.ts`)
- **属性**：**本地访问直接打开** · **如何**：在`127.0.0.1`中DSH响应**无障碍**；保护适用于隧道表面，而不是环回（`src/tunnel/proxy.ts`）
- **属性**：**仅使用链接上的会话或密钥进入隧道** · **如何**：代理验证所有内容：链接上的会话（cookie）或 `?key=`；出此 → `401` 没有挑战（`src/http/gate.ts`，`src/session/link-token.ts`）
- **属性**：**源和主机优先** · **如何**：`trustedRemotes`（没有凭据的 403）和 `Host` 逐字节反对 DNS 重新绑定（`src/http/gate.ts:15`、`src/http/host-header.ts`）
- **属性**：**可重复使用的链接密钥，可通过旋转撤销** · **作为**：CSPRNG 256 位；仅保存为 SHA-256 摘要；可重用至 `/rotacionar`（生成新密钥、使会话无效**并关闭活动连接** - WebSocket 和传输中的流立即丢弃）或关闭隧道（`src/session/link-token.ts`、`src/tunnel/proxy.ts`）
- **属性**：**401 没有挑战** · **如何**：纯文本，**无登录挑战**（浏览器弹出窗口已删除）- 从不在提示/表单中要求输入密码（`src/http/responses.ts`、`denyUnauthorized`）
- **属性**：**暴力破解有上限** · **如何**：第5次失败开始延迟； 100次累计失败掉落暴露（严格模式），只有环回通过且复位不绕过（`src/ratelimit/**`）
- **属性**：**恒定时间密钥验证** · **如何**：与`timingSafeEqual`相比摘要；令牌以 JSON/inspect 编写（`src/session/link-token.ts`、`test/security/timing-constante.test.ts`）
- **属性**：**`danger-full-access` 被否决** · **如何**：禁止升高被拒绝作为纵深防御（`src/permissions/deny.ts`）
- **所有权**：**只有配对的所有者命令机器人** · **如何**：两轴白名单 (`userKey`/`chatKey`)，默认拒绝 (`worker/surface/auth.ts`)
- **属性**：**不保证什么** · **如何**：TLS 在 Cloudflare 边缘结束（明文通过那里）；隧道 URL 不是秘密；拥有该链接的人可以访问它，直到它旋转； `?key=` 进行查询（对中介机构可见）——由所有者承担的交易； *提示注入*仍然被接受 - [`docs/THREAT-MODEL.md`](docs/THREAT-MODEL.md) §4 和 §5.1 中的设计决策
## 核心张力，由我们在他们为我们说之前先说的

该项目旨在**锁定** DSH 环回。该插件还会通过互联网暴露您的身份。这似乎是一个矛盾——诚实的表述是这样的：

> `127.0.0.1` 中的绑定**继续**，而 DSH 中的绑定**直接打开**（无需登录）。变化在于，现在有一个受监督的子进程 (`cloudflared`)，它将流量从 Cloudflare 边缘传输到**在边缘进行身份验证的专用代理**（会话或 `?key=`）。它与 `--host 0.0.0.0` 不同：本地套接字永远不会扩展，暴露是**选择加入**，短暂且可在一个命令中撤销 - 并且正是这个代理保护 `/api`、SPA 回退和 WebSocket handshake，而不是环回。
>
> **没有**改变的是：逻辑攻击面扩大。以前，攻击者需要访问机器；现在通过隧道，您需要**链接中的密钥**（或被盗的会话）。我们将“无法访问”替换为“可访问并在边缘进行身份验证”——无需登录，无需输入密码。使用关闭按钮（以及使用 `/rotacionar` 的钥匙）可随时逆转此更改。

任何不接受这种权衡的人都应该使用 Tailscale 或 SSH——我们在 [`docs/TUNNEL.md`](docs/TUNNEL.md) 和下面的“何时不使用”部分中更冷静地说。

## 你做什么（以及为什么）

1. **保护隧道，而不是环回。 **DSH在`127.0.0.1`中**直接**打开（无需登录）；暴露它的人是一个**专用代理**，它对来自互联网的所有内容进行身份验证 - `/api`、SPA 后备和 WebSocket handshake。拒绝加载时环回之外的绑定地址并拒绝禁止的权限 (`danger-full-access`)。解决了上游讨论的表面问题[#853](https://github.com/deepseek-ai/deepseek-harness/discussions/853)。
2. **永远不要向任何人索要密码。** 通过隧道访问是通过**会话**或**链接中的密钥** `?key=`（CSPRNG，256 位，磁盘摘要）。该密钥**可重复使用**，直到 `/rotacionar`（生成新密钥，使会话无效**并主动关闭已打开的连接** - 拥有旧链接的人立即删除它，包括 WebSockets）或关闭隧道。 401 是**无登录挑战** - 没有提示或登录表单。
3. **使用临时隧道**通过手机进行访问，TTL会自行关闭，并且*故障关闭探针*可防止“裸”隧道（后面没有经过身份验证的代理）。
4. **通过 Telegram 或面板打开/关闭** — 手中的杀戮按钮。

### 命令·它的作用
- **命令**：`/ligar` · **它的作用**：进入隧道，当它准备就绪时，**自动**发送带有密钥 `?key=` 的链接
- **命令**：`/desligar` · **它的作用**：破坏隧道（并撤销密钥）
- **命令**：`/acessar` · **它的作用**：（重新）发送带有密钥的链接
- **命令**：`/rotacionar` · **它的作用**：生成**新密钥**，使会话无效**并关闭活动连接**（WebSocket/流）-立即撤销旧访问
- **命令**：`/status` · `/emergencia` · **它的作用**：状态、终止开关

`/ligar`中发送的链接是
`https://<url-pública>/?key=<token>`：**链接中的密钥**验证隧道，它是
**可重复使用**直到它旋转（或折叠隧道），并且在有效时进行交换
对于一个**会话**，浏览器将重定向到干净的 URL（不含 `?key=`）。
**永远不会要求您输入密码** — 通过会话或通过密钥中的密钥进行访问
链接，本地访问直接打开。

> **因为密钥可能会出现在聊天中（并且是预期的）：** `?key=` 是该机制
> 身份验证，机器人是交付渠道。它是**链接密钥**，而不是
> “永久密码” — 无需输入密码即可访问。

每个承诺都指向实现它的代码行：请参阅 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
