# DSH Subscription Usage

DeepSeek Harness Web 插件：在模型选择器左侧显示`openai-codex` `opencode-go`订阅剩余用量。

## 安装

```bash
npx @deepseek-ai/dsh plugin --profile web add github:sd1g1/dsh-subscription-usage
```

## 凭据

### Provider · 默认 DSH credential ref
- **Provider**: OpenAI Codex · **默认 DSH credential ref**: `OPENAI_CODEX_ACCESS_TOKEN`
- **Provider**: OpenCode Zen Go · **默认 DSH credential ref**: `OPENCODE_API_KEY`
