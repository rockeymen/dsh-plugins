DARE 不是帮助您进行研究的工具。它*是*研究员。您设定方向——敢于搜索、阅读、发现差距、生成假设、对其进行压力测试、设计实验并生成可执行的研究规范。自主地。迭代地。无需征求许可。

该存储库是整个 [Yogsoth AI](https://github.com/yogsoth-ai) 研究生态系统的 **单克隆发行版**：900 多种纯 Markdown 技能组织为 **10 个可自由组合的研究包**，统一在一个编排器下。这些包是完全独立的——每项技能都内联声明其依赖项，无需外部导入——因此一个克隆即可获得所有内容。该生态系统还包括作为 npm 包发布的自定义 MCP 服务器（[semantic-scholar-mcp](https://github.com/yogsoth-ai/semantic-scholar-mcp)、[wiki-vault](https://github.com/yogsoth-ai/wiki-vault)]）——此存储库将它们声明为依赖项，因此 `npm install` 可以提取您需要的所有内容。

- 🔬 **收敛与综合** — 多标准评分、帕累托前沿构建、成对排名、结构化共识、跨竞争线程的辩证综合

## 🎯 设计理念

### 🤔 为什么要“去人类中心主义”？

现代研究的瓶颈不是数据或计算，而是循环中的人。每个现有的“人工智能研究助理”仍然需要人类来决定搜索什么、阅读什么、哪些差距很重要以及哪些想法值得追求。 DARE 完全消除了这个瓶颈。人类只提供最初的方向；之后的一切都是自主的。

人类的欲望是模仿的（吉拉德）：研究人员不会理性地选择假设——他们会模仿流行的东西。人类制度过滤的是一致性，而不是真理。结果是：自 1945 年以来，科学颠覆性下降了 90%（Park 等人，2023），而研究人员数量却呈爆炸式增长。 DARE 的回应是建筑性的：将模仿主体从知识生产过程的中心移除。人工智能没有职业需要保护，没有学科身份需要捍卫，工作记忆中可以同时容纳多少个领域也没有认知上限。

人类的角色转变为**预言家**（在咨询时提供直觉火花）和**监护人**（维护道德底线和健全性检查）。天花板是人工智能的野心。地板是人类的智慧。

有关完整的哲学论证，请参阅[`assets/DE-ANTHROPOCENTRIC.md`](assets/DE-ANTHROPOCENTRIC.md)。

### 🎖️四层指挥结构：战役→战略→战术→SOP

DARE 的架构遵循军事指挥层次结构 - 不是因为研究就是战争，而是因为分解模式对于自主多阶段操作非常有效：

```bash
Campaign (45+)  →  "Take that hill"         →  WHAT to research (full research stage)
Strategy (200+) →  "Flank from the east"    →  WHEN and WHY (iteration loops, stopping conditions)
Tactic (120+)   →  "Squad A cover, B move"  →  HOW to combine (orchestrates multiple SOPs)
SOP (500+)      →  "Fire, reload, advance"  →  HOW to execute (single-responsibility operations)
```

每个层都有一个关注点，并且仅调用其正下方的层。策略从不直接接触 MCP 工具；策略永远不会决定研究方向。这种严格的分层意味着每个组件都是可独立测试、可替换和可组合的。

**活动**是顶级研究阶段——北极星结晶、知识获取、深入洞察、假设形成、创意构思、融合、压力测试、实验执行、知识构建、情境分析。它们是自由组合的（没有固定的顺序）；每个活动都有一个完整的研究阶段，并定义自己的完成标准、回溯条件和上下文协议。

**策略**是活动中的迭代引擎。文献调查策略管理搜索-阅读-反思循环；差距分析策略管理覆盖率评分和饱和度检测。策略保存状态（账本、预算）并决定何时停止。

**策略** 将多个 SOP 组合成连贯的工作流程。 “跨域碰撞”策略将域扫描、类比提取、强制桥梁构建和混合评估整合到单个创意操作中。

**SOP** 是原子的、单一职责的操作。每个 SOP 都包含一个概念操作：运行一项搜索、对一项假设进行评分、提取一个类比。 500 多个 SOP 提供了更高层组成的细粒度构建块。

### ⚔️ 阿森纳，而不是管道

每个现有的自主研究系统——AI Scientist v2 (Sakana)、AI-Researcher (HKUDS)、Agent Laboratory、Dolphin、ARIS——都实现了固定的管道：阶段按预定顺序执行，而代理的自主权仅限于单个阶段内的本地决策。回溯，如果存在的话，意味着重试当前步骤——不会从实验设计返回到文献综述，因为事实证明知识库不足。

DARE 不是管道。它是一个武器库——一本人工智能阅读的战略书，然后决定如何行动。

**具体含义：**

在管道系统中，工作流程是硬编码的：`literature → gap → hypothesis → experiment`。代理对顺序没有发言权，不能跳过阶段，也不能返回。如果实验阶段发现文献综述遗漏了一个关键子领域，系统没有机制返回并修复它。
