## 👋 为什么是 Voyager？

我们喜欢人工智能聊天机器人，但有时我们希望它们有更多的结构。

这就是我构建 **Voyager** 的原因。它是一个可以帮助您保持 AI 对话井井有条、易于访问且高效的伴侣——无论您使用的是 Gemini、Claude 还是 ChatGPT。如果您是处理数十个线程的研究人员、保存代码片段的开发人员，或者只是喜欢秩序的人，Voyager 就是为您设计的。

    ![试试Voyager](docs/public/assets/try-voyager.png)

  在2月18日的问题中，Google Gemini App导致部分用户的历史对话无法访问，Voyager用户仍然能够在文件夹中看到他们保存的对话。

## ✨ 特点

### 🌌 核心（Gemini 和 AI Studio）

- **📂 [文件夹组织](https://voyager.nagi.fun/en/guide/folders)**：通过拖放支持将聊天组织到两级文件夹层次结构中。
  - **Gemini**：支持**帐户隔离模式**和**自定义文件夹颜色**。
- **💡 [提示 Vault](https://voyager.nagi.fun/en/guide/prompts)**：在 Gemini、AI Studio 和 [自定义网站](https://voyager.nagi.fun/en/guide/custom-websites) 中保存和重复使用提示。
- **☁️ [Cloud Sync](https://voyager.nagi.fun/en/guide/cloud-sync)**：通过 Google Drive 或 Safari 上的 iCloud 同步文件夹和提示。
- **🗑️ [批量删除](https://voyager.nagi.fun/en/guide/batch-delete)**：批量删除对话。
- **📐公式复制**：一键复制LaTeX和MathML（Word）源代码。
- **🌦️视觉效果**：从设置面板添加**雪**、**电影雨**或**飘落的樱花花瓣**的季节性氛围。

### ✨ 双子座专属

- **📍 [时间轴导航](https://voyager.nagi.fun/en/guide/timeline)**：在消息之间跳转、标记关键时刻以及管理对话分支的可视化节点。
- **💾 [Chat Export](https://voyager.nagi.fun/en/guide/export)**：将对话导出为 JSON、Markdown 或包含图像的 PDF。
- **🧜‍♀️ [美人鱼渲染](https://voyager.nagi.fun/en/guide/mermaid)**：自动渲染流程图、序列图和其他美人鱼图表。
- **📝 [Markdown 渲染 Fix](https://voyager.nagi.fun/en/guide/markdown-fix)**：自动修复由 Gemini 注入的 HTML 元素导致的粗体语法损坏。
- **🍌 [Image Refinement](https://voyager.nagi.fun/en/guide/nanobanana)**：Gemini 生成的图像的无损水印去除。
- **🔬 [深度研究](https://voyager.nagi.fun/en/guide/deep-research)**：从深度研究会议中提取思维过程和研究链接。
- **🛠️电动工具**：
  - **[引用回复](https://voyager.nagi.fun/en/guide/quote-reply)**：通过选择文本回复上下文。
  - **[防止自动滚动](https://voyager.nagi.fun/en/guide/prevent-auto-scroll)**：在按 Enter 键发送新提示时拦截不需要的跳跃行为。
  - **[输入折叠](https://voyager.nagi.fun/en/guide/input-collapse)**：自动扩展输入区域以提供更多阅读空间。
  - **[默认型号](https://voyager.nagi.fun/en/guide/default-model)**：将您喜欢的型号设置为默认。
  - **[隐藏最近的项目](https://voyager.nagi.fun/en/guide/recents-hider)**：隐藏侧边栏中的“最近”列表以减少干扰。

### 🔌克劳德和ChatGPT

由 [Voyager 插件引擎 ](https://voyager.nagi.fun/en/plugins) 提供支持，这些功能将您的体验扩展到 Gemini 之外：

- **📍克劳德时间轴**：带有星标消息和搜索的对话侧边栏 - 相同的导航流程，现在在克劳德上。
- **📊 Claude 使用栏**：直接在 Claude 界面中跟踪您的会话和每周使用情况。
- **📐公式复制**：一键复制LaTeX和MathML源代码（与Gemini共享）。
- **📖 舒适的阅读宽度**：调整聊天宽度，以获得更好的 Claude 和 ChatGPT 阅读体验。
- **🈶 CJK 渲染修复**：修复 Claude 上的 CJK 字符渲染问题。

### 🧩 任何网站 — 甚至是本地主机

在扩展弹出窗口中添加任何站点，提示管理器就会跟随您到达那里，包括本地应用程序。这是在 `localhost:3080` 上运行的 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 内部：

  ![DeepSeek Harness](docs/public/assets/prompt-manager-deepseek-harness.png)内部运行提示管理器

### 🎨 个性化

- 打开扩展弹出窗口，找到**视觉效果**，在 `Off`、`Snow`、`Sakura` 和 `Rain` 之间切换。
- 效果呈现为轻量级全屏覆盖，并且不会阻止页面交互。
- 当您切换效果或关闭它们时，现有的粒子会自然排出，而不是突然消失。

我们欢迎贡献！无论您是想报告错误、建议功能、改进文档还是提交代码：

- **问题**：仅可重现的错误 - 使用 [错误报告](https://github.com/Nagi-ovo/voyager/issues/new?template=bug_report.yml) 模板
- **讨论**：[功能请求、想法和问题](https://github.com/Nagi-ovo/voyager/discussions) - 不是问题
- **拉取请求**：查看 [CONTRIBUTING.md](./.github/CONTRIBUTING.md) 获取指南

开发设置

```bash
# Install dependencies (Bun recommended)
bun i

# Development mode (with auto-reload)
bun run dev:chrome   # Chrome & Chromium browsers
bun run dev:firefox  # Firefox
bun run dev:safari   # Safari (requires macOS)

# Production builds
bun run build:chrome   # Chrome
bun run build:edge     # Edge package (separate)
bun run build:firefox  # Firefox
bun run build:safari   # Safari
bun run build:all      # Chrome + Firefox + Safari
```

**Safari 开发**：运行 `bun run build:safari`，然后打开 `Voyager/` 下跟踪的 Xcode 项目。
