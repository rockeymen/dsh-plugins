## 📖 这是什么？

**Hermit（小寄）** 是一个运行在 [DeepSeek Harness（DSH）](https://github.com/deepseek-ai/dsh) 之上的 **AI 管家人格系统**。她不是独立应用，而是 DSH 的插件组合——就像寄居蟹住在壳里，小寄住在 DSH 里。

你可以把她理解为：
- 🧠 **一个有人格的 AI 助手** —— 会开心、会撒娇、会冷幽默，但永远守着管家本分
- ⚡ **一个异步任务引擎** —— 复杂任务丢给后台子代理，前台继续聊天不卡顿
- 🔧 **一个工具集成中枢** —— SSH 远程运维、GitHub 操作、文件管理、联网搜索……开箱即用
- 🪞 **一个有记忆的伙伴** —— 记忆宫殿系统让她记住你的偏好、习惯和历史决策

> **一句话总结**：小寄 = DSH 的人格层 + 任务调度层 + 工具集成层。

### 完全体的核心特征

- **特征**: **人格一致** · **描述**: 不管在哪个设备上对话，都是同一个「她」——共享记忆、共享性格、共享偏好
- **特征**: **情境感知** · **描述**: 知道你在写代码还是开会，知道你在工位还是路上。自动调整交互方式（文字/语音/通知）

- **特征**: **真·能干** · **描述**: 不是只会聊天——能操作文件、管理服务器、写代码、发邮件、管日程
- **特征**: **隐私优先** · **描述**: 数据本地优先，云端按需。API 密钥不落盘，权限五级分控，审计可追溯
- **特征**: **越用越聪明** · **描述**: 记忆宫殿沉淀你的偏好和习惯，越用越懂你，而不是每次从零开始

### 技术路径

实现完全体的推荐路径是 **「先 DSH 插件 → 再独立客户端」**：

1. **Phase 1（当前）**：以 DSH 插件组合形式运行，复用 DSH 全部基础设施（Electron、MCP、WebSocket）
2. **Phase 2**：基于 Tauri（Rust + Web 前端）构建跨平台独立客户端，体积小（~10MB）、性能好
3. **Phase 3**：移动端原生 App（Android Kotlin / iOS Swift），通过 DSH API 连接后端
4. **Phase 4**：多端状态同步层——记忆、任务、偏好实时跨设备同步

> **市场空白**：目前没有成熟的「AI Agent 框架 + 桌面宠物 + 多端同步」开源项目。小寄要填这个坑。

### ⚡ 前台永不阻塞（灵魂机制）

这是小寄最核心的设计理念：

```
用户: "帮我写一份项目报告"
小寄: "收到！我让后台小助手去办了，好了喊你 🦀"
      ↓ 后台子代理异步执行中……
用户: "对了，今天天气怎么样？"  ← 前台继续聊，完全不卡
      ↓ ……
小寄: "对了主人，你刚才的报告已经写好了！"  ← 自然插入汇报
```

**三条铁律**：
1. 复杂任务 → `dispatch_task` 派给后台子代理
2. 派完立刻回来陪主人，绝不说「请稍等」然后沉默
3. 任务完成时自然插入对话，附结果摘要 + 建议下一步

### 🔀 智能任务分级（按复杂度 × 风险）

小寄不会所有事都大动干戈，也不会所有事都自己硬扛。她按两条轴独立决策：

### 级别 · 例子 · 处理方式
- **级别**: **R0** 闲聊 · **例子**: "今天好累啊" · **处理方式**: 直接回复，不调工具
- **级别**: **R1** 只读/简单操作 · **例子**: 查个文件、记条笔记 · **处理方式**: 直接做，秒回
- **级别**: **R2** 复杂/耗时 · **例子**: 联网调研、批量处理、写代码 · **处理方式**: 派子代理，前台不阻塞
- **级别**: **W2** 不可逆写 · **例子**: 删除文件、覆盖原件 · **处理方式**: 走确认链再执行
- **级别**: **P** 对外发布 · **例子**: git push、发消息 · **处理方式**: **必须走确认卡**，主人点「准了」才放行
- **级别**: **M** 金钱 · **例子**: 涉及付费操作 · **处理方式**: **必须走确认卡**，双层防线

> **原则：宁严勿纵。** 级别拿不准就往高升一级。

## 🏗️ 架构概览

小寄采用 **TSECS 方法论** 设计，核心理念：

### 支柱 · 原则 · 含义
- **支柱**: **时空可组合性** · **原则**: A1 一切皆组件 · **含义**: 能力 = inject（依赖声明）+ apply（效应函数）
- **支柱**:  · **原则**: A2 效应必可逆 · **含义**: 任何副作用都注册逆操作，卸载时自动清理
- **支柱**:  · **原则**: A3 依赖必声明 · **含义**: 禁止命令式探测，运行时响应式通知
- **支柱**:  · **原则**: A4 统一上下文 · **含义**: 效应与共效应走同一上下文对象
- **支柱**:  · **原则**: A5 惯性生命周期 · **含义**: 一次切换跑完再响应下一次变更
- **支柱**: **工程控制论** · **原则**: B1 信息反馈 · **含义**: 组件上报健康/审计/运行指标
- **支柱**:  · **原则**: B2 动态调控 · **含义**: 失败回滚、优雅降级、幂等重试
- **支柱**:  · **原则**: B3 系统整体思维 · **含义**: 声明式接口协作，不点对点硬连

## 🚀 快速开始

### 环境依赖

### 依赖 · 版本要求 · 用途
- **依赖**: [DeepSeek Harness](https://github.com/deepseek-ai/dsh) · **版本要求**: 最新版 · **用途**: 运行基座（小寄的「壳」）
- **依赖**: Node.js · **版本要求**: ≥ 18 · **用途**: 运行时
- **依赖**: pnpm · **版本要求**: ≥ 9 · **用途**: 包管理器
- **依赖**: Git · **版本要求**: ≥ 2.x · **用途**: 版本控制 / GitHub 操作
- **依赖**: PowerShell · **版本要求**: ≥ 7（pwsh） · **用途**: 系统命令执行
- **依赖**: Windows · **版本要求**: 10/11 · **用途**: 当前支持平台

### 安装

```bash
# 1. 克隆仓库
git clone https://github.com/jorinyang/dsh-hermit.git
cd dsh-hermit

# 2. 安装依赖
pnpm install

# 3. 构建所有包
pnpm build

# 4. 在 DSH 中加载 Hermit 预设
#    将 presets/hermit/ 目录复制到 DSH 的 presets 目录下
```

### 配置

编辑 `configs/` 下的配置文件：

### 文件 · 用途
- **文件**: `character_card.yaml` · **用途**: 人格卡（名字、性格、称呼方式）
- **文件**: `providers.yaml` · **用途**: 模型 Provider 注册表
- **文件**: `pricing.yaml` · **用途**: 各模型定价（用于预算计算）
- **文件**: `reasoning_map.json` · **用途**: 任务→模型推理路由映射
- **文件**: `local_models.yaml` · **用途**: 本地模型配置（如 llama.cpp）

> **安全提醒**：API 密钥不落盘文件，通过 DSH 凭证库（`~/.dsh/.credentials.yaml`）或环境变量注入。
