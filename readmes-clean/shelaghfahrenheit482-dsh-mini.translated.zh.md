# ⚡ dsh-mini - 适合所有人的微型人工智能代理

## 🔥 什么是 dsh-mini？

dsh-mini 是一款超小型便携式人工智能编码助手，可直接在您的计算机上运行。这就像拥有一个智能助手，可以理解您的命令并为您编写代码——所有这些都在一个小文件中。没有复杂的设置，没有繁重的安装。只需下载、点击即可。

该工具基于强大的 DeepSeek Harness 引擎构建，但压缩为 **7.6 MB** 的单个文件 - 比类似工具小约 50 倍。它在 Windows 上运行良好，甚至通过 Termux 与 Android 兼容。

## 🎯 这是给谁的？

- 您需要一个可以离线工作的人工智能助手（连接到模型后）。
- 您厌倦了安装会降低计算机速度的大型程序。
- 您想要一些便携式设备 - 将其放在 USB 记忆棒上并在任何地方使用。
- 您对人工智能驱动的编码感到好奇，但不知道从哪里开始。

## 📦 里面有什么？

- **便携式引擎** — DeepSeek Harness 的核心，压缩至最大。
- **Pi Shell** — 与 AI 对话的友好终端界面。
- **零运行时依赖性** — 无需额外的软件。它只是运行。
- **单个文件** — 一个文件可完成所有操作。没有文件夹，没有混乱。

## ✅ 为什么选择dsh-mini？

这就是人们喜欢这个小动力的原因：

- **难以置信的小** — 7.6 MB 与典型的 359 MB 相比。您的硬盘会感谢您的。
- **快速启动** — 立即打开，无需等待。
- **无需安装** — 直接从任何文件夹运行。
- **适用于任何地方** — Windows、Android (Termux) 和 Linux。
- **隐私友好** — 您可以控制数据的去向。
- **免费使用** — 没有许可问题。

## 🔌 连接到 AI 模型

dsh-mini 是引擎，但要获得 AI 答案，您需要将其连接到模型。方法如下：

1. **打开设置** — 在终端中输入 `settings`。
2. **选择您的模型** — 您可以使用 DeepSeek 或其他兼容的 LLM。
3. **输入您的 API 密钥** — 如果您有提供商提供的 API 密钥。
4. **保存并测试** — 输入一个简单的问题以查看其是否有效。

*注意：如果您只是输入 `help` 并在本地探索，则不需要连接。*

## 📱 在 Android 上使用 dsh-mini (Termux)

dsh-mini 对 Termux 友好，这意味着您可以在 Android 手机上运行它！这是简短的版本：

1. 从 F-Droid 安装 **Termux**。
2.打开Termux并运行：`pkg install wget`
3.下载文件：`wget [your download link]`
4.运行：`./dsh-mini`

就是这样。您的手机成为便携式人工智能编码站。
