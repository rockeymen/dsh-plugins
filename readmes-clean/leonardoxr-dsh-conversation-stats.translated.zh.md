#dsh-conversation-stats

一个 DeepSeek Harness 插件，无需修补 Harness 即可配置对话统计行。

它以较低的公共槽优先级隐藏具有相同 `stats` id 的已发货 `conversation.composer.dock` 条目，保留正常的布局和视觉效果，同时允许独立隐藏每个指标。

## 设置

打开 **设置 → 插件 → 对话统计**。更改实时生效。

- 整个统计行
- 转弯
- 步骤
- 法学硕士时间
- 工具调用时间
- 获得第一个令牌的平均时间 (TTFT)
- 解码吞吐量（令牌/秒）
- 缓存命中百分比
- 输入令牌
- 输出代币

默认情况下启用所有指标并保持标准顺序。该行遵循活动的 DSH 英语或中文区域设置。它在可用时使用持久的整个会话投影，并在其他情况下保留已发送的加载窗口回退。

## 发展

```sh
pnpm install
pnpm check
pnpm pack
```

通过 DSH 配置文件安装打包的 tarball，然后在方便时重新启动 Web，以便发现新的主机命名空间和客户端捆绑包。
