# dsh-minigames

DSH Web UI 右侧小游戏面板：等待模型回复或修 bug 时的摸鱼神器。

- **折叠态**：浏览器右缘一条小竖条（🎮），不占空间。
- **展开态**：点击后占据窗口**右半部分**（默认 50vw，可拖左缘调整 360px–80vw），
  面板内自由选择游戏。
- **游戏**（全部离线、零资源文件、Canvas 绘制）：
  1. 🦖 **恐龙跳一跳** —— Chrome 经典小恐龙（昼夜/雨天）；
  2. 🧱 **俄罗斯方块** —— 经典下落消除；
  3. 🛡️ **坦克大战（带 AI）** —— 2D 坦克对战，敌军追踪 + 视线开火，共 3 波；
  4. 💎 **消消乐** —— 点击消除四连通同色块，目标分过关、逐关递增；
  5. 🔢 **华容道** —— 16 格数字华容道（15-puzzle），滑动方块按序排列，用时越短分越高；
  6. 🐍 **贪吃蛇** —— 经典贪吃蛇，穿越边界会从对侧出现（环面地图）；
  7. 🔢 **2048** —— 方向键滑动合并数字，合成 2048 即达成；
  8. 💣 **扫雷** —— 左键翻开、右键标旗、双击数字自动展开周围；
  9. 🃏 **记忆翻牌** —— 翻开两张配对，步数越少分越高；
  10. ⚫ **五子棋 vs AI** —— 15×15，AI 会进攻也会堵你；
  11. 🦘 **跳一跳** —— 按住蓄力、松开起跳，落点越准加分越多；
  12. 🧱 **打砖块** —— 移动挡板反弹小球，清完进入下一关、球速递增；
  13. 🔨 **打地鼠** —— 30 秒限时点击打地鼠，命中 +1、打空 -1；
  14. ⚫ **黑白棋 vs AI** —— 8×8 奥赛罗，角最重要，无棋可下自动让位；
  15. 🐦 **Flappy** —— 点击/空格振翅穿过柱子缝隙，越远分越高；
  16. 🧩 **数独** —— 9×9 标准数独，D 键切换难度，填满无冲突即胜；
  17. 🟡 **吃豆人** —— 经典迷宫吃豆，力量豆可反吃幽灵；
  18. 🎯 **跟枪练习** —— FPS 跟枪：锁定鼠标转视角压住三维漂移靶子，左键射击有后坐力。
- **预留扩展接口**：游戏注册表（`registerGame`），新增游戏只需实现一个接口。
- **体验细节**：折叠面板/切换标签页时自动暂停游戏、恢复时继续；每局最高分存
  localStorage；键盘输入只在点击游戏区域后生效，不会劫持聊天输入框。
- **尺寸自适应**：游戏画布按面板**真实可用空间**自适应（工具条+画布+按键提示整体
  始终完整展示，不出现滚动条；浏览器缩放/面板拖宽缩窄都会自动重排），宽高上限
  960px。

## 游戏玩法与细节

### 🦖 恐龙跳一跳

- 空格 / ↑ / 点击跳跃，↓ 蹲下；速度会**随分数提升**（`320 + 分数×0.15`）直到
  760 px/s 上限，越跑越快。
- **分数 = 移动距离 ÷ 10**，持续增长（约 50–150 分/秒）。
- 障碍：单柱仙人掌 / 双柱仙人掌 / **三种鸟**——
  - 高空鸟：从站姿头顶飞过，惩罚乱跳；
  - 低空鸟：**蹲下可躲**，或**跳到最高点**越过；
  - 贴地鸟：紧贴地面，**只能跳跃**躲（蹲下无效）。
- **后期障碍更密**：生成间隔随分数缩短（1.1–2.4s → 0.5–1.2s）。
- **每 800 分切换昼夜**：白天（米色）↔ 黑夜（反白）。
- **雨天机制**：每 1000 分起有 300 分（1000–1300、2000–2300 …）——
  斜落雨点 + 迷雾遮挡视线，并**随机闪电全屏白闪**。
- 计分上报节流为每 10 分一次，避免面板频繁刷新。

### 🧱 俄罗斯方块

- ←→ 移动，↑/X 旋转（Z 逆时针），空格硬降，C 暂存，P 暂停。
- 标准 10×20 棋盘、7 种方块（T/S/Z/J/L 采用 3×3 方阵旋转，不截断）、
  幽灵落点、下一个/暂存预览、等级加速（每 10 行一级）。
- 画布随面板自适应缩放（devicePixelRatio 高清），高度不足时收缩保比例，顶部不会被截断。

### 🛡️ 坦克大战（带 AI）

- WASD/方向键移动（**自由转向**，车身可贴墙转弯），空格开火，P 暂停，R 重开。
- 碰撞体积略小于一格（32×32 → 26×26），能过略窄通道；撞墙自动回吸网格线，
  直行时吸附网格边界，不会卡半格。
- 场景叠加半透明网格线，车道走向一目了然。
- 敌军 AI：贪心追踪 + 视线直射，出生口 2 格宽不卡墙；共 3 波（每波 5 辆）。
- 爆炸特效、出生闪烁无敌、履带动画、波次/生命 HUD。

### 💎 消消乐

- **点击任意格子，消除与它上下左右四连通的同色块**（对角线不算）；
- 一次消得越多分越高（平方级：`得分 = 10 × 消除数²`）；
- 消除后上方宝石**自由落体**补位（带下落动画、消除闪光、得分飘字），本关内不补新宝石；
- 达到**目标分过关**，目标逐关 **+400**（800 → 1200 → 1600 → …）；
- 无 ≥2 的同色块且未达标 → 游戏结束（R 重开）；支持鼠标点击与方向键+空格。
- 支持鼠标点击/拖动与键盘（方向键 + 空格）。

### 🔢 华容道

- 16 格数字华容道（15-puzzle）：4×4 棋盘，15 个编号方块 + 1 个空位；
- 从已解状态做随机有效滑动来打乱，**保证每次都可解**；
- **点击**空位同行/同列的方块（支持一次推多个）；或**方向键**滑动（方块朝箭头方向滑入空位）；
- 方块滑动带**插值动画**，在正确位置的方块自动变绿；
- **按最短用时计分**（`max(0, 1000 − 用时×2)`）：用时越短分数越高；
- HUD 显示步数 + 计时；完成显示步数/用时，R 或点击重新打乱。

### 🐍 贪吃蛇

- 方向键 / WASD 移动，R 重开，P 暂停。
- 16×12 网格，吃食物变长、+1 分。
- **环面地图**：穿越任意边界会从**对侧镜像位置**继续出现，不会撞墙死亡；
  唯一死亡方式是撞到自己身体（即将移出的尾格不算）。
- 棋盘填满即胜利（`over` 同时置为胜态）。

### 🔢 2048

- 方向键 / WASD 滑动合并，R 重开，P 暂停；也支持点击方向按钮。
- 4×4 棋盘，相同数字相邻滑动时合并为两倍并加分（合并分累加进总分）；
- 每次有效移动后随机生成新块（90% 为 2、10% 为 4）；
- 合成 **2048 达成**（`won`），无任何可移动/合并方向时游戏结束；
- 计分：合并产生的数值累加（合成 2048 的合并即 +2048）。

### 💣 扫雷

- **左键**翻开、**右键**标旗/取消、**双击已翻开的数字**自动展开，R 重开，P 暂停。
- 9×9 棋盘、10 颗雷；**首次点击必定安全**（避开 3×3 安全区布雷）；
- 数字 0 自动**洪水展开**周围；全部安全格翻开即胜（`won`）；
- **双击展开（chord）**：当周围已标旗数 == 该数字时，自动翻开剩余未开启的
  位置——若旗子标错，翻到雷则游戏结束并亮出全部雷；
- **计时与最短用时**：首次点击开始计时（HUD 右上角实时显示），排雷完成
  停止；**按用时计分**（`max(0, 1000 − 用时×2)`）上报，面板保留最高分 =
  最短通关用时，越快分越高。

### 🃏 记忆翻牌

- 点击翻牌，R 重开，P 暂停。
- 4×4 共 8 对符号，两张成对即消除，全部消除即胜（`finished`）；
- 翻到不匹配自动翻回；**步数越少分越高**
  （`max(0, 500 − 步数×5)`）。

### ⚫ 五子棋 vs AI

- 点击落子（黑子先行），R 重新开始，P 暂停。
- 15×15 棋盘，**五子连珠（横/竖/斜）即胜**；棋盘满为平局；
- AI 策略：优先**自己连五** → 其次**堵你的连五** → 再按
  「进攻 ×1.1 + 防守」启发式打分选点（只考虑已有棋子附近）；
- AI 有约 0.5s 的思考停顿，模拟对弈节奏。

### 🦘 跳一跳

- **按住蓄力**（力度条上升）、**松开起跳**，R 重开，P 暂停。
- **高抛物线**：跳起高度显著，空中带地面阴影与方块前倾，跳跃感强。
- 蓄力决定跳距与滞空时间；落到**下一个平台**前进 +1 分，
  落点越靠近平台中心额外 +2/+1 分；
- 落回当前平台不扣分继续；**落空（掉下）游戏结束**（带下坠动画）；
- **间距与宽度混合分布**：间距近（55–105）约 40%、中（105–140）约 35%、
  远（140–160）约 25%；平台宽度**有的宽有的窄**——窄（42–52）约 30%、
  普通（56–64）约 40%、宽（72–88）约 30%，窄平台更难精准落中；
- **满蓄力可跨越最远平台**（跳距约 202），但满蓄力会**飞过**近/中平台，
  需要按实际间距与宽度调节蓄力，不能无脑满蓄力。

### 🧱 打砖块

- 鼠标 / ←→ 移动挡板，R 重开，P 暂停。
- 480×320 视口：5 行 × 8 列砖墙，小球碰砖即碎、+10×关数 分；
- 挡板反弹角度随**击点位置**变化（打两侧球更斜）；
- 清空一墙进入**下一关**：砖墙重建、球速提升（`250 + 关数×20`）；
- 3 条命，球落地扣除，扣完游戏结束。
- **颜色机制**：每行砖固定一种颜色（删砖不变色）；小球会变成所消除

### 🔨 打地鼠

- **30 秒限时**：点击冒头的地鼠，R 重开，P 暂停。
- **5×5 草地**（25 洞），**最多 5 只地鼠同时冒头**，每只 0.9–1.6s 后缩回；
- **命中 +1、打空 -1**（最低 0 分）；时间耗尽游戏结束。

### ⚫ 黑白棋 vs AI

- 点击落子（黑子先行），R 重开，P 暂停。
- 8×8 奥赛罗：落子**翻转被夹住的对方棋子**；无棋可下自动让位，
  双方都无棋可下时**子多者胜**；
- 合法位置有提示点；AI 启发式：**优先占角**、避让角邻位、偏爱边缘，
  也考虑当前翻转数与中心机动性。

### 🐦 Flappy

- **点击 / 空格 / ↑ / W** 振翅，R 重开，P 暂停。
- 重力下落、每穿过一对柱子 +1 分、球速随分数略增；
- 撞柱、触地或触顶即结束；小鸟带俯仰与振翅动画。

### 🧩 数独

- 点击选中格子，**1–9 填入 / 0 或退格清除**，方向键移动光标；
- **D 键切换难度**（简单 45 线索 / 普通 35 / 困难 30），R 开新题；
- 题面深色不可改，玩家填入蓝色、**冲突标红**；
- 填满且无冲突即胜；**按用时计分**（`max(0, 1000 − 用时×2)`），
  越快分越高，面板保留最短用时。
