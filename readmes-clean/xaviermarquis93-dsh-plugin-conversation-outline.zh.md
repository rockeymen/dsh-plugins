# @deepseek-ai/dsh-client-ui-conversation-outline

[English](README.md) | 中文

在 Web 会话文本区的左侧增加一个可折叠的「对话目录」栏。它按流式顺序索引当前会话中「我」的提问与智能体的回答；点击某条记录会把文本区滚动到对应消息并短暂高亮。标题右侧提供关键词搜索框，可对每条消息的完整文本做不区分大小写的过滤。目录栏在读者停在底部时自动跟随最新内容，可折叠为窄条，且没有当前会话时不渲染任何内容。

面向 agent 的部署指南见 [AGENTS.md](AGENTS.md)。

## Model Experience

无。目录栏仅渲染浏览器中已有的会话数据，没有任何内容会进入模型请求。

#### KV Cache 影响

无；本包既不组装也不发送 provider 请求。

## 已知限制与后续工作

- 跳转按聊天节点 key 定位，因此只能到达当前已加载的文本区窗口；尚未加载的历史页之外的消息需要先加载该页才能到达。
- 智能体条目只展示其文本块，工具调用与推理过程不会被摘要进目录。
