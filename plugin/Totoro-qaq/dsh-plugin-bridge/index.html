项目简介

在 Web preset 做到一半，想换 Code preset 继续？直接切换会让旧工具组的调用历史留在新组合里。Bridge 先生成一份有界、可编辑的五段交接，再建立干净目标会话；原会话始终不动。

卸载：dsh plugin --profile web remove dsh-plugin-bridge，然后重启 dsh web。 为什么是 Bridge 承诺 · 具体含义 承诺: 执行前预览 · 具体含义: /bridge 不创建目标、不改源会话；先检查或修改固定五段交接。 承诺: 迁状态，不迁工具痕迹 · 具体含义: 决策、路径、当前状态和下一步进入干净 preset；旧工具组的不兼容调用不会跟过去。 承诺: 失败时关闭迁移 · 具体含义: kickoff 前暂停目标；无法保证时清除/取消目标，不发送模型请求。

这是小样本、可复现的回归门禁，不是总体准确率保证。 Gate · 结果 Gate: 五段摘要事实 · 结果: 30/30 Gate: 目标复述 / 首次有效工作事实 · 结果: 60/60 · 60/60 Gate: 关键事实 / 旧值复活 · 结果: 90/90 · 0 Gate: 已有图片证据 / 未解析原图路径 · 结果: 5/5 · 5/5 Gate: Confirm / --continue 到首次有效工作的目标请求数 · 结果: 2 · 1 Gate: Confirm 相对 --continue 的 nominal 配对中位额外成本 · 结果: +8.1% Gate: 摘要 worker 在干净验收组件中的 nominal 占比 · 结果: 20.74%
