项目简介

DeepSeek Harness Web GUI 的语音输入有两种模式，每种模式都有自己的 提供商后备链。 听写 — 按下麦克风，说话，文本就会在您输入时出现在作曲器中 go：语音在静音时被切割成短语，每个短语都被转录在其对应的位置上 拥有。再按一次停止；发送留在您手中。 语音消息 — 按挥手按钮，录制，再按一次。成绩单 在短暂的取消窗口后插入并发送给代理。

之后重新启动 Web UI，然后硬刷新浏览器。 提供商 密钥 · 服务 · 默认模型 · 凭证 密钥：browser · 服务：浏览器自带的语音识别 · 默认模型： — · 凭证：无，不向主机上传任何内容 密钥：deepgram · 服务：Deepgram · 默认模型：nova-2 · 凭证：DEEPGRAMAPIKEY 密钥：groq · 服务：Groq · 默认型号：whisper-large-v3-turbo · 凭证：GROQAPIKEY 密钥：hf · 服务：HuggingFace 推理 · 默认模型：openai/whisper-large-v3 · 凭证：HFTOKEN 密钥：local-whisper · 服务：本地whisper.cpp服务器 · 默认模型：服务器启动时给出的模型 · 凭证：无，完全离线

密钥通过 DSH 凭证服务读取（设置 → 凭证，或 $DSHHOME/.credentials.yaml），回退到流程环境。一个 没有密钥的提供者会被跳过，但不是致命的。 现成的提供商

dsh plugin --profile web add github:GooDAnDReaDY/dsh-voice
