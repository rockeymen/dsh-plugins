项目简介

dsh-vision-bridge 通用视觉桥，适用于 DeepSeek Harness (dsh) — dsh-vision-router 的独立替代品。

当聊天模型没有视觉（例如 deepseek-v4-flash）并且消息包含图像时，图像永远不会到达纯文本模型。相反，插件选择 如何 来处理它 - 取决于配置的 模式： hybrid（默认）——使用视觉模型自动将图像块重写为文本描述；工具仍可用于明确的后续行动。与旧版 v0.1.x 行为相同。 llm — 仅通过视觉模型自动重写（纯文本模型永远不会看到原始图像）；工具仍然可调用。 tools — 自动重写已关闭。文本模型必须显式调用 describeimage（或其他工具），否则适配器在原始图像上失败。当您希望模型决定是否进行视觉调用时很有用。

结构 兼容性说明 默认行为与 v0.1.4 相同。 现有用户升级后不会看到任何变化，除非他们切换模式、添加频道或更改策略/升级。 该插件注册顶级设置部分 (Vision)、composer.action 插槽注入（尽力而为；优雅地回退到旧版 DSH）以及 HTTP 路由 /dsh-vision-bridge/config、/dsh-vision-bridge/channels、/dsh-vision-bridge/models、/dsh-vision-bridge/test。 没有新的对等依赖项。 通道驱动程序使用 Node 22 的本机 fetch 和 AbortController。
