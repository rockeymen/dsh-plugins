项目简介

DeepSeek Harness Web 界面的俄语本地化。 它有什么作用 为内核命名空间注册俄语词典（common、 conversation、settings、settings.models、workspace、subagent、 reference 等 - 30 个内核命名空间，722 个键，100% 释放表面的涂层 DSH 0.1.1-rc.2) 以及许多第三方 插件（dsh-market、better-sidebar、task-board、im-hub 等 - 9 个命名空间，962 个键)。 将“俄语”添加为母语列表中的第三个位置 （设置→常规→语言）。选择由标准机制保存 DSH 设置和体验浏览器。 将 与活跃俄语同步。

语言环境的注册表位于浏览器中：该插件将俄语词典报告给外国词典 通过 ctx.locale.register(ns, 'ru', dict) 的命名空间 - 可能存在冲突 仅当该对（命名空间，语言）已被占用，并且 ru 未被任何人占用时。

标准选择器 (Настройки → Общие → Язык) 的语言列表位于快照中 区域设置运行时；菜单是根据它构建的，setLocale() 通过以下方式验证选择 给他。在 ru 尚未出现在列表中的内核版本上（来自 DSH 0.1.1-rc.2 框），该插件使用“Russian”项目扩展快照 - 内核文件不是 已更正。如果内核自己学习了 ru，则不会发生扩展 一切正常。该选择通过其自己的设置记录在设置中 命名空间russian-lang（内核主机电路只知道zh/en而不知道 接受 ru）。
