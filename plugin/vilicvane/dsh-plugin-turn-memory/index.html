项目简介

当顶级（根或恢复的分叉）会话的回合完成时，该回合仅标记为待处理 - 否 摘要尚未运行。在下一轮，运行时上下文携带一个挂起的 通知和主代理本身 - 当前上下文，以及用户的新上下文 message in view — 组成上一回合的全回合检查点 遵循捆绑的 dsh-紧凑转弯技能，然后用 Compactturn（转弯，摘要）。替换覆盖转弯的跨度开始 就在它自己的启动用户消息之后 - 该消息逐字保留 表面，因此检查点永远不会重复它，并将消息引导到内部 Span 逐字保留在自己的 元素中。最新用户 消息总是逐字保留。一发叉子（与对话同款，分享它的温暖 请求前缀）只在主代理出现时写入摘要作为后备 在整个回合中留下未总结的回合。原始事件保留在 用于重放和调用的仅附加日志。

Expandturn 工具以两种模式调用回合的完整记录： 代理 - 模型提出问题并按回合回忆路线 年龄：最近的回合（在recallRecentWindowMs内结束，默认2小时）使用a 其上下文逐字重播已完成回合的分叉 — 目标 转弯的完整原始文本已经在该上下文中，并且叉子是 仅当提供商的磁盘缓存仍保留前缀单元时才便宜 当这些转弯运行时坚持；较旧的回合使用子代理，其中 便宜的模型读取回合的全文并回答目标 问题。 raw — 该回合的全文直接返回到对话中； 非常大的转弯被截断；当代理回答时的后备 需要全文。

Compactturn 工具可让模型在长时间转动过程中主动压缩： 它取代了当前回合的已完成部分（该回合之后的所有内容） 回合开始消息，直到当前步骤），带有一个检查点，保持 逐字启动消息和当前步骤。与可选的 转参数它压缩了完整的前一个转整体 - span 在该回合自己的起始用户消息之后立即开始，该消息保持不变 表面上逐字逐句；这是待处理通知要求拨打的电话。的 检查点文本由当前上下文本身组成 - 组成 规则存在于捆绑的 dsh-compact-turn 技能中，文本到达为 该工具的摘要参数 - 因此没有分叉或子代理来总结跨度。 对于当前转动模式，工具验证范围（工具对 平衡），独占运行，并折叠跨度本身：收缩检查 （检查点字符与折叠节点模型可见文本），检查点 追加和表面替换都在插件中运行，镜像 全轮路径——不涉及压缩后端。全回合模式 重用与后备叉相同的替换路径（转弯记忆标记 检查站）。会话压缩保留了自己的廉价模型摘要器；的 两者永远不会混合。
