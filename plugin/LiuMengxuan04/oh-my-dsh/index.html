项目简介

DeepSeek Harness 本身已经能够让 Goal 持续推进。Oh My DSH 补上了长任务更容易缺失的部分：可以跨重启保存的任务图、有界 worker、固定完成检查、恢复流程，以及不会完全交给模型临场发挥的最终汇报。 开发者预览

0.1.0-alpha.3 是面向 DSH 与插件系统开发者的预发布版本。DSH 本身仍在快速开发中，公开 API、插件组合、配置和持久化状态都可能在后续预发布版本中发生非兼容性修改。

如果需求只是“让模型继续下一轮”，原生 Goal 模式通常已经足够。任务还需要跨重启规划、依赖顺序、委派执行、验收证据和明确完成门槛时，才适合使用 Autopilot。

dsh plugin --profile web add github:LiuMengxuan04/oh-my-dsh
