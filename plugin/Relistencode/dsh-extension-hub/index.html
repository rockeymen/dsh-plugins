项目简介

一站式管理 DeepSeek Harness（DSH）的 Skills 与 MCP 服务器。

1. 优先走 npm registry（插件发布到 npm 时）：下载 tarball 到 profile 的 nodemodules，全程不依赖 pnpm（无需符号链接/权限），并注册 bundle 行。 2. 否则浅克隆仓库到 /.dsh/extension-hub/plugins/ ，并校验它带有可用的 package.json 入口。 3. 在 profile cordis.patch.yml 注册插件（托管 insert 块）并自检写入。

启用/禁用通过改写 SKILL.md frontmatter 的 disable-model-invocation / user-invocable 实现；删除即移除文件。 MCP 全局 → 在宿主补丁 /.dsh/profiles//cordis.patch.yml 的受管区域（# >>> dsh-extension-hub … # /.dsh/mcp-servers.yaml，并生成专用预设 /.dsh/.agent-presets/ -mcp/agent.cordis.yml（以 shipped standard 为基底）。在会话预设选择器里选该预设即可生效。 支持平台

安装命令

dsh plugin --profile web add github:Relistencode/dsh-extension-hub
