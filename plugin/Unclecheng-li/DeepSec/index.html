项目简介

1. 下载 Release 里的 deepsec-0.2.0.vsix 2. VS Code 扩展面板 → 右上角 ... → Install from VSIX → 选中该文件 3. 打开项目，AI 写代码时实时标红 2. 第一次扫描：2 秒看到漏洞

仓库里自带一个故意写满漏洞的示例文件 demo/unsafe-ai-sample.ts，用来演示。 用命令行

一个 critical（硬编码 OpenAI API Key）+ 一个 high（XSS，.innerHTML 直接渲染用户输入）——这正是 AI 最爱犯的两种错。 用 TUI（终端工作台）
