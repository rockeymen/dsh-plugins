项目简介

要求：节点^22.19.0（或>=24）带有npm、pnpm（官方dsh） 插件命令驱动它），并在 Linux x8664 上使用curl（cargo 在其他地方构建）。

已知差距：已发布的 dsh 0.1.0-rc.6 缺少 EMFILE/ENOSPC deepseek-harness 前叉携带的手表容量修复。的 deepseek-ai GitHub 存储库是一个仅发布的镜像（已禁用问题和 PR），因此 该修复程序作为分支 fix/emfile-watch-capacity 存在于我们的分支中；重新评估 在每个上游版本上。受影响的用户可以从分叉构建 dsh npm（请参阅 docs/harness-updates.md）。 使用

按键：Enter 发送 · /preset 选择预设（会话立即重新加载） · Ctrl+S 简历 · /model 选择提供商/型号 · Ctrl+Q 退出。

安装命令

dsh plugin --profile web add github:HQ1995/deepseek-code
