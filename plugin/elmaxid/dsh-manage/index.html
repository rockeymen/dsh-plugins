项目简介

三个步骤，每个步骤都是幂等的，并且只有在前一个步骤失败时才可以重新执行 - 无需从头开始重试所有内容。 check-update 和 status

check-update 检查 npm 注册表并显示是否有更新版本： 没有网络或者 npm 没有响应 → 报告它无法查询（脚本不会失败）。 status 包含可用更新的简短通知，如果您处于最新状态或没有网络，则不会发出噪音。 plugins-install：批准的插件堆栈

包含三个翻译补丁（参见 plugins/patches/）：两个插件 他们带来了中文的固定用户消息，没有英文的替代方案 (dsh-restart-recover, dsh-secret-guard) — 之前被翻译成英文 进入清单，与bug修复相同的pnpm patch机制 dsh-plugin-verify。

安装命令

dsh plugin --profile web add github:elmaxid/dsh-manage
