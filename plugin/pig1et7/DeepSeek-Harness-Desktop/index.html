项目简介

DeepSeek Harness（DSH）本身是命令行工具：dsh web 会在本机启动一个 Web 服务器（默认 http://127.0.0.1:3080），托管整个 GUI（前端页面 + 后端 API + Agent 会话）。平时你需要手动执行命令、再开浏览器访问。本应用是一个 Electron 壳，把整个过程自动化：

1. 查找 dsh CLI：按优先级查找（见下文「dsh 的查找顺序」），找不到时自动 回退 npx --yes @deepseek-ai/dsh 下载； 2. 端口探测：从 3080 起逐个检查，若已有 DSH 实例在运行则复用，否则在 空闲端口自行启动服务（node web --port ）； 3. 等待就绪：轮询页面，直到出现 DSH 的启动标记（DSHBOOT）； 4. 打开原生窗口：先显示加载页，就绪后加载真实 GUI； 5. 退出清理：关闭窗口即退出应用，并只停掉「自己启动」的服务，复用的服务 不会误杀。

提示： 首次 npx 下载 dsh 需要等待一会儿；之后 dsh 会缓存在 npx 缓存里，启动变快； 若新主机访问 npm 缓慢，先执行 npm config set registry https://registry.npmmirror.com； 想要桌面快捷方式：运行 scripts\创建桌面快捷方式.cmd。 方式 B：从 GitHub 克隆源码构建（推荐）

安装命令

dsh plugin --profile web add github:pig1et7/DeepSeek-Harness-Desktop
