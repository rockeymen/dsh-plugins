项目简介

要求：macOS / Linux / Windows 10+（自带 tar），DSH 0.1.1-rc.2 或兼容版本。

1. 按上面装好插件，重启 dsh web 2. 输入 /backup 3. 搞定 —— 备份出现在 /Desktop/dsh-backups/，文件名带时间戳，旁边一份 .sha256
