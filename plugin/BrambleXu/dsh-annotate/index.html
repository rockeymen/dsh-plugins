项目简介

为 DeepSeek Harness 提供浏览器视觉反馈。/annotate 会让配套的 Chrome 扩展进入选择模式；每个被选中的元素都会为 Agent 的下一轮对话提供选择器、DOM 信息、计算样式高亮、可访问性数据、评论，以及可选的视口截图。 为什么存在 💡

如需更严格的本地授权，可以将弹窗中显示的扩展 ID 复制到后续 Harness patch layer 的 allowedExtensionId 配置中。 使用 🚀

点击元素，输入评论，按需重复操作。点击提交会将所有已捕获的信息和当前可见标签页的截图发送给 Agent。按 Escape 取消。 配置 ⚙️

安装命令

dsh plugin --profile web add github:BrambleXu/dsh-annotate
