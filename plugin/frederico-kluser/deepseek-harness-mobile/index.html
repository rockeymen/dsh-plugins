项目简介

该项目旨在锁定 DSH 环回。该插件还会通过互联网暴露您的身份。这似乎是一个矛盾——诚实的表述是这样的： 127.0.0.1 中的绑定继续，而 DSH 中的绑定直接打开（无需登录）。变化在于，现在有一个受监督的子进程 (cloudflared)，它将流量从 Cloudflare 边缘传输到在边缘进行身份验证的专用代理（会话或 ?key=）。它与 --host 0.0.0.0 不同：本地套接字永远不会扩展，暴露是选择加入，短暂且可在一个命令中撤销 - 并且正是这个代理保护 /api、SPA 回退和 WebSocket handshake，而不是环回。 没有改变的是：逻辑攻击面扩大。以前，攻击者需要访问机器；现在通过隧道，您需要链接中的密钥（或被盗的会话）。我们将“无法访问”替换为“可访问并在边缘进行身份验证”——无需登录，无需输入密码。使用关闭按钮（以及使用 /rotacionar 的钥匙）可随时逆转此更改。

任何不接受这种权衡的人都应该使用 Tailscale 或 SSH——我们在 docs/TUNNEL.md 和下面的“何时不使用”部分中更冷静地说。 你做什么（以及为什么）

1. 保护隧道，而不是环回。 DSH在127.0.0.1中直接打开（无需登录）；暴露它的人是一个专用代理，它对来自互联网的所有内容进行身份验证 - /api、SPA 后备和 WebSocket handshake。拒绝加载时环回之外的绑定地址并拒绝禁止的权限 (danger-full-access)。解决了上游讨论的表面问题#853。 2. 永远不要向任何人索要密码。 通过隧道访问是通过会话或链接中的密钥 ?key=（CSPRNG，256 位，磁盘摘要）。该密钥可重复使用，直到 /rotacionar（生成新密钥，使会话无效并主动关闭已打开的连接 - 拥有旧链接的人立即删除它，包括 WebSockets）或关闭隧道。 401 是无登录挑战 - 没有提示或登录表单。 3. 使用临时隧道通过手机进行访问，TTL会自行关闭，并且故障关闭探针可防止“裸”隧道（后面没有经过身份验证的代理）。 4. 通过 Telegram 或面板打开/关闭 — 手中的杀戮按钮。 Telegram：UI 按钮和自动链接

安装命令

dsh plugin --profile web add github:frederico-kluser/deepseek-harness-mobile
