项目简介

DSH（DeepSeek Harness）省钱插件 —— 自定义"暂停 / 继续"时间窗口，到点自动暂停（不是停止）正在执行的长任务，窗口结束自动恢复。应对大模型 API 的峰谷分时计价（如 DeepSeek 高峰 9:00–12:00、14:00–18:00 北京时间，空闲时段半价），也适用于分时电价、带宽错峰等任何"这个时间段不想让机器干活"的场景。 状态：✅ 已实现，持续维护。 界面一览
