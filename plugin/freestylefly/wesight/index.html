项目简介

WeSight 把模型配置集中在一个设置页。某个引擎选择“跟随 WeSight 模型设置”时，WeSight 会把模型配置映射到该引擎。 添加多个供应商和多个模型。 使用官方 OpenAI、Anthropic Claude 和 Google Gemini 供应商。 为 DeepSeek、Qwen、Moonshot、Ollama、OpenRouter、GitHub Copilot、本地网关或私有 endpoint 添加 OpenAI-compatible 配置。 在 WeSight 托管模型配置和本机 CLI 配置之间切换。 在需要统一管理时导入或同步本机引擎配置。 下载

从 最新版本 下载匹配的 DMG：Apple Silicon 使用 WeSight. .mac.arm64.dmg，Intel 使用 WeSight. .mac.x64.dmg。发布流水线会完成签名、公证和 Staple。打开 DMG 后将 WeSight.app 拖入 Applications 文件夹。 Windows

开发服务器默认运行在 http://localhost:5175。 带 Agent runtime 启动

安装命令

dsh plugin --profile web add github:freestylefly/wesight
