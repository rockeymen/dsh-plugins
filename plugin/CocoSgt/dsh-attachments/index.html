CocoSgt/dsh-attachments · 技能

每个文件（包括图像）都会经过存储管道：文件被写入会话工作区并在每个会话中暂存，并且一张卡片（图标图块 + 文件名 + 大小 + ✕）出现在编辑器上方。

项目简介

npm 包名:dsh-attachments · GitHub 仓库: CocoSgt/dsh-attachments

1. 回形针按钮(输入框工具栏左端):文件选择器,多选,无 accept 过滤; 2. 全窗拖拽:拖文件进窗口出现遮罩提示,松手即带入; 3. 粘贴:文件粘贴直达同一分诊;粘贴含附件引用行(📎 … → .dsh/uploads/…, 如从历史消息复制)的文本时自动再物化成卡片。 附件卡片

GitHub 回退方式: 注意:自建 profile 的 /.dsh/profiles/ /package.json 里 dsh.profile.bundles 必须包含 @deepseek-ai/dsh-base 与 @deepseek-ai/dsh-web-app,否则启动会静默挂起。

安装命令

dsh plugin --profile web add github:CocoSgt/dsh-attachments
