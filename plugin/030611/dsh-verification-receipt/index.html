项目简介

English 回答一个范围更小、可以检查的问题：这一轮中，DSH 记录了哪些形似验证操作的执行信号？

Receipt 汇总已记录的工具计数与词法层面的形似验证信号；它不能证明测试确实运行，也不能证明代码正确。 由社区维护，并非 DeepSeek 官方项目。相关 trust-layer 插件：Telemetry Redactor、Evidence Audit 与 Context Provenance。

DSH Verification Receipt 是一个面向 DeepSeek Harness 的小型、被动式 Profile Bundle。每次耐久的 turn/end 到达后，它会向本地 JSONL 文件追加一条隐私最小化、启发式执行摘要。

安装命令

dsh plugin --profile web add github:030611/dsh-verification-receipt
