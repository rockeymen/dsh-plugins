项目简介

作为 DeepSeek Harness (dsh) 插件构建的交易研究工作台。无分叉，无补丁核心 — 只是您堆叠在库存 web 或 headless 配置文件上的捆绑包。 状态：早期脚手架。 dsh 本身处于开发者预览阶段，并且进展很快；预计双方都会发生重大变化。 工作台

在带有可选外壳框架的 dsh web 下，应用程序变为图表优先： 持久的实时图表栏位于左侧，对话位于右侧。

该列是您的：输入一个交易品种，选择一个时间范围，然后它会在 环回通道根本不经过模型。它还遵循 对话 - 当代理绘制某些内容时，该列会加载该内容 仪器实时而不是镜像代理的冻结快照。感人 图表——一个符号、一个时间框架——固定它，📌芯片这么说； 从那时起，代理商的图纸将作为药丸的展示报价送达 将图表从你身下取出。点击芯片开始关注 再次。

安装命令

dsh plugin --profile web add github:maddogfinance/dsh-trading
