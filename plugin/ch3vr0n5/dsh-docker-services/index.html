项目简介

然后替换示例值，创建专用控制器帐户并 挂钩，并按照部署说明。阅读 授予 Docker/socket 访问权限之前的威胁模型。 项目布局 packages/plugin：DSH插件；没有 Docker 或秘密文件系统访问权限。 packages/controller：特权白名单实施和适配器。 packages/shared：版本化协议和配置验证。 examples：主机单元、容器部署和通用配置。

该项目故意不提供通用部署脚本：deployment 语义是特定于工作负载的，必须由管理员拥有进行审查， 固定挂钩。请参阅 release 以进行工件分离。
