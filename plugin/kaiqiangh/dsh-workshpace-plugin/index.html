项目简介

DSH Workspace 将 Workspace 选项卡添加到本地 DeepSeek Harness Web UI。它允许您检查代理接触的内容、查看只读子代理跟踪条目、查看会话工件、预览有限内容、检查 Git 更改、管理受治理的本地工作区内存以及查看代理创建的内存建议 - 所有这些都无需离开对话。 它的用途是什么

在浏览器中打开【http://127.0.0.1:3080/ZXQ15QXZ。重建插件后重新启动 Web UI，以便加载最新的包。

对于源更改，请运行 npm run build，停止当前的 dsh web 进程，然后再次启动 dsh web。仅当插件注册或链接路径发生变化时才重新运行dsh plugin --profile web add ...；重建链接的插件只需要重新启动 Web。 使用工作区

安装命令

dsh plugin --profile web add github:kaiqiangh/dsh-workshpace-plugin
