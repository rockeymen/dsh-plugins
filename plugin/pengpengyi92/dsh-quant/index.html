项目简介

dsh的理念是一切都是插件； dsh-quant 将其带入量化 — 开源内部五团队范例（PDAT → PAAT → PCPT → PRT → PET） 作为五个可插拔模块： 开放的是范式：模块如何组成，合约如何定义 （空对齐/无前瞻/手工计算测试），如何验证结果 - 不是内部秘密 你填写：产品力=UI+策略+数据接口+DL/RL 模型+交易系统构建，全部自组装，全部插件化 无限自我进化：用你的模块填充框架→运行论文/实时 → 反馈生态系统 — 这就是 dsh-quant

插件征集提案：问题＃27（五个模块×许多插件） - PDAT插件，PET插件，任何你能想象到的东西🐋 🤖 AI-Native 是经过深思熟虑的（设计声明）

dsh-quant 的主要消费者是代理（模型），而不是人类 — 从第一天起就经过深思熟虑的选择： 工具模式被注入到系统提示符中 - 每个合约（args / 输出/对齐规则）是从模型的角度编写的 等长空对齐 — 输出匹配输入长度；引导窗口 位置是 null，因此模型按索引对齐并且从不填充 规范 JSON + 渲染分离 — 机器读取结构，人类读取散文 All isConcurrencySafe — 纯函数，无共享状态；代理商可以致电所有 59把刀具并联互不干扰 技能层 — skill/quant-research 让模型自行加载工作流程
