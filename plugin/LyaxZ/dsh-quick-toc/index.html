项目简介

重启 DSH（Windows 上双击 restart-dsh.bat）后打开 Web UI。大纲默认收起——点击对话区左侧边缘的小把手展开。 使用 点击大纲标题跳转到对话中对应位置 拖动顶部横条移动面板；点 ◀ / ▶ 按钮切换左右停靠 拖右边缘调宽度、下边缘调高度、右下角同时调 大纲滚动到顶部可加载更早的组 开发 lib/client.js —— 全部 UI 逻辑（浏览器端） lib/index.js —— 宿主端空入口 cordis.patch.yml —— loader patch（符合官方 bundle 规范） 改 client.js 后浏览器硬刷新即可生效；改 loader / patch 需重启 DSH

安装命令

dsh plugin --profile web add github:LyaxZ/dsh-quick-toc
