项目简介

DeepSeek Harness 的地图缩减子代理委员会：一项任务通过不同的视角分散给几个新孩子，验证者重新检查源头的每项发现，法定人数将他们的投票转化为裁决表。

然后启动线束并选择模式： Map-Reduce 模式 出现在 Composer 的模式菜单中，位于 Standard、PTC、 最小和创造者。选择它会将理事会组成标准代理 飞机；所有其他模式都保持原样。

具有 tool-council-host 行的 # == @starsinc1708/dsh-tool-council 层 表示组成的束。第一次dsh web启动后，发布的预设 位于磁盘上：

安装命令

dsh plugin --profile web add github:starsinc1708/dsh-tool-council
