项目简介

⚡ dsh-codex-sync OpenAI Codex 与 DSH 终极双向同步桥：项目对话双向互导续聊，Skills 实时挂载、MCP 自动双向镜像。 项目会话双向流转 · 技能实时挂载 · MCP 自动镜像 · 原生现代化交互

🎛️ 侧边栏原生同步设置 📍 顶部工作区快捷入口 📥 从 Codex 导入项目对话 📤 导出 DSH 对话到 Codex 🤔 为什么要用这个插件？

在使用 OpenAI Codex 时，你可能已经积累了： 1. 大量项目的对话历史（包含完整的代码上下文、架构讨论与调试记录）； 2. 丰富的自定义 Skills 库（/.codex/skills 下各种专有工具与指令）； 3. 精心配置的 MCP 服务工具链（数据库、搜索、浏览器自动化等）。

安装命令

dsh plugin --profile web add github:Walvez/dsh-codex-sync
