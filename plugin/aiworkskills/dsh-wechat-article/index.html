项目简介

aws-wechat-article 是一个运行在 DeepSeek Harness 中的微信公众号创作插件。

整个过程仍然在对话中完成。插件在右侧增加了一个“公众号”工作台，帮助你查看文章定稿、排版文件和配图，也可以管理写作需要的产品资料与图片。

构建客户端界面时需要读取 Harness 源码里的构建预设（这部分没有随 npm 发布），默认按 ../../deepseek-harness 查找。仓库放在别处时，用 DSHSOURCEROOT 指明位置即可：

安装命令

dsh plugin --profile web add github:aiworkskills/dsh-wechat-article
