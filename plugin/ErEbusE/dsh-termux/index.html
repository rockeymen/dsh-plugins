项目简介

在 Termux(Android)上运行 DeepSeek Harness(dsh),无需 root。 这个项目是什么

本项目为了让 dsh 适配 Termux 环境所做的修复与适配,每行一条。细节见 PATCHES.md。 修复/适配 · 一句话简介 · 详情 修复/适配: 会话保存与 write 工具报 EACCES: link · 一句话简介: SELinux 禁止在应用私有存储中创建硬链接;补丁改为回退到 rename() · 详情: 补丁 1 修复/适配: dsh web 交接子进程死掉;参数被拆词 · 一句话简介: process.execPath 曾指向 glibc loader;启动器现在直接 exec node · 详情: 修复 2 修复/适配: dsh web 在 Android 上找不到浏览器 · 一句话简介: $BROWSER 指向一个 Android intent 打开器 · 详情: 修复 3 修复/适配: dsh 更新体验优化 · 一句话简介: 包装脚本认识 dsh update,原样转交内置更新器 · 详情: 适配 4 状态与限制

对用户环境的更改只有这些: 项目 · 位置 项目: Node + dsh + 打补丁的依赖 · 位置: $HOME/.local/opt/dsh-termux-runtime/ 项目: dsh 符号链接 · 位置: $HOME/.local/bin/dsh 项目: PATH 注入(带 # dsh-termux 标记) · 位置: /.bashrc 末尾 用法

安装命令

dsh plugin --profile web add github:ErEbusE/dsh-termux
