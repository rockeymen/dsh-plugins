项目简介

选择适合你的使用路径。CLI/TUI、桌面端和 VS Code 扩展都使用同一套本地 Reasonix 引擎。 路径 A：CLI / TUI

预编译归档(darwin|linux|windows × amd64|arm64)和 SHA256SUMS 见每个 GitHub release。 路径 B：桌面端

桌面端构建额外需要： Node 24+ 和 pnpm 10（npm install -g pnpm@10）用于前端 Wails CLI，与共享的 .wails-version 固定版本一致

安装命令

dsh plugin --profile web add github:esengine/DeepSeek-Reasonix
