项目简介

面向 DeepSeek Harness 社区版 VS Code Extension，支持四种模式切换、Trace Vscode内查看等特色功能

English | 简体中文 注意：本项目为独立社区项目，并非 DeepSeek 官方项目，也未获得 DeepSeek 官方维护。 [!NOTE] 亮点 - 快速查看Key余额 - 流式传输、队列、Steer、审批和计划评审支持 - 输入 @ 实时搜索工作区文件，并插入明确的文件引用 - Git Diff集成，长prompt自动转文件发送 - 在内建 Trace 中查看工具调用、结果和 Reasoning - 支持文件路径与行号跳转 - 查看当前模型、Reasoning effort、计费 Token、缓存用量和估算上下文压力 - i18n支持

功能更全面：会话状态、IDE 上下文、Runtime 活动、审批、Trace、文件变更均集成在插件内。 功能架构

dsh plugin --profile web add github:HarcoChen/dsh-vsc-integration
