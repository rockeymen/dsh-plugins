项目简介

对于离线首先从 SHA-256 验证开始。可选的语言工具链 和可独立卸载的语音包仍然是单独的下载。 运行时激活是原子的。之前验证的 DSH 闭合仍然可用 从故障屏幕；回滚在应用程序重新启动时固定，直到用户 显式恢复 APK 捆绑的运行时。

响应式产品网站位于 site/，并由 GitHub 每次推送到 main 时都会进行寻呼。它介绍了 Android 应用程序和 Windows 伴侣，并根据最新的 GitHub 解析其下载按钮 运行时释放。

该项目固定 Android Gradle Plugin 9.2.0、Gradle 9.4.1、Kotlin 2.3.21、 编译 SDK 37，目标 SDK 36，最低 SDK 29。设置 sdk.dir local.properties，然后运行scripts/build.ps1。

安装命令

dsh plugin --profile web add github:Very12345/sai
