项目简介

dsh-mmx-bridge 一个工具 = MiniMax 全部多模态能力。 让 DeepSeek Harness（DSH）的纯文本模型直接看图、画图、生成视频、说话、唱歌、翻唱、搜索、查额度。 为什么需要这个？

需要先运行 mmx auth login 登录 MiniMax 账号。如果使用 Token Plan，确保套餐有效。

MiniMax 视频生成有队列限制，高峰期可能需要等待。检查 mmx quota 确认额度充足。

安装命令

dsh plugin --profile web add github:welsione/dsh-mmx-bridge
