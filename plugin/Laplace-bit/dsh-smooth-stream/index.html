项目简介

English | 中文 dsh-smooth-stream 是 DeepSeek Harness（dsh）的社区插件，给 Web 对话做丝滑流式渲染：字跟着模型走、换行滑入、不闪。不是官方发行的一部分。

Host 日志里应出现 [dsh-smooth-stream] plugin loaded!。

卸载：pnpm dsh plugin --profile web remove dsh-smooth-stream（或 dsh plugin --profile web remove dsh-smooth-stream）。 配置

安装命令

dsh plugin --profile web add github:Laplace-bit/dsh-smooth-stream
