项目简介

一个滑杆管全局，-3 到 +20 像素，拖动立即生效。聊天记录、代码块、侧边栏、设置页、各插件面板——页面上所有文字一起变大。 🎯 准星选取：点哪调哪

设置页里点「选取区域」，或者按你自己设的快捷键（见下），鼠标会变成一个红色准星。这时候把鼠标移到界面任何地方： 鼠标划过哪里，哪里就亮起红框 旁边小气泡告诉你：这块文字是什么类型、现在字号多大 点一下，原地弹出一个悬浮条，上面有 − 和 + 两个按钮，按一下字就变一次，所见即所得 调完点「完成」，或者按 ESC / 右键 / 点别处退出

点下去会发生什么，取决于那块文字的字号是怎么定义的，选取器会自动选最合适的调法： 你点的文字 · 悬浮条显示 · 调整范围 你点的文字: 聊天正文、标题、行内代码、代码块 · 悬浮条显示: "聊天正文 / 标题一 / 行内代码 / 代码块（文字类型）" · 调整范围: 同类文字全局统一变——聊天和轨迹视图里的正文是一套，改一处全都跟着 你点的文字: 底部 LLM 用量条、用户气泡、各插件的边框标签 · 悬浮条显示: "插件名 · 具体组件名" · 调整范围: 只动这一个组件——比如把用量条调大而气泡不动，完全可以 你点的文字: 其他兜不到的 · 悬浮条显示: "主界面（全局偏移）" · 调整范围: 跟全局滑杆走

安装命令

dsh plugin --profile web add github:warmwine/dsh-ui-font
