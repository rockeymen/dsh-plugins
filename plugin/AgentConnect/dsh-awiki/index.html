项目简介

为 DeepSeek Harness 提供 AWiki 身份与消息能力。一个包同时包含 Host Service、Rust SDK Provider、Agent 工具， 以及带可拖动 AWiki Me 悬浮入口的 Web 客户端。

请在常规 DSH base 和 Web app bundle 之后应用本包。cordis.patch.yml 会加入 Host Service 和 Provider；浏览器客户端由 DSH 根据包元数据自动发现并注入。 配置

Handle 提供方的默认域名为 awiki.ai。本机用户可以在“设置 → AWiki”中覆盖该值； DSH 会把选择写入自己的设置文件，并在下次重启 Harness 后生效。该设置影响后续 身份注册和短 Handle 的域名补全，不会改写已经注册的 DID 或 Handle。

安装命令

dsh plugin --profile web add github:AgentConnect/dsh-awiki
