项目简介

您的编码代理很好，但在长时间的会话中，它可能会出现视野狭隘：错过安全漏洞，在测试实际通过之前声称“已完成”，或者在错误的转弯后继续前进。 选区委员会为其提供了第二双眼睛——一个或多个独立的“顾问”模型，他们实时观看会议并在有问题时大声疾呼。

每个顾问都会随着记录的增长而阅读它，可以使用只读工具（read / grep / glob）调查您的工作空间，并通过专用的 advise 工具提供具体建议。建议以清晰标记的形式到达，主要代理权衡——而不是它必须遵守的命令：

安装命令

dsh plugin --profile web add github:AndrasSama/dsh-omp-advisor
