项目简介

一个 DeepSeek Harness bundle：把你当前在 IDE 里的状态带进每一轮模型——打开的文件，以及当前的文本选区（文件路径、0-based 行列区间、选中文本）。

用户可在自己 profile 的 cordis.patch.yml 里覆盖任意键（它在所有 bundle 层之后应用）：

refreshIntervalMs 必须是非负安全整数。省略或 0 表示只要 IDE 状态自上次注入以来发生变化就注入；正值会额外抑制距最近一次注入不足该毫秒数的注入。pollIntervalMs 默认 5000。lockDir 默认 /.claude/ide。 模型看到什么

安装命令

dsh plugin --profile web add github:LSAI2023/dsh-ide-context
