项目简介

DeepSeek Harness：设置背景的事件监视器 watch — shell 命令或 WebSocket — 每个 stdout 行（或文本框架）都被传递到 拥有代理会话作为异步事件。代理人继续工作或闲置； 只有当某物实际到达时，推理才会发生。

以 Claude Code 的 Monitor 工具为模型。它涵盖了代理需要做出反应的情况 事情发生时而不是最后：开发服务器或测试观察者报告它 重新编译，代理应响应中期任务的日志或队列，这是一个失败的长构建 应该中断而不是等待，套接字向其提供消息。如果没有它，选项是 阻止一个命令直到它退出，或者轮询一个计时器——这会花费一个模型打开每个 空检查并将每个事件延迟最多一个完整的时间间隔。 状态

工作正常，并根据真实的 dsh 配置文件进行端到端验证。两家生产商均涵盖： 命令 — 每行交付、批处理、标签、速率限制和自动终止、jobkill、 并通过 joboutput 恢复限幅输出 websocket — 每个文本框架一个事件，多行框架保持完整，二进制框架 报告其大小、紧密代码和超时作为工作结果

安装命令

dsh plugin --profile web add github:ichabodcole/dsh-plugin-monitor
