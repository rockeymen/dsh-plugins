项目简介

一个 Windows 桌面悬浮小窗：启动 Claude Code / dsh 时自动弹出，实时显示 DeepSeek 开放平台的官方用量（余额、今日消费、模型 Tokens、请求数）和本地缓存命中统计。

DeepSeek V4 系列在 2026-08-17 起大幅涨价并改为峰谷定价——高峰时段费用直接翻倍，跑模型的成本一下子敏感起来（网友戏称"梁圣变梁子"，说的就是这次调价）。

安装命令

dsh plugin --profile web add github:yuye05/dsh-monitor
