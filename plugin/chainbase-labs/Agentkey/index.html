项目简介

AgentKey是代理生态系统的主密钥。使用Claude、Manus或其他代理时，经常需要外部数据：社交媒体、电子商务、链上数据、各种API。这意味着寻找 API 密钥、管理订阅或陷入死胡同。

现在：一台 AgentKey 搞定一切。 AgentKey 统一了人工智能执行实际工作所需的所有外部访问。 新来的？从网络开始

在触摸终端之前，您可以直接在浏览器中感受一下 AgentKey - 网站和控制台比本自述文件更直观地解释了事情。 🌐 agentkey.app — 产品概述、支持的平台、现场演示、定价详细信息 🎛️ console.agentkey.app — 注册、管理您的订阅、管理您的 API 密钥、跟踪使用情况

dsh plugin --profile web add github:chainbase-labs/Agentkey
