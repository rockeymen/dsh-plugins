项目简介

在生成前，先把用户需求写成验收合同，并在 PNG 检查时逐项对照： 编号 · 用户要求 · PNG 中应看到的证据 · 优先级 编号: R1 · 用户要求: 视觉上克制、专业 · PNG 中应看到的证据: 统一色彩、明确层级、足够留白 · 优先级: MUST 编号: R2 · 用户要求: 解释三阶段流程 · PNG 中应看到的证据: 有三个可读且有顺序关系的阶段 · 优先级: MUST 编号: R3 · 用户要求: 保留品牌 Logo · PNG 中应看到的证据: 位置、比例和清晰度符合要求 · 优先级: SHOULD

交付级、逐元素精确控制，使用公开的 pptxdesigner Build API。 FreeStyle Mode

使用 generateppt()。主题 query 和结构化 content 是同一 FreeStyle 模式的两种输入形式。 VI Build Mode

安装命令

dsh plugin --profile web add github:sunchaokun/PPT-Design-Skill
