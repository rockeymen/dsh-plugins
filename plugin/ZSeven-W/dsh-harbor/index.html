项目简介

npm: @zseven-w/dsh-harbor &middot; 当前插件版本: 0.1.0-rc.2 &middot; 已验证 DSH 0.1.1-rc.2

DSH 浅色模式下的 Harbor 设置页——实时注册表、当前 profile 归属、本机版本事实与变化基线。 为什么需要 DSH Harbor

DSH 插件运行在宿主 Node realm 中，拥有与 DSH 相同的本机权限。Harbor 不用一个“风险分数”假装解决这个问题，而是维护一本只读、带证据的事实台账：装了什么、插件声明了什么、代码和实时宿主实际暴露什么、哪些插件发生冲突，以及上次扫描后发生了什么变化。 🔎 能力清单

安装命令

dsh plugin --profile web add github:ZSeven-W/dsh-harbor
