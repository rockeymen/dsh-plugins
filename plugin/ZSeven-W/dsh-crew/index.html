项目简介

npm：@zseven-w/dsh-crew · 当前插件版本：0.1.0-rc.1 · 使用 DSH 0.1.0-rc.6 进行测试

DSH Crew 设置页面 — 主机集成、调度策略、执行和多式联运桥 为什么选择 DSH Crew

DSH Crew 是 DeepSeek Harness (DSH) - 开源代理工具的插件。它使 DSH 代理可以从 Claude Code 和 Codex 调度：协调器保留自己的模型，工作在真正的 DSH 代理上运行，并具有该工具、沙箱、预设和会话历史记录，并且主机仍然将其显示为具有实时进度的本机子代理。

安装命令

dsh plugin --profile web add github:ZSeven-W/dsh-crew
