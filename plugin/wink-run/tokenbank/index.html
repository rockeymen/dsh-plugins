项目简介

Token Bank 个人AI中枢 · Token 管家 用的明白 · 用的节省 · 用的简单 · 越用越懂你 · 闲置赚钱 一键纳管 Claude / Cursor / Codex / WorkBuddy · 一站式 Trace 与路由 · 画像驱动资源发现 · 社区分享与远程智能体

Token Bank 不只是转发 API——它把 Claude Code、Codex、Cursor、WorkBuddy、Kimi Code、OpenClaw 等主流 Agent 统一纳入本地网关，在不改动 Agent 本身的前提下，实现用量追溯、模型切换与智能路由。 一键纳管应用

1. 点击 纳管 → 开始统计该应用的 Token 用量（即使仍直连官方订阅） 2. 在路由下拉框选择 模型或场景路由 → 自动改写配置，流量走本地网关 3. 点击 还原 → 恢复官方配置，停止纳管统计

安装命令

dsh plugin --profile web add github:wink-run/tokenbank
