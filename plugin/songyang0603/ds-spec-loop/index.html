项目简介

English | 简体中文 一个可复用的 Agent Skill，把 DeepSeek Harness 公开仓库中可以观察到的 Spec 编程方法应用到其他软件项目中。

ds-spec-loop 用于帮助编程 Agent 在开发功能、修复 Bug、调整架构或接口、改进测试与开发流程、简化或删除代码时，让需求、决策、实现、测试和文档保持一致。

这里的 Spec 编程不是“先写一份很长的计划再开始编码”，而是把仓库本身作为事实来源：仓库指令记录约束，当前文档描述系统现状，决策记录保留选择某种方案的原因，代码和测试提供可以运行或检查的证据。 🧭 方法来源
