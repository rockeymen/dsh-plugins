项目简介

为 DeepSeek Harness 提供 Google Antigravity (agy) 接入： OAuth 认证、多账号池 + 自动 429 轮换、设备指纹伪装，以及 CLI 与 Web 双管理入口。 English: README.md 功能 OAuth 登录: 通过浏览器 OAuth 回调一键登录，支持 headless 粘贴 URL 模式与远程粘贴凭据 blob 通道。 双管理入口: web 和 cli 任选其一，核心功能一致。 多账号池: 加密账号存储、限流自动轮换、分级退避冷却、每账号设备指纹。 配额仪表盘: 仅在 DSH Web 启动时有效，在你的 dsh web 地址后添加 /agy 访问：登录、账号管理、每模型配额条、模型测试、 凭据导出/导入、指纹管理。 CLI: dsh-agy login|status|import|verify|logout，独立于 harness 运行。 效果演示

适用于使用 DeepSeek Harness 桌面/浏览器工作台的用户： 路径 B：无桌面 / 纯终端环境（CLI 独立使用）

删除本地文件不会撤销 Google 侧的 token——refresh token 在过期或你在 Google 账号 安全设置中手动撤销前仍然有效。 其他你可能关心的事 轮换机制

安装命令

dsh plugin --profile web add github:chaos-03x/dsh-agy
