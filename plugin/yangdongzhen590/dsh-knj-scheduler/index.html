项目简介

刷新页面后，界面右侧边缘出现「⏰ 调度器」工具栏竖条。 要求：dsh web >= 0.1.0-rc.7（rc.8 已验证）。入口通过 body portal 挂载， 不依赖宿主 slot、不需要修改宿主文件。 使用

1. 点击右侧工具栏竖条「⏰ 调度器」 2. 「＋ 新建任务」：填写任务名称、Cron 表达式（如 0 9 ）、提示词 3. 保存后任务按 Cron 调度；到点自动新建会话并执行提示词 4. 任务行可：编辑 / 启停 / 立即执行 / 查看历史 / 删除 配置（可选）

在 cordis.yml 的插件行中可覆盖： 数据位置 任务定义：$DSHHOME/profiles//dsh-scheduler/tasks.json 执行历史：$DSHHOME/profiles//dsh-scheduler/history.jsonl 卸载

安装命令

dsh plugin --profile web add github:yangdongzhen590/dsh-knj-scheduler
