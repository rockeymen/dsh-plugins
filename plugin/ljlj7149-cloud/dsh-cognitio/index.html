项目简介

dsh-cognitio 纠错驱动的认知架构插件 —— 让 DeepSeek Harness 的 AI 记住你的规矩、教训与知识，并在该守规矩的时刻自动提醒；所有自动沉淀，你批准才生效。 这是什么

cognitio（认知·张力网络）是一个 DeepSeek Harness 插件，把"AI 的记忆与自律"从凭自觉变成机制： 记忆是分层的（事实/规矩/模式/案例/命题），改过的内容永远能查旧版（版本链） 提醒是机械触发的（每回合/动作前/出错/回合末自动检索），不依赖模型记住你定的规矩 进化是纠错驱动的（出错 → 自动归档 → 每日提炼 → 你批准 → 成为新规矩） 你永远是仲裁者：一切自动产物只进草稿，批准才转正（审批面板可见可一键批）

1. 装好并重启后，打开 设置 →「cognitio 系统」 2. 「记忆库」页：看到分层记忆 + 状态（已生效/待审批）+ 筛选胶囊（全部/事实/规矩/模式/案例/命题） 3. 「规则」页：生效中的规矩（50 条+）与待你批的规矩分区显示；点条目展开定义/触发词/失效条件 4. 在任意会话重复说一句话——哨兵按需注入相关规矩（人工验证触发链路） 设置页 / cognitio 系统

安装命令

dsh plugin --profile web add github:ljlj7149-cloud/dsh-cognitio
