项目简介

双子座·克劳德·ChatGPT——终于完成了。 -> [!注意] 如果Voyager对您有帮助，请随时在X、Reddit、YouTube、Threads等上分享，每一次分享都能帮助更多人发现该项目。谢谢。 👋 为什么是 Voyager？

这就是我构建 Voyager 的原因。它是一个可以帮助您保持 AI 对话井井有条、易于访问且高效的伴侣——无论您使用的是 Gemini、Claude 还是 ChatGPT。如果您是处理数十个线程的研究人员、保存代码片段的开发人员，或者只是喜欢秩序的人，Voyager 就是为您设计的。

由 Voyager 插件引擎 提供支持，这些功能将您的体验扩展到 Gemini 之外： 📍克劳德时间轴：带有星标消息和搜索的对话侧边栏 - 相同的导航流程，现在在克劳德上。 📊 Claude 使用栏：直接在 Claude 界面中跟踪您的会话和每周使用情况。 📐公式复制：一键复制LaTeX和MathML源代码（与Gemini共享）。 📖 舒适的阅读宽度：调整聊天宽度，以获得更好的 Claude 和 ChatGPT 阅读体验。 🈶 CJK 渲染修复：修复 Claude 上的 CJK 字符渲染问题。 🧩 任何网站 — 甚至是本地主机

dsh plugin --profile web add github:Nagi-ovo/voyager
