项目简介

dsh-theme-endfield Edge Intelligence Theme — 参考《明日方舟：终末地》官网视觉风格的 DSH（DeepSeek Harness）Web 主题插件。

1. 复制 client.js 里 apply(ctx) { ... } 的函数体； 2. 用 cordisdefine 新建插件，粘贴为 Client 代码（return { apply(ctx) { ... } }），再用 cordisrun 激活； 3. 刷新页面生效；在 Run 卡片上停止插件即完全卸载（令牌层与样式层自动拆除）。

client.js 依赖 DSH Client 运行时的 theme 服务与 styles 内建，不能在普通浏览器里直接运行。 设计语言速览 维度 · 取值 维度: 纸底 · 取值: 亮 #e8e8e2 / 暗 #101110 维度: 文字 · 取值: 亮 #101110 / 暗 #f5f5f0 维度: 强调色 · 取值: 谷地黄 #fff500（默认）或 武陵青 #14d0d0，设置页一键切换 维度: 字体 · 取值: Arial / Helvetica Neue / PingFang SC / Microsoft YaHei，开启 tnum 等宽数字 维度: 圆角 · 取值: 全部 0（状态点、头像、加载圈保留圆形），可切回圆角

安装命令

dsh plugin --profile web add github:ymh0000123/dsh-theme-endfield
