项目简介

dsh-llm-codex-oauth 本项目由 DeepSeek-V4-Pro 在 DeepSeek Harness 用时约 3h 不到完成，未进行完整 Code Review，仅人工审查确保基础功能可用，使用前需了解安全风险并自行为此负责。

脚本会自动定位 $DSHHOME（默认 /.dsh），把插件复制进 DSH 实际优先解析的 nodemodules 并写入 bundle 列表，全程不碰 pnpm。Windows 上在 cmd / PowerShell 里直接运行同一命令即可，插件本身是纯 Node 实现，不依赖 bash / pwsh。

安装命令

dsh plugin --profile web add github:Player-MINEPIG/dsh-llm-codex-oauth
