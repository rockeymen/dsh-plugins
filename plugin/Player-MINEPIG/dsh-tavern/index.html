项目简介

状态：2026-08-18，对应当前角色卡创建/编辑与单份文档存储。本文介绍实际操作；消息流、架构和安全契约分别见 DSHMESSAGEFLOW.md、ARCHITECTURE.md 与 LOADERCONTRACT.md。 1. 打开和切换面板

预设面板支持导入 SillyTavern Chat Completion preset JSON，也可以创建空白预设。

append 保留 DSH 原有 system sections；replace 仅保留 Tavern profile 的模型可见 system 文本，可能使 Code Mode、结构化输出或工具提示可靠性下降，但不会关闭文件沙箱、审批和工具执行权限。 3. 角色卡
