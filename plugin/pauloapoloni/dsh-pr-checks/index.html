项目简介

布局细节：sidebar.footer.action插槽为Flex行；该包注入了一个 CSS 规则，该规则在容器的散列类 (.hHd-XafooterActions) 上启用 flex-wrap，因此小部件会占据整行，并且图标（例如 cordis 面板）会换行到下一行。如果 DSH 更新重命名该类，则小部件将继续呈现 - 只是没有换行。 发展 该条目从 cordis.patch.yml（配置 HMR）应用。对 lib/.js 中的 代码 进行更改需要重新启动 dsh web（加载程序不会重新加载已导入的模块；客户端模块注册表会缓存每个进程的解析失败）。

安装命令

dsh plugin --profile web add github:pauloapoloni/dsh-pr-checks
