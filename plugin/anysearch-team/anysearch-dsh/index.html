项目简介

@anysearch/anysearch-dsh AnySearch 面向 DeepSeek Harness 的官方网页搜索插件。 English | 简体中文

需要 Node.js 22.19 或 Node.js 24+、pnpm 11.7 和 DeepSeek Harness。DSH 插件命令使用 pnpm 管理 profile 依赖，因此 pnpm 必须位于 PATH 中。

快速体验不需要 API Key。未配置时，请求使用 AnySearch 匿名额度。 提供什么 通过 Harness 内置的 websearch 返回 AnySearch 搜索结果。 实时发现可用领域和垂直搜索能力。 使用标签、参数、地区和语言执行高级搜索。 并发执行一至五个搜索，并保留单项失败。 按需提供清洗后的网页正文；单次搜索的结构化正文累计不超过 200,000 字符，并另行限制向模型展示的字符数。 支持调用方取消、55 秒 HTTP deadline、60 秒高级工具预算、响应校验和不会向重定向目标泄露凭据的安全策略。 可选 API Key

安装命令

dsh plugin --profile web add github:anysearch-team/anysearch-dsh
