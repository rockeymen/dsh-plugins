项目简介

插件使用仓库现有的本地 Git 配置、SSH 密钥、HTTPS credential helper 和 Git remote。不调用 GitHub API、不保存 GitHub token、不实现 OAuth、不依赖 GitHub CLI，也不暴露任意 shell 命令。GitHub 链接只打开对应的浏览器页面；Compare 页面是创建 pull request 的交接入口。Git 写操作需要用户明确触发，并在完成后重新读取仓库状态。 实现分析

重新构建插件后需要重启 Web Harness。在 Workspace 的更多菜单中选择 查看 Source Control。 开发检查

安装命令

dsh plugin --profile web add github:PivotStackIntelligence/dsh-github
