项目简介

iPSS 代理 InterPSS Agentic 电力系统仿真代理，用于交流潮流、基于直流的应急分析和 NERC TPL-001-5 样式报告。此存储库提供了针对 OpenAI Codex Desktop、Claude Code CLI 和 Deepseek Harness 的面向代理的技能（请参阅 Setup.md）。其他代理 CLI 可以通过从 .agents/skills/ipss-sim/ 或 .claude/skills/ipss-sim/ 复制技能内容来重用相同的工作流程。

它还作为 DSH 插件集成到 Deepseek Harness 中。您可以按照传统的分步方式运行电力系统仿真：

安装命令

dsh plugin --profile web add github:InterPSS-Project/ipss-agent
