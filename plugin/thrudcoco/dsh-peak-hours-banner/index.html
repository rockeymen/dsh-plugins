项目简介

dsh-peak-hours-banner DeepSeek Harness（DSH）Web GUI 时段状态横幅插件

横幅右上角提供悬浮控制： “–” 最小化为红/绿状态圆点（点击圆点展开）， “×” 关闭横幅（刷新页面恢复）。 🖥️ 文本显示规则 场景 · 横幅显示 场景: 工作日 · 北京时间 09:00–12:00 · 横幅显示: 🔴 现在是高峰时段（09:00–12:00），请注意余额消耗。 场景: 工作日 · 北京时间 14:00–18:00 · 横幅显示: 🔴 现在是高峰时段（14:00–18:00），请注意余额消耗。 场景: 工作日其它时间 · 横幅显示: 🟢 现在是空闲时段，请注意休息，劳逸结合。 场景: 周六 / 周日全天 · 横幅显示: 🟢 现在是空闲时段，请注意休息，劳逸结合。

横幅按 “你计算机的时钟” 换算成北京时间的窗口来判断。你在不同时区，同一 时刻对应的北京时间不同，属正常现象。

安装命令

dsh plugin --profile web add github:thrudcoco/dsh-peak-hours-banner
