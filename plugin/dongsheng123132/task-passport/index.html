项目简介

如果 U-King 不在 PATH，在该 profile 的 cordis.patch.yml 覆盖插件配置：

如果记不住编号，也可以说任务名。插件会先列护照；只有名称唯一时才继续，重名时必须让人选择。 通用 CLI

长状态只接受文件，不塞命令行参数。stdout 除 prompt 外只输出 JSON，适合 Agent 与脚本调用。 不依赖 U-King 的本地存储
