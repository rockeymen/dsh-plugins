项目简介

一个 DeepSeek Harness（DSH）待处理改动审核插件：自动跟踪每次成功的 edit / write / 编辑器（strreplaceeditor）改动，在侧边栏整合为一个待处理列表，可逐个文件查看完整差异并保留 / 回退，也可以把工作区里版本控制仓库的本地改动一键导入（Git / SVN / Perforce）。

若通过 npx 启动 harness（如 npx @deepseek-ai/dsh web）：

或手动：把本包加入 profile 的 package.json 依赖，并在该 profile 的 cordis.patch.yml 中加入：

安装命令

dsh plugin --profile web add github:9087/dsh-diff-approval
