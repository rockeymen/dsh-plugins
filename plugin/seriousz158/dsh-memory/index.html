项目简介

dsh-memory 是一个本地的、Git 支持的长期内存插件，适用于 DeepSeek Harness (DSH)。

dsh-memory-sync --dry-run 报告候选差异（添加/修改/删除 路径、拒绝的文件和原因）而不触及活动根、日志， Git，或者水印。

清除操作保留其现有语义：它保留 .sync， .last-sync、README.md和scripts/，并且在清除日志后仍然 存在，以便操作员可以看到发生了什么。清除报告后回滚 rollback-conflict 因为较新的内存写入取代了运行。 v0.3：序列化同步运行、运行状况和中断运行恢复
