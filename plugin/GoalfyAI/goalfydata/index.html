项目简介

将 spreadsheets、API、数据库和代理输出转变为可重用的数据集和数据应用程序 保留业务环境并保持最新状态。

Codex、Claude Code、Manus 和其他连接的代理可以创建数据集、编写更新脚本、分析结果和构建数据应用程序。 GoalfyData 将结果数据及其字段定义、指标定义、表关系、权限和治理规则保存在一起。

其结果是一个持久的数据资产，可以在对话、代理、设备和团队之间重复使用。导入数据、运行 SQL 分析、计划更新、通过受控访问进行共享以及从同一数据集部署数据应用程序。当数据集更新时，连接的应用程序会继续读取最新数据。 快速入门

安装命令

dsh plugin --profile web add github:GoalfyAI/goalfydata
