项目简介

给 DeepSeek Harness 的纯文本模型外挂托管视觉能力，同时保留 Desktop/profile 中配置的文本模型作为推理模型。图片先交给免费或自定义的 OpenAI 兼容视觉 API，VLM 实际生成并交给配置文本模型的描述会写入 DSH Session，之后按普通文本重放。

要求 DSH 0.1.0-rc.6 或同一 0.1.x 线上的更高版本，以及 Node.js 22.19+ 或 24+。 三步即用：免注册托管视觉

开始前，你需要一个已能正常调用文本模型的 DSH Web profile。插件不要求特定的主推理提供方或模型，会把视觉描述交给配置中的 targetProvider 和 targetModel。

安装命令

dsh plugin --profile web add github:121103qwq/dsh-vision-sidecar
