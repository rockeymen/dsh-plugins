项目简介

在 DSH 会话中使用超级模组注入器，运行时注入即生效，卸载即净： 方式 C：Release bundle 包

下载 Releases 中的 dsh-sysmon-0.1.0.tgz，作为 bundle 包装配（与 dsh-web-ui 家族插件一致），装配时应用仓库内的 cordis.patch.yml 插入插件行（id：sysmon，包名：@dsh-external/dsh-sysmon）。 验证

安装命令

dsh plugin --profile web add github:21hbguo/dsh-sysmon
