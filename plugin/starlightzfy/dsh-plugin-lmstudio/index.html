项目简介

在 DeepSeek Harness（DSH）Web 界面上，把 LM Studio 本地部署的模型当作对话模型使用。

LM Studio 提供 OpenAI 兼容端点（默认 http://127.0.0.1:1234/v1）。本插件把 DSH 内置的 llm-pi-ai 适配器指向该端点，模型选择器随即出现本地模型—— 不消耗云端 API 额度。

本包声明了 dsh.bundle，dsh plugin 会自动把它加进 profile 的 bundle 层。 然后重启 dsh web 并刷新 http://127.0.0.1:3080。 配置

安装命令

dsh plugin --profile web add github:starlightzfy/dsh-plugin-lmstudio
