项目简介

Monorepo 用于 DeepSeek Harness 的 iKanban 插件包。 套餐 @isomoes/dsh-ikanban - 库存DSH Web重新包装和键盘优先定制基础 packages/ui-layout - 三列 Web shell 的私人源代码 packages/ui-sidebar - 品牌侧边栏外壳的私人来源 packages/ui-workspace - 工作区和会话浏览器的私有源 发展

pnpm dev 自动创建或刷新配置文件。使用 pnpm dev:config 无需启动即可检查生成的合成。

详见软件包【开发指南](packages/ikanban/README.md#local-development) 用于重建行为和配置文件清理。
