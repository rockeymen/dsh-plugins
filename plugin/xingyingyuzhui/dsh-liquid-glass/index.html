项目简介

DeepSeek Harness（DSH）Web 皮肤：在官方浅色 / 深色 / 跟随系统之上叠加壁纸，以及可选的液态玻璃岛。

装完重启 DSH（dsh web），然后打开 设置 → 通用 → Liquid Glass。 使用 控件 · 作用 控件: Wallpaper · 作用: 预设 / 导入。滑杆只改壁纸透明度。 控件: Glass blur · 作用: 每个玻璃岛背后的 backdrop blur。壁纸保持清晰。 控件: Liquid Glass · 作用: 开/关材质。关了恢复官方表面，壁纸可单独留着。

旧的「壁纸模糊」存储键不再读取，也不会自动换成新的玻璃模糊。 工作原理 面 · 文件 · 说明 面: Host · 文件: host.js · 说明: 托管冰原 / 深水 JPEG。哈希 URL 一年 immutable，legacy URL no-cache。 面: Client · 文件: client.js · 说明: ModuleLoader bundle：设置行 + 壁纸层 + 玻璃岛 CSS。源码在 src/client/，client.js 由 npm run build 生成。

安装命令

dsh plugin --profile web add github:xingyingyuzhui/dsh-liquid-glass
