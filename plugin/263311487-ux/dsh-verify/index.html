项目简介

dsh-verify（Witness）· 智能体说做完了，浏览器来证明 你让 DeepSeek Harness（或其他 AI）帮你写了个网页。它说"做完了"。你敢直接上线吗？

dsh-verify 会打开一个真实的浏览器，把你写好的检查清单一步步执行一遍：点击、输入、看样式、查控制台报错、对比截图。通过就是 PASS，不通过就是 FAIL，还附带截图证据。 评判者不是 AI，是真实浏览器。 如果 Witness 帮你抓到了问题，⭐ 给仓库点个星——这是这个项目活下去的方式。 为什么需要它

我们跑了一个 4-agent 网页开发团队（需求 → 前端 → QA → 评审）。团队的自我评审结果是： ✅ "所有需求均已满足，无问题。"

dsh plugin --profile web add github:263311487-ux/dsh-verify
