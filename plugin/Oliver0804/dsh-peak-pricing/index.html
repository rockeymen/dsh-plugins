项目简介

一個 DeepSeek Harness Web 外掛， 在輸入框底下加一行：現在是 DeepSeek 的哪個計價時段、還剩多久、以及這個工作階段 到目前為止花了多少錢。 綠點 — 離峰（空闲时段）：適合開長工作的時候。 橘點 — 尖峰（高峰时段）：同樣的用量價格剛好兩倍。 倒數：目前費率還剩多久，精確到秒。 金額：本次工作階段的花費，每一筆增量都用「它發生當下」的費率計價。

滑鼠停在該行（或用鍵盤聚焦到它）會顯示完整明細：模型、當前費率、四個 token 分桶用量、尖峰時段表——外加一張快取命中率走勢圖：每筆輸入增量一個點，固定 0–100% 縱軸，最多保留最近 120 個點，長工作階段也不會失真。走勢與累計金額同住 localStorage，重新整理不會丟；和費用一樣，開啟工作階段後的第一筆讀數只能 整筆取樣，之後的每一點都是精確的增量。 安裝

單位為人民幣元／百萬 tokens。價目表就寫在 src/pricing.ts 的一個常數裡——DeepSeek 之後調價，改那裡就好。

安装命令

dsh plugin --profile web add github:Oliver0804/dsh-peak-pricing
