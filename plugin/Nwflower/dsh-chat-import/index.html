项目简介

📥 DSH Chat Import 把 13 种外部 Agent 聊天历史全保真导入 DeepSeek Harness 为可继续（resume）会话——并可导出 / 同步回 Claude Code。

dsh-chat-import 从 Claude Code、Codex、ChatGPT、Cursor、Gemini、Reasonix、opencode、ZCode、Grok Build、OpenClaw、Pi Coding Agent、Hermes 与 Kimi CLI 导入聊天历史——工具调用、思考过程一应俱全——成为全保真、可继续（resume）的 DeepSeek Harness 会话。源文件只读读取（绝不改写），不碰 DSH 引擎；每次导入都成为一条全新会话，并按源 cwd 归入对应工作区。

importchatgpt / importopencode / importzcode / importhermes 恒返回批量结果——一个文件 / 数据库包含全部会话，一次调用即可让每段对话成为独立会话。

安装命令

dsh plugin --profile web add github:Nwflower/dsh-chat-import
