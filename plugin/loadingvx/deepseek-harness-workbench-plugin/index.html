项目简介

DeepSeek Harness Web UI 工作台插件。在「对话」视图中打开工作台后，对话保留在左侧；右侧新增两栏，分别承载编辑器（含语法高亮与终端）以及文件与 Git。 发行信息 项目 · 说明 项目: 包名 · 说明: dsh-workbench-plugin 项目: 当前版本 · 说明: 0.1.8（npm 标签 latest） 项目: 软件源 · 说明: https://registry.npmjs.org

2. 重启 dsh web。 3. 访问 http://127.0.0.1:3080 ，进入「对话」，在标题栏右侧打开 工作台。 升级 自动提示

工作台为三栏布局。左侧为系统对话；右侧两栏为本次新增的能力区：中央为编辑器与终端，最右侧为文件树与 Git。

安装命令

dsh plugin --profile web add github:loadingvx/deepseek-harness-workbench-plugin
