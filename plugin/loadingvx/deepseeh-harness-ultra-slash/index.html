项目简介

DeepSeek Harness 的 Ultra Slash 插件：在会话输入框的 / 菜单里单独一组「插件命令」，和 DSH 自带命令分开。 功能 命令 · 做什么 命令: /steer 内容 · 做什么: 把内容交给模型的下一步，不打断当前对话 命令: /new · 做什么: 开启空白会话 命令: /skill · 做什么: /steer +「完成后把方案存成当前项目的 skill」 命令: /docs · 做什么: /steer +「完成后把原因和方案写成 docs 里的 md」

安装命令

dsh plugin --profile web add github:loadingvx/deepseeh-harness-ultra-slash
