项目简介

dsh-doctor 查出你的 DeepSeek Harness patch 悄悄改坏了什么。

但 dsh 处理 id 定向 patch 的方式是整个替换该条目的 config，不是合并。你没有重写的那两个字段，已经从真正启动的树里消失了：

拼错 id 同样是静默的。把 agent-default-model 写成 agent-defualt-model，dsh 只往 stderr 打一行，然后照常启动、退出码 0——用 Web UI 启动时你根本看不到那行。

安装命令

dsh plugin --profile web add github:asdf17128/dsh-doctor
