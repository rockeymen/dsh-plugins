项目简介

通过 OAuth 将你的 ChatGPT 订阅连接到 DeepSeek Harness，同时保留用户自主默认项、Harness 原生审批、非敏感诊断和可靠的会话恢复。

可在 设置 → 插件 → 插件配置 → Codex Connect → 使用 ChatGPT 登录，也可使用 CLI：

doctor 只读取进程与文件系统元数据，不打开 OAuth 文件，也不会输出 token、授权 URL、授权码、账户 ID 或认证文件内容。 显式配置

安装命令

dsh plugin --profile web add github:franksong2702/dsh-codex-connect
