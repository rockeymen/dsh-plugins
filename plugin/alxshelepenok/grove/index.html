项目简介

代码不断增长。上下文窗口则不然。种一棵 Grove 🌳 G拉夫驱动的R推理全面V验证E证据。一种正式的工作流程协议，通过机器强制的不变量、经过验证的证据和结构化上下文使人工智能编码代理保持在正轨上。旨在保持深度、长期运行的项目在不同会话、代理和月份之间保持一致。 我们不再只是编写代码。 我们控制着每天 20 次运行的火车，确保它不会脱轨。 这给你带来了什么： 原子进步： 每项任务都经过机械证明，而不仅仅是声称。 压缩上的层次结构：上下文是严格结构化的，永远不会有损地总结。 绝对可重复性： 每个动作都会被记录，因此任何步骤、决定或假设都可以重播和追溯。 跨代理的连续性：如果代理在目标中间停止，另一个客户端或模型上的另一个代理将从验证状态恢复。 完全所有权：每个目标、决策、任务、问题和假设都存储在完全属于您的持久历史图表中。

Grove 将规则强制执行为存储在单个校验和锁定文件中的确定性不变量。代理人不能在没有可伪造证据的情况下宣布工作已完成，不能启动未准备好的任务，也不能产生幻觉的进展。

Grove 不是有损即时压缩或汇总，而是将项目状态构建为具有机器可检查边缘的类型化推理图。它精确路由当前步骤所需的执行数据包，仅此而已。

dsh plugin --profile web add github:alxshelepenok/grove
