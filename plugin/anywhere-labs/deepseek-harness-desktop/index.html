项目简介

DeepSeek Harness（dsh）是由 DeepSeek AI 开发的开源 agent harness（智能体框架）。

它采用一切皆插件的架构，并由 Cordis 驱动，其设计参见论文 A Programming Paradigm for Spatiotemporal Composability。 开发者预览

DeepSeek Harness 目前处于 开发者预览 阶段，正在快速迭代。未来将出现破坏兼容性的变更。 运行 通过 npm 运行
