项目简介

🛡️ dsh-permission-rules DeepSeek Harness 的 Claude Code 风格声明式权限规则。 规则裁决已知的。评审模型裁决未知的。 Compatibility Surface · Status Surface: Harness · Status: DeepSeek Harness 0.1.1-rc.2 Surface: Node · Status: ^22.19.0 · · >=24.0.0 Surface: Platforms · Status: 全部（host + Web 设置客户端） Surface: Model · Status: 任意（deny/ask 原因经工具结果呈现） What you get

dsh-permission-rules 在 tools/pre-execute waterfall 上为每次工具调用前置一个有序的 allow / deny / ask 规则列表——确定、即时、可审计，由你用纯 YAML 编写： deny 阻断调用；规则的 reason 成为模型可见的错误。 ask 走官方审批接缝（挂载 dsh-auto-review 用第二模型作答，或由人作答；两者皆无时 harness 失败关闭）。 allow（及未命中）严格经 next() 委托——下游监听器绝不会被短路。

在 ignorable 标记出现之前写入的会话日志可能被较新 harness 构建拒绝（SessionFormatUnsupportedError）。随附的 scripts/repair-session-logs.mjs 仅重写目标审计行以携带 ignorable: true，保帧、带备份：

dsh plugin --profile web add github:PerryLink/dsh-permission-rules
