项目简介

DeepSeek Harness 的控制台命令插件：网页服务管理、SSH 隧道管理、一次性问答、可选的控制台 TUI 启动——全部在斜杠命令里完成。 快速接入

开箱即用：/web 和 /tunnel status 零配置可用（插件自动探测运行中的 dsh 入口）。隧道主机和控制台 TUI 路径在 profile 的 cordis.patch.yml 里配置：

再次 dsh plugin --profile web 并重启后，/tunnel start、/console 即可用。 命令 命令 · 说明 命令: /web status · 说明: 网页界面是否在运行（端口 + PID） 命令: /web start · 说明: 后台启动网页界面（node web --port ） 命令: /web stop · 说明: 停止网页界面进程 命令: /web restart · 说明: 重启 命令: /tunnel status · 说明: 隧道是否在运行 命令: /tunnel start · 说明: 启动 SSH 隧道（需配置 tunnelHost） 命令: /tunnel stop · 说明: 停止隧道 命令: /ask · 说明: 走 headless 的一次性问答（有超时保护） 命令: /console · 说明: 启动控制台 TUI（需配置 consoleCommand） 配置

安装命令

dsh plugin --profile web add github:Isanti2016/dsh-console
