项目简介

⚔️ DevQuest — 把开发变成 RPG DevQuest 是一个 DSH 插件：你在 agent 里做的回合、工具调用、待办、输出 tokens，都会按规则换算成 XP。XP 推等级，等级出称号，成就记录你走到哪一步。装好之后不用做任何额外操作，正常干活就会自动计分。

📅 每日任务+宝箱 · 🗓️ 每周挑战 · 🎁 每日幸运抽奖 · 🛒 赛季商店 · 🎨 主题皮肤 · 🏆 47 枚成就+稀有度 · 🏷️ 多称号 · 📊 统计+荣誉墙 🎮 怎么玩

装上插件后什么都不用配置，正常干活就自动计分： 你做了什么 · 你会得到 你做了什么: ✅ 完成一个回合 · 你会得到: +10 XP，连击 +1 你做了什么: 🧰 调用工具 · 你会得到: +1 XP（编辑/命令/SSH 等「锻造师」工具 +2，单回合封顶 +10） 你做了什么: 📋 清空待办 · 你会得到: 每个 +15 XP 你做了什么: 📝 输出 tokens · 你会得到: 每 10k +1 XP 你做了什么: 💥 犯错的回合 · 你会得到: +2 XP（安慰奖） 你做了什么: 💪 犯错后爬起来 · 你会得到: 「东山再起」成就 +100 XP 🎓 新手任务链

dsh plugin --profile web add github:lucky8197/dsh-devquest
