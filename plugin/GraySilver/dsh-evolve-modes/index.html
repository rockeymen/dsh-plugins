项目简介

DeepSeek Harness Evolve Modes 让 Agent 的工作方式可组合、可审查、可持续改进，最终实现 Agent Self Evoling。 dsh-evolve-modes 是 DeepSeek Harness 的独立 Web 插件。它在输入区提供一个紧凑的工作流控制项，让你组合 Agent 的工作状态、思考策略、质量门禁和自进化行为。

重启 Web profile 后，自进化模式控件会出现在输入区工具旁。打开顶层 自进化模式 设置即可管理全局学习规则。

点开控制项即可分别调整四个维度： 维度 · 选项 · 作用 维度: 工作状态 · 选项: 正常 · 计划 · 作用: 立即完成任务，或进入官方 DSH 计划工作流。 维度: 思考策略 · 选项: 标准 · 第一性原理 · 作用: 正常回答，或显式梳理目标、事实、假设、约束、推导和验证。 维度: 质量门禁 · 选项: 关 · 对抗性审查 · 验收审查 · 作用: 不增加审查，独立寻找风险，或对照任务和已批准计划验收结果。 维度: 自进化 · 选项: 关 · 开 · 作用: 自动分析会话，生成待人工审阅的规则提议，自动优化AGENTS.md（但不改动 AGENTS.md）

安装命令

dsh plugin --profile web add github:GraySilver/dsh-evolve-modes
