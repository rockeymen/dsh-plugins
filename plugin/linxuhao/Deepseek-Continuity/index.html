项目简介

一个 DeepSeek Harness 插件，提供 代理本地图像/语音/音乐/SFX生成并记住它的制作 - 相同 角色在每次调用中都保持相同的角色，并且绝不允许失败的生成 成功通过。

该命令完成整个后端：预检 → 构建引擎 → 仅获取权重 本机可以使用→启动它们。 PyPI 发行版是 dsh-continuity （导入名称仍为 continuitymcp）。它不是 continuity-mcp——PyPI 上的那个名字 属于不相关的项目，所以不要uvx continuity-mcp。 要从源代码运行：uvx --from git+https://github.com/linxuhao/Deepseek-Continuity continuity-setup

将其添加到已有应用程序包的配置文件中。如果您将其指向新配置文件，dsh 创建一个仅包含 @deepseek-ai/dsh-base 加上此插件的应用程序 - 没有应用程序，因此启动它 不执行任何操作并挂起。自己添加应用程序 /.dsh/profiles/ /package.json：

安装命令

dsh plugin --profile web add github:linxuhao/Deepseek-Continuity
