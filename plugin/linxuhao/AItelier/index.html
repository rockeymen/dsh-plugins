项目简介

AItelier 人工智能代理的结构化但动态的子代理工作流程 - 您的代理将工作委托给确定性的、经过全面审核的管道，它可以通过 MCP 生成、运行和编辑。

AItelier 使多代理人工智能管道确定性且完全可审计 - 定义一个管道（或让您的代理生成一个管道），运行它，并检查为什么它做了它所做的一切。整个表面暴露在 MCP 上，因此任何使用 MCP 的代理都可以使用 AItelier 作为其工作流引擎：将批量工作委托给廉价、确定性的管道，并且仅在检查点做出决定（请参阅使用来自另一个代理的 AItelier）。其之下是一个开放引擎（SkillFlow，MIT，在 PyPI 上为 skillflow-py）加上旗舰软件交付管道；更广泛的无代码工作流平台位于路线图。 为什么是AItelier

大多数“人工智能代理”工具都是为演示而构建的，而不是为了信任。为您构建软件或自动化工作流程的工具是非确定性黑匣子：您无法重现运行，无法审核代理执行其操作的“原因”，也无法在重要的地方插入人工批准。这正是阻止特工部署在任何严肃的领域的墙——受监管的行业、企业、任何“通常有效”但不够好的地方。
