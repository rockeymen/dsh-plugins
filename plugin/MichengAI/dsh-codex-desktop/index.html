English · 下载 · 更新日志 · 反馈问题 DSH Codex Desktop 是 DeepSeek Harness 的社区维护桌面发行版，并非 DeepSeek AI 官方产品。

开发环境需要 Windows、Node.js 24.19.0 和 pnpm 11.22.0。

本地构建制品写入 release\，不会提交。推送 vX.Y.Z 标签后，工作流会打包 Windows x64、macOS arm64/x64，以及 Linux x64 的 AppImage / deb 制品。 项目文档
