项目简介

DSH Agency Agents 为 DeepSeek Harness 提供 271 名可召唤的专业智能体

主会话保留任务上下文、判断和最终交付；专家子代理只提供专业视角，不能继续召唤专家，避免递归委派。 界面预览

Codex 和 WorkBuddy 只负责代装；装好后仍要打开 DSH Web 使用「设置 → 专家」。

安装命令

dsh plugin --profile web add github:MichengAI/dsh-agency-agents
