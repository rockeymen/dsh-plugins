项目简介

DSH Codex UI 为 DeepSeek Harness Web 重构 Codex 风格侧栏、工作区会话树、全局搜索和轮次导航

@michengai/dsh-codex-suite 是一键套件，会把下面 6 个插件装进同一个 profile： 插件 · npm 包 · 作用 插件: Codex UI · npm 包: @michengai/dsh-codex-ui · 作用: Codex 风格侧栏、工作区会话树、搜索和轮次导航 插件: 专家管理 · npm 包: @michengai/dsh-agency-agents · 作用: 从「专家」进入对应设置页 插件: 技能管理 · npm 包: @michengai/dsh-skills-manager · 作用: 从「技能」进入对应设置页 插件: 归档管理 · npm 包: @michengai/dsh-archive-manager · 作用: 提供永久删除和已归档会话管理 插件: IM 助理 · npm 包: @michengai/dsh-im-connect · 作用: IM 设置页和「频道」页签 插件: 定时任务 · npm 包: @michengai/dsh-automation · 作用: 定时任务设置页和「定时」页签

dsh plugin --profile web add github:MichengAI/dsh-codex-ui
