项目简介

需要「常驻声明式」作业时，在 profile 的 cordis.patch.yml 里覆盖 config；也可以完全跳过这步，改用界面或会话内创建（见使用）：

作业配置错误（重名、非法表达式、缺时区等）在挂载期 fail loud，不会静默吞掉。 使用 手工添加作业

在任意会话里直接对 agent 说需求即可： 每周一早上 7 点检查过期依赖，把升级清单存到 reports/deps-audit.md。

安装命令

dsh plugin --profile web add github:squirrel20/dsh-cron
