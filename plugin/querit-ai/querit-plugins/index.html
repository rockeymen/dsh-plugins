项目简介

注册 Querit.ai 即可获取 API 密钥，每月可进行 1,000 次免费 API 调用 — 无需信用卡。相同的密钥适用于所有集成。 pi-querit — Pi

该向导会验证密钥，然后让您配置持久搜索默认值（结果计数、时间范围、国家/地区、语言、域白名单/黑名单）和可选的固定模型自动摘要工作流程。除了 API 密钥之外的所有内容都可以跳过。 密钥所在位置： /.pi/agent/querit-search.json（尊重 PICODINGAGENTDIR），在 POSIX 上使用 0600 模式编写。 CI / 临时替代方案： 设置 QUERITAPIKEY 环境变量。当两者都存在时，环境变量优先。 切勿将密钥放入聊天或日志中：扩展程序会屏蔽密钥输入并从每个错误表面编辑密钥。

请参阅 pi-querit README 以获取完整的工具参考。 dsh-querit — DeepSeek Harness

安装命令

dsh plugin --profile web add github:querit-ai/querit-plugins
