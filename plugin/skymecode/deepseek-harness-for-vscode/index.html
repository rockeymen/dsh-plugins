项目简介

1. 打开要开发的代码项目。 2. 在 VS Code 用户 settings.json 中配置 DeepSeek API Key：

也可以运行命令 DeepSeek Harness: 设置 API Key，扩展会写入同一个用户设置。

3. 点击 Activity Bar 中的 DeepSeek Harness 图标。 4. 在输入框描述任务并发送。

安装命令

dsh plugin --profile web add github:skymecode/deepseek-harness-for-vscode
