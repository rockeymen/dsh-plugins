项目简介

Leppy Loop 是一个本机外部 Cordis 捆绑包，它为每个工作线程执行一个跟踪的 Markdown 检查表，其中包含新的 DeepSeek Harness 进程和会话。控制器拥有 Git 同步、工作树、清单转换、关闭、门、持久恢复状态和进程租用。工作人员仅收到当前行、其 Done: 合约、允许的路径、适用的存储库指令和明确的禁止。

创建一个跟踪清单，例如 examples/feature.task.md，提交它，启动一个 Web 会话，其工作空间就是干净的签出，然后调用不带参数的命令：

该命令对 AI 轮流进行排队，检查对话和存储库，解析预期的跟踪清单和权威 Git 库，并调用私有 leppyloopstart 工具。如果目标确实不明确，人工智能会提出一个简洁的问题，而不是猜测。命令后的自然语言作为意图转发，而不是解析为 CLI 参数，例如 /leppy-loop continue the checklist from this conversation。

安装命令

dsh plugin --profile web add github:aleleppy/leppy-loop-deepseek
