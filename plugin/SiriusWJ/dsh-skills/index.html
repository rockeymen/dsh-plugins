项目简介

Personal skill collection for DeepSeek Harness (dsh). Each skill is a directory containing a SKILL.md (YAML frontmatter: name + description), drop into $DSHHOME/skills/ to load locally. Skills Skill · 说明 Skill: dsh-plugin-npm-publish · 说明: DSH 插件开发与发布（本地插件 → npm + GitHub + 市场可发现）：包结构、宿主/客户端 API、defineTool schema DSL、会话级 tools.restrict、npm 自动发布 pipeline、踩坑清单 本地加载

技能会被 dsh 的 skill-filesystem watcher 实时发现（无需重启）。

安装命令

dsh plugin --profile web add github:SiriusWJ/dsh-skills
