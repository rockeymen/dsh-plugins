项目简介

如果 Side Chat 能让你的主任务保持专注，欢迎点一个 ⭐；这会帮助更多 DSH 用户发现它。 为什么需要 Side Chat？

如果你直接从 DeepSeek Harness 源码仓库运行 CLI，可使用仓库脚本： 使用方法

1. 在普通父会话中至少完成一轮对话。 2. 点击会话标题栏中的 Side Chat / 侧边对话，或按 Cmd/Ctrl + Shift + .。 3. 输入一个聚焦的临时问题。输入框会立即可用，父会话已完成上下文在后台静默准备；立刻发送的消息会被立即接收，但第一条回复可能稍慢。侧边智能体可以读取继承的上下文和只读资源；面板或窗口尺寸变化时，抽屉会在不重新挂载的情况下调整位置。 4. 可以自由切换任务：抽屉会按父会话停放，返回时自动恢复原来的对话记录。 5. 通过收起、Escape、原生标签页关闭、标题栏按钮或 Cmd/Ctrl + Shift + . 隐藏 Side Chat 时，对话记录和草稿都会保留。真正结束时，使用内部 结束 操作并确认。

安装命令

dsh plugin --profile web add github:Lukeknow0/dsh-side-chat
