项目简介

Markdown · 开源 · 多 Agent · MCP 与 CLI Flowix 让笔记成为持续工作的记忆

用 Markdown 记录内容，把需要的上下文交给 Agent，再将结果写回同一篇笔记，方便检查、修改和下次继续使用。 让工作持续推进

把产品、开发、研究和个人知识放在一起，让 Agent 不必每次从头开始。 场景 · 说明 场景: 产品工作 · 说明: 集中管理需求、反馈和决策，让产品文档保持最新。 场景: 软件开发 · 说明: 保存项目背景和约束，让编码 Agent 接着推进。 场景: 课题研究 · 说明: 将资料、分析和结论放在一起，方便追溯和复用。 场景: 个人知识 · 说明: 让笔记、计划和个人偏好成为 Agent 可用的上下文。 让不同 Agent 使用同一份记忆

安装命令

dsh plugin --profile web add github:text2future/flowix
