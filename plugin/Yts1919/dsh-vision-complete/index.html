命令行方式（可选，路径换成你自己的实际位置）： 第 3 步：配置 API Key（必做，否则云端模型用不了）

1. 随便找一张图片（或按 Win+Shift+S 截一张），拖进 DeepSeek 聊天框。 2. 对它说「描述这张图」。 3. ✅ 能返回图片内容 = 装好了，开始用吧。 4. ❌ 报「没有 API Key / 401」→ 回第 3 步：确认 DASHSCOPEAPIKEY 已设置，并完全退出重开 Harness。 5. ❌ 报「没有 mcpqwen-mm-plugins- 工具」→ 看下面「常见问题」第二条。 💡 兜底办法：如果实在配不好环境变量，直接把 API Key 整段粘贴发给 DeepSeek 也行（例：「这是我的 key：sk-xxx，接下来看图都用它」）。它会在本次对话里直接用这个 key 看图。注意这只是临时方案，重启后仍建议按第 3 步配好，这样每次都能自动生效。 二、怎么用
