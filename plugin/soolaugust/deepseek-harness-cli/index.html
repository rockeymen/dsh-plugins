项目简介

dsh cli 是一个交互式终端 agent，fork 自 DeepSeek Harness 并聚焦于 CLI 使用：在终端里获得像 Claude Code 那样的编码体验——全屏 UI、流式输出、工具卡、会话历史、权限控制，而无需浏览器。

首次启动会创建/恢复一个会话；输入文字回车发送，模型输出流式渲染在输入框上方。 使用 操作 · 效果 操作: 输入文字 + Enter · 效果: 发送给 agent 操作: ↑ / ↓ · 效果: 历史导航（跨会话持久） 操作: Shift+Tab · 效果: 循环权限 preset 操作: Ctrl+O · 效果: 展开/收起工具组 操作: Ctrl+C · 效果: 运行中取消当前回合；提示符下退出 操作: /exit /help /clear /session /model /permission · 效果: slash 命令

通过 /.dsh/settings.yaml 指向任意 OpenAI 兼容端点（如 mify、OpenRouter），模型路由和 websearch 均可配置。详见 CLI 指南 · 使用自定义模型提供方。 开发 继承自 DeepSeek Harness

安装命令

dsh plugin --profile web add github:soolaugust/deepseek-harness-cli
