项目简介

⚡ dsh-overdrive DSH 界的 OpenClaw：把 DeepSeek Harness 变成"看得见思考过程、可以随时指挥"的聊天智能体。 English | 中文

dsh-overdrive 是 Hermes Agent / OpenClaw 的多平台平替，但基于 DeepSeek Harness —— 桥接进 WhatsApp · Telegram · Discord · Slack · 飞书 · 钉钉 · 企业微信 —— 做到了它们做不到的事：每一步思考和工具调用都在聊天里可见，危险操作永远等你点头。 为什么不用 OpenClaw？

Hermes / OpenClaw 是"终端智能体 + 20 多个聊天频道"，但它是黑盒——你只看到答案，看不到过程。
