项目简介

这是 DeepSeek Harness 的原生本地项目任务板插件。SQLite 是任务共享状态的唯一权威；Agent Session、Goal、Workspace、工具、权限和对话历史仍由 Harness 管理。

Agent 只能把已验证工作提交到 inreview；只有经过认证的用户 UI/CLI 操作才能验收为 done。

以本仓库 package.json 为准（撰写时为 0.1.0）。pnpm pack 之后使用实际生成的 tarball。

安装命令

dsh plugin --profile web add github:shengsheng90/DSH-taskboard
