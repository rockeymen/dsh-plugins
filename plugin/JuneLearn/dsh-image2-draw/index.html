项目简介

你是否在 DeepSeek Harness 中遇到无法生成图片的问题？本插件为 DeepSeek Harness 增加 Image2 生图能力，可以通过第三方中转提供的 OpenAI Images 兼容接口调用 gpt-image-2。配置很简单，只需填写 baseURL 和 API Key，即可在对话中使用 文生图和图生图工具。
