项目简介

本地开发要求 Node.js 24 或更高版本。当前项目使用 DSH 0.1.0-rc.6。

右侧“结果与证据”直接读取当前绑定 DSH Session 的 session.history。用户消息、请求上下文、模型输出、工具调用、工具结果、权限变化和最终回答都在同一条可回放轨迹中，不维护第二套运行中心。 对话和工作台

Canvas 保存不可变版本，支持正文编辑、版本比较、精确行内建议和冲突处理。Site 使用同一套版本能力，并在隔离沙箱中提供桌面、平板和手机预览。 Git Worktree 隔离开发

dsh plugin --profile web add github:vibeinging/deepseek-harness-desktop-app
