项目简介

DeepSeek Harness 持久插件：支持拖拽 / 点击上传非图片文件（PDF / Word / Excel / ZIP / 文本等），把文件路径直接写入输入框草稿，agent 即可读取。 工作方式（三个入口共用一套逻辑） 入口 · 行为 入口: 拖拽到窗口任意位置 · 行为: 全屏高亮浮层 → 松手 → 获取文件 入口: 回形针按钮（输入框工具行左侧，28px 圆形原生风格） · 行为: 点击弹系统文件选择器（多选） 入口: hover 气泡 · 行为: 「点击选择文件 · 也可把文件拖到窗口任意位置」，1.5s 自动消失，每次 hover 循环

1. 桌面壳直取原始路径（Electron 壳 window.dshDesktop，webUtils.getPathForFile）—— 零上传，拿到 Finder 里的真实路径； 2. 拖拽自带路径（text/uri-list，如 Obsidian 拖笔记）； 3. 上传兜底（浏览器/无壳时）—— POST /api/dsh-file-drop 保存到 /.dsh-drops/，返回工作区路径。

/dsh-desktop/：Electron 壳，npm start 启动。自动复用/拉起 dsh web（127.0.0.1:3080）， preload 注入 window.dshDesktop（getPathForFile + drainDroppedPaths），使拖拽直取 Finder 原始路径。 视觉引擎基准（modlens，2026-08 实测）

安装命令

dsh plugin --profile web add github:dannyvan/dsh-file-drop
