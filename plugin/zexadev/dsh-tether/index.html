项目简介

在手机上用你开发机里的 DeepSeek Harness。 跨网络,点对点直连,中间不经过任何服务器。 不用配中转,不用同一个 WiFi,不用在手机上装 Linux。

独立的社区开源项目,与深度求索不存在隶属、合作、授权或背书关系。本仓库无深度求索员工或 DeepSeek Harness 上游官方团队成员参与。中文 · English

DSH Tether 把 DeepSeek Harness 的 Web 界面通过点对点直连带到手机上。agent 依旧跑在你代码所在的那台电脑,手机拿到的是 DSH 自己的完整界面——会话、工具调用、审批、设置全都在,不是另做一套。用 6 位码配对一次,之后两端在哪个网络都能互相找到。 它解决什么 你不在电脑那个网络里,又不想中间有一台服务器。

安装命令

dsh plugin --profile web add github:zexadev/dsh-tether
