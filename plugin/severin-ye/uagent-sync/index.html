项目简介

你有不止一台机器。每台机器上的 opencode / Codex 都装着不同的插件、MCP 服务器、技能，子模块也停留在不同提交。手动同步是一场噩梦：git submodule update、npx skills add、复制粘贴配置文件…… uagent-sync 把它变成一条命令：

然后把它加进 opencode 配置（config/opencode.json）并重启： Codex 首次备份 改用源码？ git clone https://github.com/severin-ye/uagent-sync && cd uagent-sync && npm install && npm run build，之后用 node dist/cli.js 。 新设备？ 先 opencode-sync init --init-type sync --github-url ，再 opencode-sync pull。 Codex 支持

插件按以下顺序定位 CLI：cordis.yml config.cliPath → 环境变量 OPENCODESYNCUAGENTSYNCCLI → 本地 checkout 相对路径 → npm 依赖 uagent-sync/dist/cli.js → 工作区递归（向上找 .gitmodules 再找 uagent-sync/dist/cli.js）。详见 packages/dsh/README.md。

安装命令

dsh plugin --profile web add github:severin-ye/uagent-sync
