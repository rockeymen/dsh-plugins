项目简介

一个设置选项卡（“连接器”）可通过 DSH Web UI 管理两件事： MCP 服务器 — 编辑 cordis.patch.yml 中的 MCP 块（stdio/streamable-http）。旧版 SSE 服务器（例如知乎）保留为 mcp-remote --transport sse-only stdio 桥接器；该插件仅管理该配置文本。 用户技能 — /.dsh/skills/ /SKILL.md 下的读/写/删除技能。

最小 API 密钥回退：出现可重试请求错误（AUTH / 401 / key / rate / timeout → agent/request-error）时，默默地标记当前密钥冷却并一步使用下一个池密钥重试相同的请求。提供始终可见的设置部分 (settings.section → API Key 回退)，显示 分nek 按键计数/光标/冷却/健康（可见性门控轮询，无忙循环）。

在/.dsh/settings.yaml中配置： 工作原理： llm-pi-ai 提供程序（例如 ninerouter）通过凭证域进行身份验证 - 主机写入 ctx.credentials.set(env, key) 和 process.env[env]，因此重试实际上到达模型调用 和 UI settings.section + settings.plugin.item 卡显示 分nek 冷却/运行状况良好。旋转受到每回合限制（turn:step → ≤ keys.length 重试），并有每次失败 30 秒的冷却时间（最多 5 倍）。有关完整参考，请参阅 dsh-key-fallback/README.md；有关 ESM 捆绑模式，请参阅 dsh-vision-bridge 的 index.js。
