项目简介

DeepSeek Harness 的本地优先工具箱。 产品研究、上下文切换、插件预检和兼容性监控都集中在一个以安全为中心的可视化控制面板中。

DSH Toolbox 是 DeepSeek Harness 的配套产品，适用于个人、本地优先的工作流程。四个插件作为本机 DSH 配置文件包运行。 DSH Switchboard 在活动 Harness 进程之外运行，以检查配置文件、运行运行状况检查、预览捆绑包更改、创建备份以及安全回滚更改。

只读交换机检查无需 PATH 上的 DSH CLI 即可进行。默认情况下，应用或回滚更改需要 CLI，因为成功的 dsh --profile --dump-config 是运行时安全门。

安装命令

dsh plugin --profile web add github:HiWhaleW/dsh-toolbox
