项目简介

dsh-law · 深法工作台 DeepSeek Harness 的本地法律工作台插件。首页参考全国法院“一张网”的工作台逻辑，把待办提醒、月历排期、案件概览和最近动态放在同一屏；案件对话统一交给 DSH 原生会话，并自动使用用户预设的「法律模式」。零 npm 依赖，数据完全本机。

旧案件如果绑定的是空白标准模式会话，工作台会直接切换为法律模式；如果旧会话已经有对话，则保留原会话历史，自动新建并改绑一个法律模式会话。 独立运行（仅案件管理，可选）

路由：/api/dsh-lawbench/info（状态）、/api/dsh-lawbench/workbench/（同源镜像代理，SSE 透传）。同源 iframe 还通过 DSH 官方 session.、skill.list 与 commands/ 接口连接原生会话；全部带 loopback 护栏。

安装命令

dsh plugin --profile web add github:wesky820/dsh-law
