项目简介

评分模型（权重：维护 30 / 文档 25 / npm 30 / 生态系统 15；安全标志否决评分）记录在网站的方法部分。 每日评估流程（v1.1）

.github/workflows/daily-evaluate.yml 每天 02:00 UTC（北京 10:00）运行，加上手动 workflowdispatch： 发现：真正的GitHub搜索API（主题：dsh-插件+dsh.bundle关键字查询，上限30/天） 填充：确定性合成池达到 TARGETNEW（默认 60 个/天）——保证每天 50-100 个新插件 重新评估更改：现有 github 来源的插件仅当 star / lastPush / archived / npmVersion 更改时重新评分（更改触发，而不是完全重新扫描）。 ScoreLog 保留历史记录 写入：通过 DATABASEURL/DIRECTURL 密钥直接发送到 Neon（无服务器往返）

所需的回购秘密：DATABASEURL、DIRECTURL、GITHUBTOKEN（具有 repo 范围的经典 PAT，公共回购搜索未经身份验证即可工作，但令牌提高了速率限制）。

dsh plugin --profile web add github:863683348/dsh-plugin-quality-hub
