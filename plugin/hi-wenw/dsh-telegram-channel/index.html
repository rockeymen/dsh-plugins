项目简介

1. 电脑 dsh web 开着（会话列表与 Web 对齐，已归档除外） 2. 手机 Bot：/sessions → 工作区 → 会话 → 附着 3. 之后手机 ↔ Web 走同一条轨迹；可用 /model 切换模型（下一回合生效） 效果截图

电脑 Web 同步收到同一条消息与回复： 一键管理菜单（推荐） 先准备两样东西： 准备 · 怎么拿 准备: Bot Token · 怎么拿: Telegram 搜 @BotFather → /newbot → 复制 token 准备: 数字 User ID · 怎么拿: 搜 @userinfobot → Start → 复制纯数字 Token 不要发到公开群；泄露了去 BotFather /revoke。 Windows 请在 PowerShell 执行。若当前是 CMD，用下面「CMD 一键」那行。 脚本已兼容 irm | iex（菜单逻辑包在 scriptblock 里）。CMD 请用下面整行。 CMD 一键：

1. 菜单选 2 启动 dsh web（或自己运行 dsh web） 2. 浏览器里可看到工作区与会话（归档会话不会出现在手机列表） 3. 手机对 Bot：/start → /sessions → 选工作区 → 选会话 → 聊天 4. 需要换模型时：/model → 点选（与 Web 同 API，下一回合生效） 5. 续接上下文：附着后点 查看上次对话，或发 /last

安装命令

dsh plugin --profile web add github:hi-wenw/dsh-telegram-channel
