项目简介

浏览器打开后，右下角会出现默认宠物（尺寸 160px）。当前默认模型为 Hiyori（Live2D 官方示例模型），首次加载需联网。

自定义模型：打开设置 →「桌宠配置」→「我的模型」，填写名称与 .model3.json 地址（外网 CDN、自建静态站或本机 HTTP 服务均可）。比例与默认差较多时可展开「空间分区覆盖（可选）」按字段微调五矩形（头/身/腿居中列 + 左右臂；0–1，留空用默认）；建议配合开发者选项「显示点击分区」对照色块。内置 Hiyori 已带居中分区预设。 配置设置

安装命令

dsh plugin --profile web add github:cyanfish-x/dsh-live2d-pets
