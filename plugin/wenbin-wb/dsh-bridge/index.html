项目简介

1. Node.js ≥ 22 (DSH 要求 ^22.19.0 或 ≥ 24.0.0) 2. dsh CLI 可用 — 能在终端直接运行 dsh 命令

如果你刚发布后立即升级，add @latest 可能仍然装到旧版本。这是 pnpm 11 的供应链安全机制 minimumReleaseAge（默认过滤发布不足 24 小时的新版本）导致的，不是插件问题。 解决方法（任选其一）：

升级完成后重启 DSH，并在浏览器硬刷新（Windows: Ctrl+Shift+R，macOS: Cmd+Shift+R）清除缓存，然后确认设置页显示最新版本号。 使用 🔐 访问安全认证与后台防篡改（v2.5.0 重磅）
