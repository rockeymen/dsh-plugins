项目简介

1. 打开设置 → 插件排序器。 2. 在启用/禁用列之间拖动包。 3. 拖动已启用的包以更改加载顺序。 4. 单击包以获取详细信息和诊断信息。 5. 单击“保存草稿”保留您的编辑而不应用它们。 6. 单击 保存 将更改写入配置文件。 7. 手动重启DSH以使更改生效。 Loader Entries 部分显示底层 Cordis 加载器行： 活动条目列在左侧，禁用条目列在右侧。 受保护的架构条目呈灰色且无法切换。 单击条目可查看其 ID、名称、描述、版本和存储库。 发展

安装命令

dsh plugin --profile web add github:inks-knowledge/dsh-plugin-sorter
