项目简介

打开 Web UI 的“设置 → 模型高级配置”，即可新增端点或编辑现有 llm-pi-ai 模型配置。

如需固定版本，在仓库地址后附加 commit SHA，例如 github:MarvekG/deepseek-harness-model-config# 。 本地调试

安装命令

dsh plugin --profile web add github:MarvekG/deepseek-harness-model-config
