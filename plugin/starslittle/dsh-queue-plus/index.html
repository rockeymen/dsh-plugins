项目简介

预构建包（不用授权构建脚本）： 能做什么 和自带队列一样能改、删、插话 点「排序」后原地拖拽改执行顺序 一键清空，10 秒内可撤销 别人同时改了队列，这次操作会被拒绝，不会排乱 装完怎么验 现象 · 怎么办 现象: 排队两条后标题旁出现「排序」 · 怎么办: 已生效 现象: 没有「排序」 · 怎么办: 确认已重启，并选「排队发送」而不是马上发送 现象: 关掉或卸载后队列变回原样 · 怎么办: 正常 边界 撤销只在本机当前进程里有效，限时 10 秒 不管插话队列、上下文队列和子 agent 的队列 卸载后自带队列自动恢复

面向 @deepseek-ai/ 0.1.0-rc.6 的公开 Agent Inbox 与 Web 插件契约。DSH 仍在 RC，契约若改需要同步升级插件。 许可

安装命令

dsh plugin --profile web add github:starslittle/dsh-queue-plus
