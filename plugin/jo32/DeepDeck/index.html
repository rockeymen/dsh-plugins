项目简介

DeepDeck 是一款基于 DeepSeek Harness.上游项目作为浅层 Git 子模块固定在 vendor/deepseek-harness；该存储库拥有桌面生命周期、插件组成的界面、品牌、打包和自动更新层。 anywhere-labs/deepseek-harness-desktop 的社区市场固定在 plugins/community-market 下，而 dsh-codex-connect 仍然是单独的固定结账。两者都作为普通 Cordis 捆绑包进行预加载。

DeepDeck 重用了官方 web 配置文件及其完整的插件组成的 UI。桌面主机在操作系统分配的环回端口上启动 Harness 进程，等待其准备就绪，然后在应用程序窗口中打开本地 UI。关闭应用程序会彻底关闭 Harness 进程。

先决条件：Node.js ^22.19.0 或 >=24.0.0、Corepack 和 Git。

安装命令

dsh plugin --profile web add github:jo32/DeepDeck
