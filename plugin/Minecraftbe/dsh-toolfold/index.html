项目简介

装完重启 dsh 并刷新浏览器即可生效（bundle 层在启动时合成）。可用以下命令确认已进入 最终配置： 早期版本若曾在 cordis.patch.yml 手工加过 toolfold 行，先删除该行再切换，避免双挂载。 卸载

设置入口：设置 → 插件 → 工具折叠（卡片外观与内置插件卡片一致，跟随深浅主题）。 设置项 · 说明 设置项: 展开动画时长 · 说明: 展开/收起瀑布动画的单卡时长，0–1000ms，默认 240ms；0 为瞬时切换 设置项: 保留思考 · 说明: 已完成的思考默认隐藏；开启后思考保留——分隔模式下显示在两条折叠条之间，合并模式下展开时按原顺序插回调用之间 设置项: 思考分隔调用组 · 说明: 开启（默认）：已完成的思考把前后两组工具调用隔开、各自独立折叠；关闭：思考并入所在工具组一起折叠（旧行为） 设置项: 性能统计 · 说明: 在卡片内实时显示插件自身耗时（观察回调/引擎刷新/合并重算/安全重扫/摘要克隆的累计次数与 ms/s，以及被零开销短路忽略的流式批次），用于验证插件开销

安装命令

dsh plugin --profile web add github:Minecraftbe/dsh-toolfold
