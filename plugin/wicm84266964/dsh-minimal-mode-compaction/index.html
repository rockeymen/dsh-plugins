项目简介

为 DeepSeek Harness 的极简风格 agent 增加长会话所需的三种压缩路径： compaction-basic 的 token 压力自动压缩和上下文溢出恢复； 人工 /compact； 模型在任务中调用 compactnow，由插件排队到当前回合结束后执行。

本项目不复制官方压缩引擎。它只提供一个用户 preset 和一个调度工具，底层复用 DSH 自带的 dsh-compaction-basic、dsh-command-compact 和 dsh-compaction-tool-result-pruner。

它还注册一个 /context 命令：直接输入 /context 显示当前有效上下文窗口，输入 /context 256k、/context 1m 或纯 token 数值时写入 DeepSeek 模型设置。命令写入的是 DSH 原生 llm-deepseek 设置，后续请求实时使用新容量；自动压缩仍按 preset 的阈值比例计算。 和现有项目的区别

安装命令

dsh plugin --profile web add github:wicm84266964/dsh-minimal-mode-compaction
