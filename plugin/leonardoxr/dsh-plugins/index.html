项目简介

插件是带有可选主机和客户端部分的 Cordis 模块。包清单声明了 DSH 捆绑补丁和客户端注入元数据。主机代码必须使用公共DSH服务/路由；客户端代码必须使用注入的服务并且必须干净地卸载。

对于更好的侧边栏集成，请参阅dsh-better-sidebar/AGENTS.md。关键规则：使用 inject = ['betterSidebar']，通过 ctx.betterSidebar 注册选项卡/查看器，在 ctx.effect() 中包装注册，以便处理程序是 HMR 安全的，使用包前缀 ID，并将 dsh-better-sidebar 保留为可选的对等依赖项。该服务仅存在于客户端。 本地开发

安装命令

dsh plugin --profile web add github:leonardoxr/dsh-plugins
