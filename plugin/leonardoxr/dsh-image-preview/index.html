项目简介

该插件使用 DSH 的公共会话范围 tool.call.toolview 插槽。由于官方工具树通过同一槽分派嵌套子调用，因此一个渲染器涵盖了两者： 直接拨打readimage；和 tools.readimage(...) 调用嵌套在 runcode 代码模式中。

每个加载的预览都包括复制图像以及可见的成功或失败反馈。支持时直接复制PNG字节；必要时，其他可接受的格式会在浏览器中转换为 PNG。 安全性和生命周期 字节仅通过 ctx.sessions.binding(sessionId).session.readAttachment(attachmentId) 获取。 模型提供的文件路径仅是显示/导航元数据，浏览器插件永远不会重新读取。 仅呈现经过身份验证的 PNG、JPEG、WebP 和 GIF 附件响应。 Blob URL 在替换、重试、卸载和 HMR 处置时被撤销。 剪贴板副本使用相同的经过身份验证的附件 blob；有界浏览器内转换永远不会重新读取模型提供的路径或添加网络回退。 格式错误/遗留结果和附件 RPC 失败会降级为有界内联错误，没有文件系统或网络回退。 设置

该插件在 DSH 设置 → 插件下提供了一张 图像预览 卡，其中包含两个实时、持久的选项： 启用内联预览 — 禁用它会删除自定义渲染器并恢复 DSH 的通用工具行。 自动打开预览 — 禁用后，每个图像开始折叠并仅在单击 显示预览 后加载。 发展

安装命令

dsh plugin --profile web add github:leonardoxr/dsh-image-preview
