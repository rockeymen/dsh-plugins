项目简介

主机或捆绑补丁更改后重新启动 Web 配置文件，然后刷新现有 DSH 网页。对于仅浏览器开发，运行 npm run watch:client；当活动 Web 运行时启用其 HMR 链时，DSH 客户端 HMR 可以重新挂载重建的捆绑包。 它是如何组成的

捆绑的 cordis.patch.yml 仅禁用基本 session-title-llm 行并插入此插件。它故意启用核心 session-title 服务。 DSH 一次支持一个异步标题提供程序，因此启用两个提供程序行会发生错误。

自动生成使用第一条符合条件的人工消息。单击“重新生成标题”显式调用相同的持久服务，并使用最多配置的最近人工消息数量。手动重命名继续固定标题；显式再生故意取消固定并替换它。 设置

安装命令

dsh plugin --profile web add github:leonardoxr/dsh-auto-chat-titles
