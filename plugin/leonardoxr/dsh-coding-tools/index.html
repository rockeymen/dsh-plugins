项目简介

一个 DeepSeek Harness 主机插件，带有范围狭窄的设置卡，可在不修改 DSH 的情况下添加紧凑的、有界的编码工具： coderead — 具有精确字节版本标记的 UTF-8 代码窗口 editranges — 具有操作员可配置批准的原子、观察范围编辑 astgrep — 将 ast-grep CLI 固定在一个提供程序读取文件快照上，具有分页和只读进程限制 lsp — 使用有界 JSON-RPC 的持久只读语言服务器查询 当匹配的 LSP 服务器已处于活动状态时，插件拥有的编辑后的新诊断摘要

该包提供 cordis.patch.yml，它插入包前缀行 dsh-coding-tools。主机插件更改后重新启动 Web 配置文件。原始源补丁本身并不是包注册。

可扩展的编码工具卡出现在设置→插件→插件配置中。它为 coderead、editranges、astgrep 和 lsp 提供开关，以及单独的 需要编辑批准 和 需要流程启动批准 控件。批准提示默认开启。高级限制和语言服务器计划仍然是配置文件配置。保存的设置保留在 DSH 的用户层中并实时应用：禁用的工具将被取消注册，启用的工具将被注册，并且进程支持的资源将被停止或重新创建，而无需重新启动 DSH Web。重新配置会取消正在进行的读取和查询，排出可能已提交的编辑，并使现有游标和 coderead 版本令牌无效。

安装命令

dsh plugin --profile web add github:leonardoxr/dsh-coding-tools
