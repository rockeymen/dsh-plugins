项目简介

⏱️ dsh-automation 让 Coding 任务按计划在全新 Agent Session 中运行，并随时管理定时任务。

🕒 想让重复或单次 Coding 任务稍后运行，又不依赖一段旧对话？ 🧭 想让每次无人值守运行都守在明确的工作区与权限边界内？ 🧾 想随时查清运行了什么、使用哪个 revision、最终如何结束？ ✨ dsh-automation 把三项要求收进同一条工作流。

用户和 Agent 都可以在 DSH 中创建、管理、暂停、恢复和查看定时任务；每个真正 dispatch 的 occurrence 都会在全新 root Agent 与 Session 中启动，并留下可审计记录。 完整任务 + 运行计划 + 权限边界 → 全新 root Agent + 全新 Session + 持久运行历史

安装命令

dsh plugin --profile web add github:titanwings/dsh-automation
