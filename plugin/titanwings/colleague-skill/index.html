项目简介

🧬 dot-skill（同事.skill） "你们搞大模型的都是码圣！血肉苦弱！赛博飞升！"

🧑‍💼 你的同事跳槽、导师毕业、搭档转岗，带走了整套工作方法和上下文？ 💞 你的家人、老友、伴侣渐行渐远，你想留住和 TA 相处的方式？ 🌟 你喜欢的作家、偶像、思想家你够不着，但你想听他对你的问题怎么看？ ✨ 这些，dot-skill 都能解决。

从 colleague.skill 升级成 dot-skill —— 不止同事，任何人都能蒸馏成 Skill

安装命令

dsh plugin --profile web add github:titanwings/colleague-skill
