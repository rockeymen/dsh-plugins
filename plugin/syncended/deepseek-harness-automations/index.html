项目简介

该表单将常见设置分为 任务、计划 和 代理和访问。作业 ID、超时、重叠和失火仍可在折叠的高级部分中找到。暂停的作业仍可以通过 立即运行 启动。 插件配置

默认值适用于本地 Web 配置文件。需要时覆盖配置文件的 cordis.patch.yml 中的捆绑行：

1. 调度程序声明发生并在相同原子状态突变中推进其持久 nextRunAt 水印。 2. 承认的运行固定完整的作业版本并获取唯一的出现键。 3. 重启后调度queued运行。 4. 在任何代理工作开始之前，运行标记为 running。 5. 重新启动时，孤立的 running 记录将变为 interrupted 并且不会自动重试，从而避免静默重复文件/网络影响。 6. 利用会话持久性仍然是代理记录的真实来源；自动化状态存储编排元数据和有界的最终文本摘要。

dsh plugin --profile web add github:syncended/deepseek-harness-automations
