项目简介

可以从示例清单开始。如果没有设置 UPSTREAMRADARCONFIG，插件会保持休眠，不发起轮询。

启动后，Radar 会轮询 OSV 与 npm，先把事件状态持久化，再把有变化的事件交给第一个在线的根 DSH Agent。 在真实 DSH 中运行证明

运行 pnpm run try:dsh:live，可以在 DSH 投递前加入一次当前 OSV 与 npm 数据轮询。 闭环如何工作

安装命令

dsh plugin --profile web add github:MicroMilo/upstream-radar
