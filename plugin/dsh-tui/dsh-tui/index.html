项目简介

需要 Node ^22.19 || >=24 和 dsh CLI（npm i -g @deepseek-ai/dsh@next）。

1. 环境变量：DEEPSEEKBASEURL=http://localhost:8000/v1 搭配 DEEPSEEKAPIKEY。 2. 设置文件（热加载）：$DSHHOME/settings.yaml

3. OpenAI 兼容网关（vLLM、SGLang 等）：在 profile 补丁（$DSHHOME/profiles/tui/cordis.patch.yml）里声明一个 llm-pi-ai 路由并把默认模型指过去——参见 dsh 的 providers 指南。 开发

安装命令

dsh plugin --profile web add github:dsh-tui/dsh-tui
