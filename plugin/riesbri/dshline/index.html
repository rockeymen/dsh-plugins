项目简介

利用插件发布功能； dshline 在终端中呈现本机支持的功能。它在进程内运行并使用 Harness 合约，而不是创建单独的提供程序运行时、状态存储或策略。

Harness 拥有功能、状态、运行时、持久性和策略。 dshline拥有终端演示。 通用能力集成

dshline 通过标准 Harness 功能而不是提供商特定的代码进行集成。工作消耗ctx.jobs和ctx.subagents；会话使用ctx.sessionQuery； /connect 使用 Harness 的模型、设置、凭证和授权服务； /plugins通过ctx.agentPresets读取并切换运行代理的组成。因此，新的提供程序可以流经现有接口，而不需要专用的 dshline 实现。

安装命令

dsh plugin --profile web add github:riesbri/dshline
