项目简介

dsh-assistant-optimization 一个面向 DSH web profile 的插件：让模型输出更好读，让你的 prompt 更好写。 English 功能

四项能力，开箱即用。官方渲染从不被替换——插件遮蔽 DSH 组件后把渲染委托回去，所以 Markdown、工具卡片、图片、表格的行为与原版完全一致。 · 能力 · 做什么 💭 · 能力: 推理折叠 · 做什么: 把误渲染进正文的推理过程折叠进原生 "Think" 区块 📊 · 能力: Mermaid 图表 · 做什么: 把 mermaid 代码块渲染成可交互 SVG（缩放 / 拖拽 / 触摸） ✎ · 能力: 编辑 Diff 数值 · 做什么: 在折叠态 Write、Edit 行上显示 +10/-2，无需展开 ✨ · 能力: Prompt 增强 · 做什么: 一键把粗糙草稿改写成更清晰的指令 🛰️ · 能力: 语义搜索 · 做什么: contextsearch：用模糊描述定位代码（Windsurf 驱动） 推理折叠
