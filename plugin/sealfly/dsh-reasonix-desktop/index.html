项目简介

Reasonix v1.29.0 前端的 Wails 外壳，桥接到 DSH 后端（127.0.0.1:3080）。 为什么从 Electron 迁到 Wails

Reasonix 前端是为 Wails 写的（依赖 window.go.main.App + window.runtime + --wails-draggable 原生拖拽）。之前的 Electron 桥把 --wails-draggable 映射成 -webkit-app-region: drag，触发了 Chromium 的合成层行为，导致布局热切换时侧栏 logo 叠影（旧帧残留）。Wails 的拖拽是原生层的，不经过渲染合成，根除叠影。 项目结构 构建 & 运行 验证清单（迁移核心目标）

安装命令

dsh plugin --profile web add github:sealfly/dsh-reasonix-desktop
