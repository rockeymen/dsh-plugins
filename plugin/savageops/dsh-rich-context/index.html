项目简介

dsh-rich-context Agent manager for DeepSeek Harness — edit the AGENTS.md files your agents read, and define subagent personas: named roles with their own system prompt and a pinned provider / model / effort route, launchable as real sessions. 管理 AGENTS.md 与子代理人格：全局/工作区编辑、源扫描与默认切换；每个角色一个 Codex 风格 TOML（含 provider/model/effort 路由），编译为 DSH 预设、可从面板或模型的 agents 工具启动为真实会话。 Install
