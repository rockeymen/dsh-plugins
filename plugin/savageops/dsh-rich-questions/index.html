项目简介

Your agent doesn't just send a questionnaire — it composes one from the conversation's context: a directed graph of questions where each answer decides what gets asked next, every option carries its own reasoning, and the whole thing renders in the same composer seat you're already looking at. One tool call. No forms product, no account, no copy-paste. 富问题/问卷系统 — 由 agent 现场编写的分支问卷：每个答案决定下一题，每个选项自带洞察与流程图，直接在聊天输入框位置作答。

askuserquestion 非常适合 1-3 个简单问题，仅此而已。真正的工作——期望收集、验收标准、跨十几个交互维度确定构建范围——需要路径（一个答案会改变接下来重要的事情）、深度（单行标签不足以选择好）和速度（有时你已经知道目的地）。 asksurvey 就是这个系统，它保持简单的流程不变。 比较如何

在作曲家座位上渲染，实时分支路径上每页一个问题： 进度条+针对当前路径的已回答/总计； back 根据保存的答案重新评估分支 带复选框的多选、自由文本 other 行、每个问题 skippable 出血行语法：选项行从卡片的边缘到边缘运行，由 1 像素细线分隔线分割（无浮动芯片）；自由文本行有自己的分隔线，页脚是一个出血工具栏 - 操作按钮向右浮动，作为由垂直细线分隔的全高段，后退箭头和进度保持在左侧 每个操作按钮均由延迟工具提示解释 - 开始/下一步/提交（上下文）、跳过、银行、快速、重新滚动、推送、讨论、后退、最小化、取消 键盘可操作的行，带有咏叹调标记的控件； UI chrome 本地化（EN / 简体中文，在其他地方优雅地回退） 主机权威挂起状态、环回防护路由、SSE + 轮询补充 创作指南
