项目简介

dsh-plugin-mcp 适用于 DeepSeek Harness (dsh) 的通用模型上下文协议 (MCP) 桥接插件

dsh-plugin-mcp 是 DeepSeek Harness 的官方标准插件，可将您的 DeepSeek 代理无缝连接到 模型上下文协议 (MCP) 服务器的整个生态系统，并具有完整的 Claude Code 级功能奇偶校验。

请参阅我们完整的 ROADMAP.md，了解当前功能和即将到来的里程碑。 特点 🔌 通用 MCP 支持：在 stdio、sse 或 websocket 上运行任何 MCP 服务器。 🚀 10,000+ 服务器规模引擎：默认休眠进程池，具有 JIT 工作激活和 LRU 空闲进程收割机（即使有 10k 服务器，也保持 30k 字符）并将其存储为具有结构化预览的本地工件。 🛠️ 自动工具桥接：通过 JSON 架构验证将 MCP 工具动态注册到 DSH 工具注册表中。 📂 资源和提示桥：将 MCP 资源和提示模板直接公开到代理上下文中。 ⚡ 弹性执行：独立的服务器生命周期、每个服务器的超时控制和非阻塞错误处理。 🏷️ 干净的命名空间：自动工具名称前缀（githubcreateissue、postgresquery）以避免跨服务器的名称冲突。 🧩 Cordis Native：直接构建在 Cordis 生命周期挂钩（ctx.provide、ctx.on('ready')、ctx.on('dispose')）上。 ⚡ 1 行 Docker 快速入门

安装命令

dsh plugin --profile web add github:menotbobbybrown/dsh-plugin-mcp
