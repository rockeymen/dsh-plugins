项目简介

原生 Rapid-MLX 提供程序 DeepSeek Harness — 所以 dsh 从服务器获取其模型事实，而不是从您输入的内容中获取 settings.yaml。 状态：发布到 npm 作为 @raullenchai/dsh-provider。 在 Verified 上运行的端到端 dsh 在 M3 Ultra 上运行 dsh 0.1.0-rc.7； dsh 0.1.0-rc.8 与 API 兼容 — LlmAdapter 合约是字节相同的，唯一的变化是附加的——并且 在协议和单元测试级别根据 rc.8 重新验证适配器。 DSH 仍然是快速发展的开发者预览版，因此请将此视为跟踪 一个移动的目标，而不是一个冻结的兼容性承诺。 它对你有什么作用

DSH 已经可以通过其通用的方式与本地 Rapid-MLX 服务器通信 openai-completions 提供商。这条路线可行——但它一无所知 您的模型超出了您手写的范围：

需要Node ≥ 22.15（dsh导入Node的Zstd流API而不声明它） 以及正在运行的 Rapid-MLX 服务器。

安装命令

dsh plugin --profile web add github:raullenchai/rapid-mlx-dsh-provider
