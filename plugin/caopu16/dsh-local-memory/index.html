项目简介

DSH（DeepSeek Harness）本地跨会话记忆插件：捕获每轮对话摘要、注入最近几天记忆，并提供 memorysearch 工具按需检索全部历史记忆。

1. 在项目 nodemodules/@deepseek-ai/ 下创建 dsh-tools 和 dsh-llm 的本地软链（指向 /deepseek-harness 里的包），让独立项目也能解析 DSH 同款模块。 2. 修改 /.dsh/profiles/web/cordis.patch.yml，把 local-memory 插件路径指向 /dsh-local-memory/src/index.mjs。

返回结果按关键词/子串命中打分排序，包含日期文件、轮次标题和正文片段。 项目结构 测试 记忆文件格式

安装命令

dsh plugin --profile web add github:caopu16/dsh-local-memory
