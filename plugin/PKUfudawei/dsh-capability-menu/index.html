项目简介

为 DeepSeek Harness 提供统一的能力菜单管理 Tools 和 Skills 的暴露水平 (上下文占用大小) 和执行方式 海量tools/skills也不会塞满一次请求, 节省token和上下文 MCP 工具与 Skill 按 exposed/progressive/blocked 三级管理暴露程度和执行方式

服务端与前端两个包均已发布到 npm（@daweifu/capability-menu 与 @daweifu/capability-menu-web）：

Capability 是上位概念，Tool / Skill 是不同类型的 capability，不是「两种工具」： kind · 对 Agent 提供 · action · 备注 kind: tool · 对 Agent 提供: 执行一个动作（MCP 工具） · action: execute · 备注: 由 ctx.tools 索引 kind: skill · 对 Agent 提供: 某类任务的方法/流程/知识 · action: load · 备注: 由 ctx.skills 索引 execute / load 是 capability 对外声明的规范 action：tool 的 execute 在底层由 ctx.tools.execute 走完整工具管线执行；skill 的 load 加载方法/流程正文。当前版本（0.1.0）只有这两种 kind 与两种 action。

安装命令

dsh plugin --profile web add github:PKUfudawei/dsh-capability-menu
