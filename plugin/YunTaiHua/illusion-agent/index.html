项目简介

IllusionAgent 幻想与实用，于此交融。融合多个开源项目精华，构建统一智能代理。

IllusionAgent 是一款开源的 AI 智能体平台。它将多模型语言模型网关、 中英双语命令行、浏览器端 Web 界面与可扩展的插件生态融为一体， 在 Windows、macOS、Linux 之上皆能从容运行。

桌面版内置 Python 3.12 和 Node.js 20 运行时，详见桌面版文档。 基本使用 Print 模式说明

安装命令

dsh plugin --profile web add github:YunTaiHua/illusion-agent
