项目简介

一个DeepSeek Harness插件。 visualizer 工具在模型编写时将独立的 HTML 文档流式传输到聊天中，并在沙盒内联框架中进行实时预览 - Chart.js、外部 CDN 库，所有这些。没有任何东西触及工作区。

guideModules同时缩小两个导轨面。常设系统提示名册仅列出这些类型的单行代码，而 JIT 工具的参数枚举仅接受这些 id，因此在任何代码运行之前，禁用的类型会在参数边界处被拒绝。 guideTool: false跳过第二次工具注册；渲染工具和常设提示部分不受影响。未知的模块 ID 或空的 guideModules 插件加载失败。默认情况下，所有五种类型（chart、diagram、mockup、interactive、art）均处于打开状态。 它是如何工作的

该工具将 html 声明为其最后一个架构参数，因此记录的工具调用参数在模型流式传输时带有不断增长的文档前缀。该卡对该前缀进行解码，并使用透明画布在空源沙盒 iframe 内绘制实时预览；在调度时，最终的 DOM 会被协调，并且脚本会按照文档顺序运行一次。当文档流式传输时，一条苍白的品牌带以 3.6 秒的缓慢节奏沿对角线扫过整个画面（从左上到右下）。它是变换动画的，在减少运动的情况下被禁用。它使实时阶段一目了然，并在文档稳定后立即停止。

dsh plugin --profile web add github:abidhmuhsin/dsh-visualizer
