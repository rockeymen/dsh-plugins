项目简介

一套为 DeepSeek 模型专门调校的沉浸式角色扮演 Agent 预设：零工具、纯对话，系统提示词内置 DeepSeek 官方角色扮演适配指令与酒馆（SillyTavern）社区验证过的演出规则。 💬 社区交流

想一起交流角色扮演玩法、调教预设的小伙伴，欢迎加入我们的飞书交流群～(｡•̀ᴗ-)✧ 角色卡怎么写才带感、OOC 怎么调 各种预设/插件的使用心得和踩坑记录 DeepSeek 角色扮演的实测技巧（温度、注入指令、记忆库用法）

dsh 的 Agent 预设是文件系统型的：把本仓库放进 /.dsh/.agent-presets/roleplay/ 即可，dsh 即时识别、无需重启服务：

安装命令

dsh plugin --profile web add github:oliblue-evan/dsh-roleplay-preset
