项目简介

将数据库密码放入adapter.passwordEnv命名的环境变量中，然后启动DSH。密码值既不被插件配置接受，也不被工具返回。

配置的主体必须是只读的。捆绑的 KS 查询包包含列入白名单的元数据 SELECT 语句；原始行、免费 SQL、凭据、源写入和持久超集突变均超出此插件的工具范围。 PostgreSQL 仍然是有限制的 v0.16.0 试点，并且不会在这里作为主要的实时插件路径进行宣传。 高级工具曝光

默认情况下，所有六个工具都会公开。高级配置文件可以设置任何个人 根据 expose 至 false 条目；省略的条目保持启用状态。值必须是 布尔值、未知名称在加载时失败，并且禁用所有六个失败，因为 没有工具表面的捆绑包应被禁用或删除。参见 examples/intent-exposure.patch.yml。 高级外部运行时

安装命令

dsh plugin --profile web add github:JoFe2/kaleidosphere-dsh-plugin
