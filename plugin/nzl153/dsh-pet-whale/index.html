项目简介

DeepSeek Harness（DSH）Web 界面的桌宠插件：右下角一只官方轮廓版小鲸鱼，随 agent 状态实时切换动画。纯 DOM 实现、零 React 依赖、零运行时第三方依赖，WebAudio 合成音效无音频文件。

空闲 → 思考·深潜 → 工作·敲代码 → 完成·冒泡 → 报错，对话气泡随状态变化 在线预览

仓库内的 preview.html 即预览页源码，本地直接打开同样可以体验。 特性 能力 · 说明 能力: 状态机 · 说明: idle / think（深潜）/ working（游动 + 敲键盘 + 代码粒子）/ celebrate（跃起冒泡）/ error（发抖 + 尴尬黑线）/ disappointed（报错后短暂失落）/ wait（等待你的输入）；优先级 error > celebrate > think > working > idle 能力: 回合语义 · 说明: 回合进行中永不发呆：有工具 = working，无工具（文字流或内部推理）= think 深潜；工具密集期键盘动画粘滞 2.5s 能力: 交互 · 说明: 单击戳戳、双击 360° 翻滚、拖拽时眼睛变成动漫勾勾眼（> =0.1.0-rc.6（web profile）。
