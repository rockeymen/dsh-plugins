项目简介

dsh-chat-timeline 1:1 复刻 DeepSeek 官网右侧「对话导航栏」的 DeepSeek Harness (DSH) 插件——把 chat.deepseek.com 官方网页版的 ScrollNav 界面与交互原样带进你的 DSH Web 聊天界面。 非 DeepSeek 官方出品，与 DeepSeek 无任何关联。 预览 功能 常驻右侧导航轨——屏幕右侧细长竖轨，每条用户消息一个指示线，与官网折叠态一致 悬停展开——面板显示消息预览，随滚动实时高亮当前阅读位置（品牌蓝） 点击跳转——一键平滑滚动到对应消息，自动加载更早历史 自动隐藏——会话少于 2 条用户消息时自动消失 无障碍——ARIA 标签 + 遵循系统「减弱动态效果」设置 工作原理

1. 将插件复制到 $DSHHOME/profiles/web/plugins/dsh-chat-timeline/（$DSHHOME 通常是 /.dsh） 2. 在 profiles/web/package.json 添加依赖 "dsh-chat-timeline": "file:plugins/dsh-chat-timeline"，运行 pnpm install 3. 在 profiles/web/cordis.patch.yml 添加： 4. 重启 dsh web 并刷新浏览器 架构参考 布局/CSS：官网 ScrollNav 的 1:1 移植（提取自官方 main.css，以 dsct 前缀命名空间化） 插件架构：参考 asukasec/dsh-message-preview（MIT）

安装命令

dsh plugin --profile web add github:jjxjjjjiik-bot/dsh-chat-timeline
