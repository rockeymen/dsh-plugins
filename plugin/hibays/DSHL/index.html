项目简介

启动流水线第 2 步先并发探测全部工具并写日志（透明汇报），随后按下图装配。 第一原则：系统里已有的可用工具原样使用，绝不重装。

二进制位于 target/release/dshl（Windows 为 .exe）。首次构建会自动编译对应平台的 WebUI C 库（webui-rs 是 git 源码依赖，无需预编译库）。 门禁（fmt / clippy / test / JS 检查）

门禁逻辑只有一份：scripts/gate.sh（POSIX）/ scripts/gate.ps1（PowerShell）/ scripts/gate.bat（cmd 转发）。CI 与本地跑的是同一条命令：
