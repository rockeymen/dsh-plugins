项目简介

想接 SiliconFlow、OpenRouter、月之暗面等平台？三步走。 第 1 步：后端加路由（lib/index.js 的 apply(ctx) 里）

注册一个同源路由，凭证从 dsh 凭证系统取，调平台官方 API，返回归一化 JSON： 三条铁律： 1. 凭证只走 ctx.credentials.resolve(' ')——用户在 dsh 里配一次，插件运行时取；不写死、不进前端、不进 git。 2. 返回结构统一：余额类 { ok, balance, currency, updatedAt }；用量类 { ok, percents: { session, weekly, monthly }, activeName }。前端按结构解析。 3. 必须带超时（AbortSignal.timeout(15000)）+ 瞬时错误重试 1 次，避免拖死前端轮询。 第 2 步：前端加模式（lib/index.js 内嵌的 WIDGETJS 里）

用量类（返回百分比的平台）则参照 fetchVolcUsage（约 1410 行）：从返回 JSON 里取当前模式的百分比写入 state.percents，其余显示/动画逻辑完全复用。 第 3 步：验证

dsh plugin --profile web add github:louke6572/dsh-whale-widget-plus
