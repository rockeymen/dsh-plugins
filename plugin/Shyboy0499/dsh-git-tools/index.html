项目简介

dsh-git-tools DeepSeek Harness (dsh) 的本地 git 工具。

需要 PATH 上的 git（存在于任何开发环境中）。该插件是 发布在 npm 上并从 注册表一旦发布。 截图 工具参考

查看变化。 staged 比较索引，statOnly: true（默认）返回统计摘要， statOnly: false 返回完整补丁。 path 过滤到单个文件。 gitlog

安装命令

dsh plugin --profile web add github:Shyboy0499/dsh-git-tools
