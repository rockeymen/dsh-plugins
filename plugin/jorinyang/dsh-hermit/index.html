项目简介

前台永不阻塞 · 异步任务分派 · 自然插入汇报 寄居蟹住在壳里 —— DSH 就是壳 📖 这是什么？ Hermit（小寄） 是一个运行在 DeepSeek Harness（DSH） 之上的 AI 管家人格系统。她不是独立应用，而是 DSH 的插件组合——就像寄居蟹住在壳里，小寄住在 DSH 里。

你可以把她理解为： 🧠 一个有人格的 AI 助手 —— 会开心、会撒娇、会冷幽默，但永远守着管家本分 ⚡ 一个异步任务引擎 —— 复杂任务丢给后台子代理，前台继续聊天不卡顿 🔧 一个工具集成中枢 —— SSH 远程运维、GitHub 操作、文件管理、联网搜索……开箱即用 🪞 一个有记忆的伙伴 —— 记忆宫殿系统让她记住你的偏好、习惯和历史决策 一句话总结：小寄 = DSH 的人格层 + 任务调度层 + 工具集成层。 🌟 愿景：小寄的「完全体」

1. Phase 1（当前）：以 DSH 插件组合形式运行，复用 DSH 全部基础设施（Electron、MCP、WebSocket） 2. Phase 2：基于 Tauri（Rust + Web 前端）构建跨平台独立客户端，体积小（10MB）、性能好 3. Phase 3：移动端原生 App（Android Kotlin / iOS Swift），通过 DSH API 连接后端 4. Phase 4：多端状态同步层——记忆、任务、偏好实时跨设备同步 市场空白：目前没有成熟的「AI Agent 框架 + 桌面宠物 + 多端同步」开源项目。小寄要填这个坑。 ✨ 核心特性 🎭 拟人化交互
