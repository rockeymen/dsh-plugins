项目简介

TypeScript monorepo 源码（提取自 deepseek-ai/deepseek-harness）保存在 archive/monorepo-src 分支。 模型牌价

lib/client.js 中的 MODELPRICING（以及 lib/index.js 的回退表）保存当前 DeepSeek 牌价；面板打开时会先请求 GET /api/billing/pricing，优先采用官方定价页数据，不可达时静默回退内置表。
