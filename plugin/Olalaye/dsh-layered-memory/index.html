模型会对应调用 memoryremember / memoryrecall / memorycommit 完成操作。（注：删除/清空请使用 UI 或 RPC，模型工具暂不提供删除入口。） 3. 管理 UI（设置 → 记忆管理）

点击侧边栏底部「设置」，在左侧导航选择「记忆管理」： 功能 · 操作 功能: 查看记忆 · 操作: 顶部四个标签：语义记忆 / 情景记忆 / 瞬时记忆 / 全部，按分类与时间排序 功能: 统计 · 操作: 顶部徽章显示各层条数；存储路径悬停可见 功能: 检索 · 操作: 搜索框输入关键词回车，显示匹配结果与匹配度百分比；清空后回车恢复列表 功能: 编辑 · 操作: 每条记录右下「编辑」→ 修改文本/分类/重要度 → 「保存」 功能: 删除 · 操作: 「删除」→ 2.5 秒内再次点击「确认删除」 功能: 清空 · 操作: 顶部「清空本层/清空全部」→ 再次点击确认 功能: 手动新增 · 操作: 「+ 手动添加记忆」→ 选择层级/分类/重要度 → 输入内容 → 「添加记忆」 4. 数据文件管理
