项目简介

dsh-soup DeepSeek Harness 本身是一大锅汤——营养丰富，但尝起来略显寡淡，不太好喝。dsh-soup 给它加上点 UI 调料，让它变得美味起来。 为什么叫 soup

DSH（DeepSeek Harness）功能很强：会话、工具、轨迹、Goal 一应俱全，营养都在汤里。但 UI 上略显寡淡——文件散在终端里、预览要跳出去、模型在跑你却看不到速度、长一点的目标被截成一行省略号。 dsh-soup 不重写 DSH，而是像下厨一样给这锅汤加几样调料： 🧅 葱 —— 右侧文件树，提鲜点缀，让项目结构在会话旁长出来； 🫚 姜 —— 会话内「预览」tab，去腥增香，Markdown / 代码 / 图片 / PDF / Notebook 就地看； 🧄 蒜 —— 多行 GoalBar，味重提味，把那条总被截断的目标条熬成完整一行行； 🧂 盐 —— 输入框上方的实时 t/s 速率徽标，百味之首，虽小却提味，实时知道模型跑得多快。

四样调料，一个插件，三平台通用（macOS / Linux / Windows）。装上之后——DSH 还是那锅汤，只是变得美味了。 速览 调料 · 是什么 · 一句话 调料: 🧅 右侧文件树 · 是什么: 和左侧工作区并列的右列文件浏览器 · 一句话: 提鲜点缀，结构在旁长出来 调料: 🫚 会话内预览 · 是什么: 会话区顶部新增「预览」标签页 · 一句话: 去腥增香，内容就地入味 调料: 🧄 多行 GoalBar · 是什么: 不再被截断的多行目标条 · 一句话: 味重提味，目标完整入味 调料: 🧂 速率徽标 · 是什么: 输入框上方的彩色 t/s 指示 · 一句话: 百味之首，小而提味 它能给你什么 🧅 右侧文件树（主打 · 葱 · 提鲜点缀）
