项目简介

Superdesign：Claude Code、Cursor以及任何编码代理的设计技巧 停止交付 AI-slop UI。 编码代理编写出色的代码和平庸的界面：通用布局，默认的 shadcn 一切，没有品味。超级设计是赋予你的代理设计判断力的技能，因此它提供的 UI 看起来实际上是经过深思熟虑的。

该技能处理剩下的事情：它读取您的代码以获取上下文，收集真实的样式参考，并生成您可以分支和完善的设计草稿。 核心场景（该技能处理什么）

1. 帮我设计X（功能/页面/流程） 2. 设定设计系统 3. 帮我改进X的设计（让它看起来不像AI生成的） 工具概述 A) 灵感和风格工具（通用，始终可用）
