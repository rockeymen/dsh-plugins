项目简介

适合二次开发：改动客户端代码后刷新页面 / HMR 即可生效；bundle/Loader 层改动需重启 dsh web。

刷新页面后，任意发起一个任务：状态栏文案立即变为幽默文案，且每 30 秒随机切换。 ⚙️ 配置说明

安装命令

dsh plugin --profile web add github:Ycet/dsh-fun-turn-status
