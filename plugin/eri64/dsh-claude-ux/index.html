项目简介

Claude 式「区域风控 + 自主结束对话」插件 —— 适用于 DeepSeek Harness 的 web profile。

blacklist / cnTimezones / 词表 / minSignals / showAttempts / promptEnforcement / ipCheck / blockOnUnknown / abuse.llm.enabled 需改 patch 后重启（provider/model/timeout 已可设置页改）。 隐私

默认配置下（ipCheck: false、webRtcCheck: false）插件不与任何外部服务通信：所有检测（时区、语言、代理、黑名单、浏览器语言/字体）都在本机完成，不上报任何遥测。完整的数据流向与暴露点分析见 docs/PRIVACY.md。 开发

安装命令

dsh plugin --profile web add github:eri64/dsh-claude-ux
