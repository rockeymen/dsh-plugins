项目简介

dsh-file-panel-left DSH Web 的「纯文件工作台」侧边栏插件 —— 文件资源管理器、编辑器与预览器一体，左树右内容，文件浏览、编辑、引用与对话联动在一个面板里完成。

在 profile 的 cordis.patch.yml 中手动挂载（与 CLI 自动挂载二选一，不要重复）：

安装命令

dsh plugin --profile web add github:ssjob123/dsh-file-panel-left
