项目简介

DeepSeek Harness Web GUI （dsh web）的 Catppuccin 主题插件。

它内置 Catppuccin 的四个主题——Latte、Frappé、Macchiato、Mocha—— 把整个界面的配色都换成对应的 Catppuccin 色板；并在 设置 → 常规 → 外观 下方提供一行 Catppuccin 快捷切换，选择会自动保存、下次启动自动恢复。
