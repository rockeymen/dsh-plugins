项目简介

半自动、全自动两种模式，躲开大模型的高峰时段和峰顶价格。DeepSeek Harness 必备插件。

lowtide 是 DeepSeek Harness (dsh) 的一个插件。它解决的问题很朴素也非常自然：

通常，你想让 Agent 干活的时候，就得坐在电脑前向它发送指令，等待回复，然后人工审核。但这种工作方式似乎忘了：你有大把的空闲时间，也有避开某些模型峰谷定价的机会。

安装命令

dsh plugin --profile web add github:KelaoHu/dsh-lowtide
