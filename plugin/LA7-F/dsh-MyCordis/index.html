项目简介

复用 Harness 的 webServer / dynamicCordisRunner / fs / shell 等服务，零外部依赖、零数据库；唯一持久化状态（收藏 / 常驻）以工作区文件 packer2-favorites.json 保存。启动后自动在 dsh Web 界面注入入口按钮，并提供独立页面。 预览版：

Cordis「便携包」目前可能只支持Windows端使用，后续考虑会去 Windows 依赖以变更为通用型工具 背景：

安装命令

dsh plugin --profile web add github:LA7-F/dsh-MyCordis
