项目简介

dsh-learning-bundle DeepSeek Harness 的非官方社区捆绑包。 DSH 的校样校正环。 将校正记录为 候选人，慎重采用，仅在正确的情况下回忆 配置文件/工作区/会话，并重建每个模型可见的交付 会话日志。

这是一个故意缩小的 Stage 0+1 版本。它不会自动生成 记忆，默默地激活它们，或者声称是一个通用的 RAG 系统。 60 秒的证明

相同的无头任务在 DSH 上通过真实插件运行两次 v0.1.1-rc.2： 手臂 · 学习项目 · 模型可见注入 · 最终响应 手臂：L− · 学习项目：候选 · 模型可见注射：0 · 最终响应：npm install 手臂：L+ · 学习项目：明确采用 · 模型可见注入：1 · 最终响应：pnpm install
