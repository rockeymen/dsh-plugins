项目简介

在 DSH（DeepSeek Harness）的 Web GUI 里，随时看得见 DeepSeek 的钱花在哪： 余额还能撑几天、今天花了多少、哪个模型最贵、缓存替你省了多少，以及 2026-08-17 峰谷定价之后账单会变成什么样。

装上之后 GUI 里多两样东西：右下角一个可拖动的悬浮额度窗，顶部栏多一个「额度」tab。 为什么需要它

用 DSH 跑 agent，钱是一点一点漏掉的，而 DSH 自己不会告诉你： 你真正想知道的 · 装之前 你真正想知道的: 余额还能用几天？ · 装之前: 只有一个余额数字 你真正想知道的: 今天花了多少？这个月呢？ · 装之前: 只有「累计」，没有时间感 你真正想知道的: 钱花在哪个模型上？ · 装之前: 不知道 你真正想知道的: 缓存到底帮我省了多少？ · 装之前: 完全看不到 你真正想知道的: 8-17 涨价后我的账单会变成多少？ · 装之前: 只能自己算

安装命令

dsh plugin --profile web add github:Cassius0924/dsh-usage-dashboard
