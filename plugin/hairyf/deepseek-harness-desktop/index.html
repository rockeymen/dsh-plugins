项目简介

在桌面上一键运行 DeepSeek Harness —— 无需 Node.js、无需 pnpm、无需 Docker，下载即用。

首次运行会下载 Node 运行时与 Harness 内核（合计约几百 MB），随后直接进入 http://127.0.0.1:3080 的 Harness 界面；此后完全本地运行，无需联网。 系统要求： Windows 10+（64 位）· macOS 10.15+ · Linux（AppImage）· 首次运行需要网络 开发与构建

需要 Node.js 20+、Rust 1.77+、pnpm 9+，以及平台编译工具链（MSVC + WebView2 / Xcode CLT / WebKit2GTK）。 工作原理

安装命令

dsh plugin --profile web add github:hairyf/deepseek-harness-desktop
