项目简介

在 DSH Web 的侧边栏底部添加「dsh 管理」入口。点击后打开浮动面板，列出本机 3080–3129 端口上的全部 dsh web 实例（端口 / PID / 状态），并可停止选定实例。

主机端在 webserver 上注册一个 JSON 路由 /dsh-easy-port-manager/api： 动作 · 说明 动作: action=list · 说明: 并发探测 3080–3129：先问 action=self（挂载了本面板的实例会自报 pid / 启动时间 / 活跃会话数），再回退页面标记探测 动作: action=self · 说明: 实例自报 { pid, port, startedAt, sessions } 动作: action=start · 说明: 在第一个空闲端口启动新的 dsh web 实例（detached + windowsHide） 动作: action=stop&port= · 说明: 目标是自己 → 延迟 300ms 走 appExit 优雅退出；否则转发 stop-self 给目标 动作: action=stop-all · 说明: 结束所有托管实例（远程转发 + 自身优雅退出） 动作: action=stop-self · 说明: 自身优雅退出

全程不启动 netstat/tasklist/powershell 等任何子进程，与挂载的 shell 执行器无关。 结构

安装命令

dsh plugin --profile web add github:xswt442-cmd/dsh-easy-port-manager
