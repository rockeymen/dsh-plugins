项目简介

也可以保留组合行，在 Harness 设置页的插件清单里禁用本插件。 工作原理 数据来源：Harness 的 tokenUsage / sessionStats 投影（provider 上报值）叠加插件对会话日志的增量折叠（request/header + assistant/message usage）。历史会话读取一次后缓存，增量更新仅读取上次水位线之后的新事件。 插件装载契约： package.json 声明 dsh.client.platform = "web" 及 inject 依赖，宿主扫描器据此生成 window.DSHBOOT 图行并挂载 /plugins//client.js 路由 浏览器半以模块表格式打包，工厂返回 { apply, inject }，服务依赖以导出的 inject 为准 UI 入口通过 ctx.slots.inject('shell.overlay', …) 注入为 root 作用域浮层 热更新边界：lib/client.js 内容变化刷新页面即生效；dsh.client 声明变化需要重启 dsh 开发 来源与版权

安装命令

dsh plugin --profile web add github:H1a3x/dsh-token-stats
