项目简介

1. 新会话，切到「DeepSeek + 长任务编排」模型组（或直接提出长任务，skill 自动触发） 2. longtaskbegin(goal) 初始化 → 按计划的子任务逐个执行 → codexscore 打分 → 迭代 3. 全部通过 → codexreview 终审 → 报告 注意事项 Codex 走 ChatGPT 订阅额度，与 Codex++ 共用登录态 → codex 调用已串行化，长任务期间尽量少用 Codex++ Codex 不可用时任务会暂停并提示，不会用 Kimi 顶替规划/评审

安装命令

dsh plugin --profile web add github:rocker2018-droid/dsh-longtask-orchestrator
