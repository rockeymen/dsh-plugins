项目简介

在 dsh web 会话页的 「记账」Tab（与「梦境」并排）展示 beancount 账本的月度快照： 本月收支总览、资产结构、支出分类占比、最近交易。只读——不在插件里记账，Fava 保留做深度分析。 工作原理

改代码后重启 web 生效：launchctl kickstart -k system/com.dsh.web

安装命令

dsh plugin --profile web add github:fatatalia/dsh-ledger
