项目简介

Codex Switch 一个小巧的 macOS 工具：一键把 Codex 在「官方 OpenAI」和「你自己的自定义 / 第三方 API」之间切换，切换后对话记录始终都在。

Codex Switch 把原本要手改 /.codex/auth.json 和 /.codex/config.toml 的事变成一次点击：官方 OpenAI 和你的自定义 provider 同时保留在配置里，切换只改「默认走哪一路」，不会重写已保存对话的 provider/model 归属。内置国内主流大模型快速预设，并能在本地启动适配器把只支持 Chat Completions 的接口桥接成 Codex 需要的 Responses 协议。 ⚠️ 不要在对话里让 Codex 自己改接入方式，容易改坏。切换请用本工具，稳定得多。 下载

从 GitHub Releases 下载 Codex-Switch-vX.Y.Z.dmg。

安装命令

dsh plugin --profile web add github:kuangre123/codex-switch
