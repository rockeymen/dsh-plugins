项目简介

卸载：dsh plugin --profile web remove dsh-api-gateway。 手动组合行（不用 CLI）

插件本质是普通 Cordis 行，也可手工编排。它发布跨会话共享的 HTTP 面，应挂宿主组合（或 profile 的补丁层）——绝不能放进 agent preset：

Windows PowerShell（零依赖、UTF-8 安全）： PowerShell 5.1 默认 ANSI/GBK 发中文会乱码：用上面的 UTF-8 字节写法（或声明 charset=utf-8）；PowerShell 7 默认 UTF-8 无此问题。服务端按 Content-Type 的 charset 解码（默认 UTF-8，兼容 GBK）。没有 jq？brew install jq，或用 Python/PowerShell 版。

安装命令

dsh plugin --profile web add github:litestartup-com/dsh-api-gateway
