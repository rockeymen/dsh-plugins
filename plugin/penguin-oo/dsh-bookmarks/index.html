项目简介

给 DeepSeek Harness（DSH）Web 界面加「回复收藏夹」：收藏任意一条已完成的 AI 回复（可加备注和标签），在统一的收藏中心里跨会话浏览、搜索、筛选，一键导出 Markdown。

然后重启 DSH（dsh web）。插件会自动加入 profile 的 bundle 层，无需其他配置。

bundle 行暴露三个可选上限： 键 · 默认 · 含义 键: maxNoteBytes · 默认: 4096 · 含义: 单条备注的最大 UTF-8 字节数（"" 清除备注；省略该字段则保留原值）。 键: maxSnippetChars · 默认: 300 · 含义: 服务端摘要的最大字符数。 键: maxTags · 默认: 8 · 含义: 每条收藏的标签上限；单个标签 ≤ 32 字符，自动去空白与去重。

安装命令

dsh plugin --profile web add github:penguin-oo/dsh-bookmarks
