项目简介

为 DeepSeek Harness 提供 Turn 级项目文件恢复，并可选择从恢复后的这一轮继续新对话。 Turn Rewind 是用户看到的功能名、仓库名和 Profile Bundle 名。Change Ledger 是底层持久恢复引擎；ctx.changeLedger 服务、磁盘格式和存储路径继续保留这个名字，因为它们描述的是可复用的快照与恢复层，而不只是 Web 上的回退按钮。

插件不会自动 commit、stash、reset、切分支、修改 Git index，也不会替用户判断某项改动“应该回滚”。 效果预览

打开后会先展示受影响文件，可选择“恢复文件并从这里继续”或“只恢复文件”： 为什么底层需要 Change Ledger

安装命令

dsh plugin --profile web add github:Anionex/dsh-turn-rewind
