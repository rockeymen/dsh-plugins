项目简介

前置条件：可用的终端 TTY、官方 dsh CLI，以及 pnpm 10+。运行模型还需要 DEEPSEEKAPIKEY。

dsh-tui --resume 恢复上次会话；Windows 也可用仓库里的 dsh-tui.cmd（等价）。

TUI 启动后会在后台检查 npm 是否有新版本；发现更新时会提示，输入 /update 即可自动更新并重启恢复当前会话。

安装命令

dsh plugin --profile web add github:ccch1mneyyy/dsh-TUI
