DeepSeek Harness）词库插件

master1Sun/dsh-prompt-library · 技能

DSH（DeepSeek Harness）Web 插件：在 composer 工具栏注入一个「提示词库」按钮，管理可复用的 prompt 片段，点击即可插入当前输入框。支持自动学习：输入复杂 prompt 文案时，插件会自动识别并保存到提示词库。

项目简介

基于单个 SOUL.md 人格文件约束每一次 AI 调用与整个聊天会话，形成稳定的助手人格。文件默认生成模板、删除会自动重建；内容由用户手动维护，AI 只读引用、不擅自改写。 文件 · 含义 · 作用 文件: SOUL.md · 含义: 人格 · 作用: 身份、性格/语气、工作规范 自动学习输入内容为提示词入库，AI 智能完善标题、标签、摘要和正文 人格文件为用户的显式设定（含默认模板），AI 据此遵循性格、语气与工作规范 设置

在 DSH 设置 → 词库调整：自动学习、手动确认、AI 智能完善、面板大小、侧边栏、按钮显隐、# 触发等，修改即时生效。 数据存储

启动 dsh web，点击聊天栏「词库」按钮打开面板，或输入 # 快速触发；点击「AI 优化」一键优化输入内容。 开发 / 构建 效果图 作者 master1Sun GitHub: https://github.com/master1Sun/dsh-prompt-library

安装命令

dsh plugin --profile web add github:master1Sun/dsh-prompt-library
