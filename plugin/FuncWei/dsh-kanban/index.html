FuncWei/dsh-kanban · 技能

dsh-kanban · DeepSeek Harness 的任务板 DeepSeek Harness 插件，将完整的 Hermes 看板（Nous Research，MIT）引入 DSH：完整的看板引擎和 UI 作为本地 sidecar 运行，而 DSH 添加了 Web 服务器集成、模型工具和与工作人员一起执行卡片的 DSH 本地调度程序。 Hermes平价：9柱板、多板

项目简介

1. 对话里说「建一张卡：整理本周公众号选题」→ agent 调 kanbantaskcreate 2. 卡片进入 ready 列后，调 kanbandispatch（或让 agent 调）→ DSH headless worker 认领执行，看板上实时看到 running → done 与运行记录 3. worker 最终消息写 DONE/BLOCKED；非零退出计入失败次数，连续失败自动转 blocked 并给出诊断恢复动作 架构 许可

MIT。Sidecar 复用 Nous Research Hermes Agent（MIT）的看板实现，详见 NOTICE.md。

安装命令

dsh plugin --profile web add github:FuncWei/dsh-kanban
