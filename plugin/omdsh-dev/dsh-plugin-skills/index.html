项目简介

为 DeepSeek Harness 插件开发而生的 Agent skills——从零搭建插件包，到选择正确的测试分层，全程在 agent 会话内完成。 包含内容 Skill · 功能 Skill: dsh-write-plugin · 功能: 端到端搭建插件：先选对形态（工具 / LLM 适配器 / hook / 服务 / 配置），再走完包清单（package.json 不变量、tsconfig 注册、README + Model Experience、验证门禁），每种形态配一份自包含的参考文件。 Skill: dsh-test-plugin · 功能: 为插件改动选择正确的测试分层：单元测试、逐文件覆盖率门禁、真实 API e2e、无密钥快照、Web 浏览器快照——以及何时"必须"加快照，含真实入口路径与 built-bin smoke 覆盖。

Claude Code 项目通常把 .claude/skills 软链到 .agents/skills；如果没有：

安装命令

dsh plugin --profile web add github:omdsh-dev/dsh-plugin-skills
