模型的回答长出界面——文字还在

omdsh-dev/dsh-genui · 技能

DeepSeek Harness 的 GenUI：交互式 UI 组件通过 dsh-ui 栅栏在助理回复中内联渲染 — 布局、图表、绘图、表格、测验、美人鱼、3D 场景以及返回模型的动作事件循环。提供栅栏教学主机插件、浏览器渲染器（客户端部分）和 genui 技能。

项目简介

English · 简体中文 让模型的回答长出界面——文字还在，可交互的 UI 已经能用。 🔌 生态：仓库已挂 #dsh · #dsh-plugin topic，欢迎 @dsh-plugin 收录。

模型不再只回你文字。装上它，你问"这个月订单怎么样"，它一边分析一边在回答里渲染出一张能点的数据面板：看趋势、拖滑块、按刷新，模型会真的响应你。

实际效果：模型输出的一块可交互监控面板（点「刷新」它会重新生成数据） 播放器没出来可 下载 mp4；四幕演示脚本见 demo-prompts.md。 ⚠️ 先看这里：双通道渲染（任何 dsh 版本都能用）

安装命令

dsh plugin --profile web add github:omdsh-dev/dsh-genui
