项目简介

普通 npm 依赖从包 registry 解析。DSH 宿主是成品包的运行时消费者,不是源码或构建输入。 仓库布局 可扩展的源码与测试结构

不要给函数插件添加 default export。Cordis Loader 会解包 exports.default ?? exports;多余的 default export 会丢弃 inject、Config、apply 等命名空间导出。 内置开发 skills

invariant companion 通过窄本地接口使用宿主的 invariants 服务。这让包构建不依赖宿主私有源码包,同时保留 DSH profile 使用的运行时注册。 插件形态

安装命令

dsh plugin --profile web add github:omdsh-dev/plugin-template
