项目简介

本仓库只存在这三个完整包。三包之外的任何代码——包括官方的 @deepseek-ai/dsh-tool-cordis 工具集或需要修正的上游依赖——一律不作为第四个包加入,而是以 pnpm 依赖补丁的形式存放在 patches/ 中(见 patches/README.md)。 仓库结构 仓库边界

运行 pnpm run verify:self-contained 强制执行该边界:它拒绝本地路径依赖规格、离开仓库的编译器或代码路径、外部或损坏的 Markdown 链接、绝对工作站路径,以及任何仓库布局契约文件的缺失。 组合包行为

Patch handler 是通过 ctx.fabric.register() 注册的可信代码;YAML 或模型输入永远不会反序列化可执行 handler。服务支持 Node ESM/CommonJS 加载期变换、browser 构建期变换、优先级组合、HMR 安全销毁、静态目标校验、generator 委托和 watched browser transforms。

dsh plugin --profile web add github:omdsh-dev/fabric
