项目简介

回调中的 payload 是发布者传递的任何内容。直接应用 或者忽略它并重新获取你自己的真理，两者都是一流的风格。

主题过滤：订阅与其确切主题和任何子主题相匹配 （'kanban' 匹配 'kanban/change'）。浏览器的连接URL带有 选项卡主题的联合，因此服务器仅发送该选项卡侦听的内容 为.当选项卡的最后一个侦听器取消订阅时，连接将关闭。

每次（重新）打开流时，合成主题 relay 的订阅者 收到'relay/open'。从消息应用状态的消费者使用它来 重新同步：流中断时丢失的任何内容都会恢复一 重新获取。 设计

安装命令

dsh plugin --profile web add github:joao-paulo-santos/dsh-event-relay
