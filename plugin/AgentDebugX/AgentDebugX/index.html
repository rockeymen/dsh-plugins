项目简介

AgentDebugX 用于代理人工智能系统的本地优先调试框架：诊断故障、确定根本原因、通过证据进行恢复，并通过重新运行验证修复。

AgentDebugX 将失败的代理运行转变为结构化、可审核的调试 文物。它摄取实时或导出的轨迹，检测可见的故障 发出信号，将其归因于负责的步骤或代理，建议恢复 操作，并准备受控重新运行，以便可以验证修复而不是 猜到了。

该项目专为研究人员和工程师构建复杂的法学硕士而设计 代理：多代理系统、使用工具的代理、使用计算机的代理、基准 跑步者和本地代理开发工作流程。 AgentDebugX 是本地优先的 默认：跟踪保留在您的计算机上，共享是选择加入的，并且恢复建议 将明确的策略和批准元数据带入重新运行边界。 📰 新闻 🔌 2026-08-25 — 已发布 dsh-agentdebugx v0.1.0， DeepSeek Harness 的 AgentDebugX 插件。 📄 2026-07-31 — 发布 CUADebug，我们的诊断框架 以及修复计算机使用代理故障。 📄 2026-07-21 — 发布了 AgentDebugX论文，介绍我们的 用于故障可观察性、归因、恢复和恢复的开源工具包 在 LLM 代理中重新运行。 📦 2026-05-16 — 发布于 AgentDebugX PyPI。 📄 2025-09-29 — 发布 LLM代理失败的地方以及他们如何从失败中学习， 介绍 AgentErrorTaxonomy、AgentErrorBench 和 AgentDebug。 系统概述
