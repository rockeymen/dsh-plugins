项目简介

工具链路径可用环境变量覆盖（DEVECOHOME / DEVECOSDKHOME / HVIGORW / OHPM / HDC），CI 场景必须显式提供。 测试

工具包获取：登录 华为开发者联盟下载中心 - Command Line Tools，选择 Linux x64 且与工程 SDK（6.1.1(24)）匹配的版本（6.1.1.300）。

签名 secrets：SIGNINGKEY（p12 base64）/ SIGNINGCERT / SIGNINGPROFILE / KEYSTOREPASSWORD / KEYPASSWORD / KEYALIAS 变更记录

安装命令

dsh plugin --profile web add github:enoughpower/dsh-harmony
