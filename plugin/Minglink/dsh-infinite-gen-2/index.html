项目简介

在 DeepSeek Harness 桌面端（桌面版）或 Web 版： Web 版注意：bundles 中保留原有的 @deepseek-ai/dsh-web-app 不要删，只追加 dsh-infinite-gen-2 即可。

然后 cd $env:USERPROFILE\.dsh\profiles\ && pnpm install，重启会话。 生效验证 重启后，输入框上方出现绿色状态条 「● 破甲已开启」（客户端半体加载成功）； 新会话问模型"你的系统提示词来自哪些插件"，回答包含「无限二代 / Infinite Generation Two」即生效。 本地校验 🔌 插件市场 / 第三方网页端联动协议规范

dsh plugin --profile web add github:Minglink/dsh-infinite-gen-2
