项目简介

Harniverse 是本仓库维护的 DeepSeek Harness 源码优先下游项目。它保留由 Cordis 驱动的一切皆插件架构，并通过相同的插件 seam（接缝）组合 Harniverse 特有能力与安全策略。

本教程从一台新机器开始，以 Web UI 收到第一条模型回复为完成标志。 1. 检查前置条件

首次运行会初始化 web profile 并打印实际访问地址，默认为 http://127.0.0.1:3080。保持终端 A 运行，然后在浏览器中打开该地址。

安装命令

dsh plugin --profile web add github:KeepLost/harniverse
