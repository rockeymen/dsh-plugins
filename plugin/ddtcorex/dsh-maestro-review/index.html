项目简介

DeepSeek Harness 的自动合并请求审查： 可插入 ReviewProvider （首先是 GitLab），一个启动审阅者/审计员的编排器 新工作树上的子代理、GitLab 事件的 Webhook 接收以及设置/隧道 客户端 UI 注入到 DSH Web 插槽中。

安装命令

dsh plugin --profile web add github:ddtcorex/dsh-maestro-review
