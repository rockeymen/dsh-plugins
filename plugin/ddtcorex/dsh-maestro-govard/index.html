项目简介

Govard 的薄 DeepSeek Harness 桥 — 暴露 Govard 工作区/项目 将工具添加到 DSH 会话作为注册工具。 Govard 引擎本身是一个单独的 Go 代码库和二进制文件；这个包只是桥梁，它不嵌入Go代码。

Go 二进制文件在 govard 存储库 (make build) 中单独构建；这座桥 期望它在 PATH 或其配置位置可用。 发展

在移交之前，必须针对 Govard 管理的真实项目实时验证运行时功能 — 参见 AGENTS.md。

安装命令

dsh plugin --profile web add github:ddtcorex/dsh-maestro-govard
