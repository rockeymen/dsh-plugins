项目简介

原版是会话级动态 Cordis 插件，通过 cordisdefine / cordisrun 创建（参见 DeepSeek Harness 文档）。code.host 的函数体即 src/index.js 去掉 module.exports 包装；code.client 的函数体即 client/index.js 去掉包装。 注意：动态形态使用沙箱私有的 harness.handle / host.call 通道（client/index.js），而静态 bundle 形态（client/bundle.js）通过 HTTP 路由 /ds-api-usage/snapshot 与 Host 通信。修改协议时请保持两者同步。 作为组合插件（持久化，手动）

安装命令

dsh plugin --profile web add github:Sev7een/ds-api-usage
