项目简介

！[很棒的DSH插件](https://awesome-dsh-plugin.com) DSH 托盘

要求：Windows，以及 PATH 上的 node。 菜单 打开Web UI — 在默认浏览器中打开http://127.0.0.1:3080。 显示日志（Windows 终端） — 在 Windows 终端选项卡中跟踪服务器日志。 启动/停止/重新启动服务器 — 与运行状态互斥。 登录时启动 — 复选框；注册/删除每个用户的运行键条目。 退出（停止服务器） — 停止服务器并删除托盘图标。

This repo carries Cordis plugin scaffolding — package.json with a dsh.bundle manifest, cordis.patch.yml, and src/plugin.js. CI validates the manifest and PowerShell syntax on every push. Limitations Windows only. Assumes the default port 3080 and the default web profile. "Launch at login" stores absolute paths; re-toggle it after moving the repo. Independent tool, not an official DeepSeek product. DSH Tray（中文）

安装命令

dsh plugin --profile web add github:nxz1026/dsh-tray
