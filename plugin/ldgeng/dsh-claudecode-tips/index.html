项目简介

用于网络配置文件的 DeepSeek Harness (DSH) 插件包。它用旋转的 Claude Code 式 加载字（原始 56 个字集）取代了静态 深潜... 转弯状态标签。状态旁边的经过时间时钟被保留。 改变了什么

该实现是一个小型浏览器端客户端插件：它监视聊天 DOM 并仅重写状态文本节点。没有服务器代码，没有模型提示更改，没有 DSH 的分叉。

需要 web 配置文件和支持树外捆绑包的 DSH 版本（dsh 0.1.0-rc.6 或更高版本）。

安装命令

dsh plugin --profile web add github:ldgeng/dsh-claudecode-tips
