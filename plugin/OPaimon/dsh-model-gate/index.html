DSH 的单型号禁用门

OPaimon/dsh-model-gate · 模型适配

dsh-model-gate DSH 的单型号禁用门。拒绝整个提供者路由或精确对 - 被拒绝的模型从每个发现路径中消失，并且仍然到达它们的任何调度都会以协议内错误块终止。设计上非破坏性：您的提供商配置或凭证中的任何内容都不会受到影响。拒绝名单是一个独立的覆盖层

项目简介

面向 DSH 的单模型禁用门禁。按整条 provider 路由或精确的 provider/model 对配置拒绝名单 —— 被禁模型从一切发现路径消失，仍到达它们的任何调用都会以 协议内 MODELDISABLED 错误 chunk 终止。

然后重启一次 DSH，让 bundle 层装载新条目。此后的名单编辑全部经 settings 热 生效，无需再重启。已在 DSH 0.1.x-rc 上验证。 用法

匹配精确且区分大小写。禁用某条 provider 路由会隐藏其下所有模型。带 加斜杠前缀的模型 id 在所有 provider 上生效，包括接受显式 directory 外 id 的 专用路由（如 DeepSeek 直连）。 设置界面

安装命令

dsh plugin --profile web add github:OPaimon/dsh-model-gate
