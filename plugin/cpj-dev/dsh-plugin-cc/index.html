项目简介

一个连接 Claude Code 与 DeepSeek Harness（dsh）的插件市场项目。它提供代码审查、对抗式设计评审、任务委派、后台运行，以及可恢复的多轮 dsh 会话。

安装命令

dsh plugin --profile web add github:cpj-dev/dsh-plugin-cc
