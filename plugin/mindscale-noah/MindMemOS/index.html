项目简介

想省去部署直接体验，可以先用官方云服务（在 官网 申请 API key）；需要私有化或离线使用，按下面的本地部署启动。 1. 本地部署

MindMemOS 使用 uv 管理依赖和执行本地命令。详细配置方法可以查看docs/deploy/instructionZH.md。

默认端口 8000：FastAPI http://127.0.0.1:8000，API 文档 http://127.0.0.1:8000/docs。 1.1 准备配置文件 启动前，至少需要在 config/mindmemos/dev.yaml 中配置以下三类模型路由： chatmodelrouter：支持记忆抽取、Skill演进等。 embedmodelrouter：语义向量 embedding，维度保证与QDrant维度配置一致。 rerankmodelrouter：可选，记忆检索结果重排。

安装命令

dsh plugin --profile web add github:mindscale-noah/MindMemOS
