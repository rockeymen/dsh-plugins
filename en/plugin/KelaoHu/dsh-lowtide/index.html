Project overview

dsh-lowtide Queue tasks when it's busy. They run on their own when it's cheap.

Semi-auto or full-auto, off the model's peak hours and peak prices. A must-have plugin for DeepSeek Harness.

Three tasks waiting in the queue, the price status glowing in the session header, auto-run when your window opens Introduction

Install command

dsh plugin --profile web add github:KelaoHu/dsh-lowtide
