Project overview

配置默认指向 http://localhost:1933。如需覆盖任何设置，请在 profile 的 cordis.patch.yml 中以 id: openviking 写入完整配置（patch 整体替换 config）： 可视化配置（dsh Web UI）

部署 dsh web 时，插件配置可以直接在浏览器里编辑：设置 → 插件 → 插件配置 → OpenViking。卡片字段与上方 YAML 完全对应，保存后写入 $DSHHOME/settings.yaml 的用户层，叠加在 profile 的 id: openviking 配置之上： 请求相关字段（endpoint、apiKey、account/user/agentId、timeoutMs、repoContext.、autoRecall.、自动提交间隔）保存即生效； stateFile 在插件启动时读取，修改后需重启； 已覆盖的字段显示「已覆盖」徽标，可一键「恢复默认」（清掉用户层覆盖，重新继承 profile 配置）； 非法值（含非 http(s) 的 endpoint）在保存时被设置层拒绝，不会写入。

在 dsh plugin --profile web add|remove（pnpm 会清理 profile 的 nodemodules）或升级 dsh 之后重新执行；如果插件页里卡片消失，先跑这个脚本再重启 dsh web。 创建账号与密钥

Install command

dsh plugin --profile web add github:Rxiain/dsh-openviking
