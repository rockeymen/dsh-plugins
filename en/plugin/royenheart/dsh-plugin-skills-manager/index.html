Project overview

1. 全局技能设置 — 在 dsh 设置里启用/禁用技能，写入 settings.yaml 的 skills-manager namespace；技能清单跟随当前会话发现（复用 skill.list RPC）。 2. 工作区覆盖 — 工作区三点菜单里的「技能管理」入口（补丁 0001），以及设置页内的「工作区」页签；技能发现走 skill.list({ cwd })，不依赖该工作区已有会话。 3. 会话覆盖 — 会话「轨迹」右侧的「技能」页签；支持 Shift 连续多选 / Ctrl 独立多选后批量启用/禁用。 技能识别范围

插件是 dsh profile bundle（package.json 的 dsh.bundle.patch 指向 cordis.patch.yml，后者插入插件自身 host 行）。dsh plugin add 成功后会把 插件自动 reconcile 进 dsh.profile.bundles，因此不再需要手写 bundle / cordis:include 配置。

复用 dsh 自带的 locale 框架（@deepseek-ai/dsh-client-locale）：src/locales/ 定义 skills-manager 命名空间的 zh / en 两套扁平字典，host 端 ctx.locale.register('skills-manager', dicts) 注册，client 端 ctx.locale.bind('skills-manager') 取翻译函数；所有 UI 文案都走这个 API。双语键集合与占位符对称性由 tests/i18n.test.ts 强制。 数据流

Install command

dsh plugin --profile web add github:royenheart/dsh-plugin-skills-manager
