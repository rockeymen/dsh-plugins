Project overview

👁️ 给 DeepSeek 带上眼睛 —— 粘贴图片直接识别 · ⚓ 锚定模式实测比官方 Standard 约 +8%

dsh 只能开在浏览器标签页里？这个仓库把它变成一个真正的桌面应用：Tauri 2 原生窗口 + 系统 WebView，Linux / Windows / macOS 通用。打开就是官方 WebUI——会话、工作区、插件、技能一个不少，dsh 升级后界面跟着升级，永远不用重打包前端。

DeepSeek 主力对话模型是纯文本的——你贴一张截图，它两眼一抹黑。本应用内置 ModLens（全网第一个 dsh 视觉插件）：外挂视觉引擎后，图片直接粘贴进对话框就能识别，不用先存盘再填路径。配套的 设置 → 视觉模型 页面把 OpenAI / Gemini / Anthropic / 本机 CLI 引擎全配齐，免费的 Gemini key 就能跑。 ⚓ 锚定模式：比官方 Standard 约 +8%

dsh plugin --profile web add github:TommyFang2077/dsh-desktop
