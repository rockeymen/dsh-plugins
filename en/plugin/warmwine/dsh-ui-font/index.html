Project overview

设置页里有一行「UI 捕捉快捷键」，点「录制」然后按下你想用的组合键（比如 Ctrl+Alt+F）就存好了。为什么要自己设而不是给个默认值？因为浏览器和编辑器的搜索键基本都是 Ctrl+F 系，写死一个默认键太容易撞车。所以默认留空——想用就花五秒录一个，不想要就不占任何键。

微调列表里每个插件那句话介绍，是插件自己 package.json 里写的描述（没有的话取 README 的标题）。插件升级换了描述，点「刷新」就是新的。 工作原理（给想了解的人）

版本历史见 CHANGELOG.md。 已知边界 dsh-ssh 的 xterm 网页终端用自己的内置字体，不参与缩放（准星悬停时会提示） 换肤插件（qq98 之类）激活时会接管字体变量，以皮肤为准 网页预览面板里 iframe 渲染的内容（比如预览一个网页）不是本页元素，准星选不到

Install command

dsh plugin --profile web add github:warmwine/dsh-ui-font
