Project overview

A 股自选股实时行情盯盘插件：在 DeepSeek Harness（DSH）Web 界面的右上角显示一个可折叠弹窗，实时监控自选股行情、切换分组、查看分时与 K 线、设置买卖目标价。

Install command

dsh plugin --profile web add github:Awu12277/dsh-stock-watch
