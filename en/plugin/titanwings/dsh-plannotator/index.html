Project overview

📝 dsh-plannotator Review the plan before your coding agent writes the code.

① The plan sounds plausible, but one sentence hides a migration risk? ② You found several independent problems, but the only choices are Approve or Reject? ③ You want every comment to stay attached to the exact text the agent must revise? ✨ Turn a binary plan gate into a precise, multi-comment review.

Select exact plan text, collect precise comments, and return one structured review—without leaving DeepSeek Harness.

Install command

dsh plugin --profile web add github:titanwings/dsh-plannotator
