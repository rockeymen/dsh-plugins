Project overview

clawhub地址 https://clawhub.ai/zhaoolee/notes-export-api 支持自定义底部品牌标识(点击就能改)

只要你喜欢，可以把底部的「锤子便签」改成「凿子便签」或「榔头便签」 支持下载文章，包含网页，markdown以及管理的图片资源 支持接入DeepSeek，修正语法错误，重点加粗，通俗化润色 零配置，复制即可将权限导入hermes agent

登陆后，复制一行专属链接，粘贴给Hermes Agent或OpenClaw，即可获取包含登身份认证的skill包，实现人机协同 支持多用户隔离

Install command

dsh plugin --profile web add github:zhaoolee/notes
