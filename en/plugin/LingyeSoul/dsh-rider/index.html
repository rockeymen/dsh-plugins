返回结构：{ provider, model, text, reasoning?, note?, image: {mediaType, width, height, bytes} }； note 在会话模型已支持视觉时给出提示（不阻断）。 图片理解卡片（设置页内粘贴/上传图片看图）

纯文本会话模型下，DSH 会在对话流拦截直接粘贴的图片（提示"当前模型不支持图片"）。 dsh-rider 设置页提供「图片理解」卡片，绕开对话流直接看图：图片经 dsh-rider 自建 HTTP 路由直抵 Node half 的视觉模型调用链（不经 apiproxy 的 prompt 入口， 不触发图片准入拦截）。 用法：打开设置 → dsh-rider 设置页 → 「图片理解」卡片 → 粘贴（Ctrl/Cmd+V）/ 拖拽/点击上传图片 → 点「理解」→ 视觉模型返回的描述显示在卡片内（含模型元信息 + 复制按钮）。描述不自动写入对话流，可自行复制后以文字发给 agent。

Install command

dsh plugin --profile web add github:LingyeSoul/dsh-rider
