Project overview

A workbench plugin for the DeepSeek Harness Web UI. After Workbench is opened in Conversation, chat stays on the left. Two new columns appear on the right: the editor (syntax highlighting and terminal) and files & Git. Release Item · Description Item: Package · Description: dsh-workbench-plugin Item: Version · Description: 0.1.8 (npm tag latest) Item: Registry · Description: https://registry.npmjs.org

DeepSeek Harness is installed, and dsh web can be started. Procedure

2. Restart dsh web. 3. Open http://127.0.0.1:3080, enter Conversation, and select Workbench in the header. Upgrade Automatic notice

Install command

dsh plugin --profile web add github:loadingvx/deepseek-harness-workbench-plugin
