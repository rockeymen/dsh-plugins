Project overview

面向 DeepSeek Harness 的 YouMind OpenAPI 插件。 来源与致谢

本插件的 YouMind 工作流与 Skill 设计参考并适配自 YouMind-OpenLab/skills。感谢 YouMind OpenLab 公开相关 Skill 与 OpenAPI 使用范式。本项目是面向 DeepSeek Harness 的社区适配，不代表 YouMind 官方发布。

从 https://youmind.com/settings/api-keys 创建 API Key，然后将它保存到 DSH 的受管凭据文件：

Install command

dsh plugin --profile web add github:seamas0825-lab/dsh-youmind-plugin
