Project overview

A desk pet that shows you what your agent is doing. It floats above every window — including fullscreen — and changes expression as DSH works, waits, finishes or fails.

idle · working · waiting · error · happy · sleeping Install

The pet appears on your desktop, floating above whatever you are working in. Nothing is added to the DSH page itself.

Install command

dsh plugin --profile web add github:anneheartrecord/dsh-desk-pet
