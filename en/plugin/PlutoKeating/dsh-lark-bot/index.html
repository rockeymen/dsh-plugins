Project overview

把 DeepSeek Harness 接入飞书 | Bridge DeepSeek Harness into Feishu / Lark

This project ships as a standard dsh profile bundle: one command installs it into a dsh profile, and dsh loads the bridge engine as a standard plugin on boot (the package declares dsh.bundle.patch, so dsh plugin add works directly).

setup 会自动完成：发现本机 dsh → 预批准 pnpm 构建策略 → 执行标准的 dsh plugin --profile dsh-lark add dsh-lark-bot。

Install command

dsh plugin --profile web add github:PlutoKeating/dsh-lark-bot
