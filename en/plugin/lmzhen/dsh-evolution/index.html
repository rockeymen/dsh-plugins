Project overview

After install, restart the DSH profile. The agent now has durable memory, skillmanage, background review, curator, approval, and threat checks. [!WARNING] Plugins run third-party code with your local permissions. Review this repository before installing, and prefer a profile without production credentials for a first test. This installs @deepseek-ai/dsh-evolution-preset: host services and model tools in one layer. Good for trying the plugin quickly. 2. Layered install (recommended)
