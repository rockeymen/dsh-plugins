Project overview

四者都支持：断点续跑（vibemathresume / vibev4resume）、人工/自动模式切换、vibemath / vibev4 工具集与 /vibe /v4 命令、按项目隔离、子代理权限调控。v2 与 v3 均为同级主推——偏好结构化 JSON 数据与确定性调度选 v2，偏好论文式 md、规划代理与理论发明库选 v3；v4 是最新的「常驻自组织合作研究」实验架构。 🧠 架构与分工（v1 · 经典）⚠️ 早期架构 · 将弃用 · 不建议新项目使用

主代理会自动：vibemathaddproblem 加题 → vibemathstart 启动 → 之后你随时问它进度。

主代理会自动调用 vibemathstatus / vibemathreport 并把结果用人话汇报给你。 方式 B：命令 / 工具（精确控制）
