Project overview

dsh-crew is a plugin for DeepSeek Harness (dsh). It turns your dsh session into a product manager (PM) that runs a crew of role agents: architect, engineer, test engineer, code engineer, QA, code reviewer, security reviewer, doc reviewer, and researcher. What it is

You talk to the PM. The PM starts role agents for the work, and every decision is written down in documents that stay in the repository.

Two lanes: ask — you want an answer. The PM answers. Nothing changes. team — you want a change. The PM runs the crew: one task per change, one round of QA, one round of each review, then a commit. Pushing and publishing still need your own yes, every time. Install

Install command

dsh plugin --profile web add github:stuarthu/dsh-crew
