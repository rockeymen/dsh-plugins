Various modes implemented based on dsh web

SeaOf0/dsh-redteam-model · model-adapters

Based on the various modes implemented by dsh web, the purpose is to serve redteam for authorized security research, covering penetration testing, red team assessment, code audit and other fields.

Project overview

前置：Node.js >= 22（DSH 本身要求）。无需预装 pnpm/dsh（经 npx 拉起）；bash/python 非必需。 方式一：设置页管理台（推荐）

获取源码任选其一：git clone https://github.com/SeaOf0/dsh-redteam-model.git，或仓库页 Code → Download ZIP 解压。

也支持 npx ./deploy。Windows（Win10+ 自带 bsdtar）：流程一致，预设链接用 junction 免管理员。

Install command

dsh plugin --profile web add github:SeaOf0/dsh-redteam-model
