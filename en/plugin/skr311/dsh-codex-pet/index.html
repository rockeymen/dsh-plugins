Project overview

DeepSeek Harness（DSH）桌面宠物插件：导入/上传 codex 风格的精灵图序列帧宠物，在 DSH Web GUI 以 shell.overlay 悬浮浮层渲染，含图库管理、基础交互与 Agent 状态联动。 📸 预览 ✨ 核心特性 序列帧播放：单 WebP 精灵图（格式 A），逐帧毫秒时长，行=动画（idle / running / waiting / review / failed / 移动 / 挥手 / 跳跃）。 悬浮浮层交互：右下角常驻，可拖拽（视口钳制 + 位置持久化）、点击挥手、空闲随机小动作。 图库管理：设置 → 宠物图库——zip 上传 / URL 导入 / 启用 / 停用 / 删除 / 首帧预览。 Agent 状态联动：订阅 DSH 会话状态——工作中→跑动（常驻）；审批/提问→等待（脉冲一次）；任务完成→得意（脉冲一次）；任务失败→沮丧（脉冲一次）。 深/浅主题：全部样式走 --dsw- 主题令牌，自动适配 DSH 主题。 🎮 操作指南

Install command

dsh plugin --profile web add github:skr311/dsh-codex-pet
