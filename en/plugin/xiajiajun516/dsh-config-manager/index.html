Project overview

🎒 DSH Config Manager Pack up your DSH configuration and take it anywhere — restore your whole environment on a new machine with one click. What is this? 🤔

Shown fully before importing: ⚔️ Conflict handling

When the target already has a same-named item, you choose: Option · Meaning Option: Keep Current · Meaning: Leave the target's config untouched Option: Use Imported · Meaning: Overwrite with the backup's value Note: a "decide later / review" option is intentionally not offered — an undecided conflict would block the import from proceeding. Every conflict must be resolved before continuing. 🗺️ Path mapping

Install command

dsh plugin --profile web add github:xiajiajun516/dsh-config-manager
