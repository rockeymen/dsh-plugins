Project overview

dsh-sentry is a free, open-source, read-only DeepSeek Harness plugin for the Sentry Web API. Every tool is an HTTP GET; the plugin never resolves, assigns, archives, or otherwise changes Sentry state.

If the result still exceeds the 200KB tool-result budget, the plugin degrades in fixed steps — source context, then breadcrumbs, then frames down to at most 10 without raising a lower caller cap. If administrator-enabled frame variables still make the result too large, they are removed as a final fallback. The last step is reported in meta.trimmed.degraded. Counters such as omittedFrames are always "original total minus what you received", never a running tally. Localization
