Project overview

沉浸式听朗读 · 豆包音质 点一下 🔊，把 AI 回复用豆包的自然音色念给你听——无需复制，不做自动朗读 DeepSeek Harness 插件 · BYOK · MIT

引擎（Omi DSH）构建见 engine/README.md：./engine/build/build-service.sh 后 ditto 到 /Applications/Omi DSH.app。 使用 🔊 点读；播放中再点 = 暂停，再点 = 从暂停处继续；点其它消息的 🔊 = 打断并读新的。 只读最终回答：工具执行日志、思考过程不会读；代码围栏、表格、纯图形（盒绘/ASCII）在请求前过滤，回复若只有这些内容，按钮呈禁用态并提示"没有可朗读的内容"。 引擎未启动 / 未配置 Key 时，点击会给出明确提示（含去哪打开 Omi）。 成本透明

豆包 TTS（seed-tts-1.0）按字符数计费，由你在火山引擎账户自行承担。为此： 只有手动点 🔊 才合成，不自动朗读； 引擎对相同文本 3 秒内去重，且进程内 LRU 缓存最近 3 条（≤5MB、纯内存、退出即清），重复朗读不重复计费； 纯表格/纯代码等无有效内容不发请求（invalidtext）。 架构与协议

Install command

dsh plugin --profile web add github:PolinniZhong/dsh-omi-voice
