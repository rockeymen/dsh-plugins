DSH version information plug-in

NEVSTOP-LAB/dsh-version-inspector · skills

DSH version information plug-in, a new "Version Information" page is added to the DSH settings panel, which displays the versions of DeepSeek Harness, plug-ins and dependencies in a compact multi-column tree, and support.

Project overview

全部数据由 Host 侧只读收集，通过一个同源控制路由 GET /version-info（回环校验）提供给客户端： 项 · 来源 项: Harness 版本 · 来源: @deepseek-ai/dsh/package.json（模块解析） 项: 插件列表 · 来源: Cordis Loader（ctx.get("loader").entries()，尽力而为；可用时列出已挂载插件） 项: 各插件版本 · 来源: 各插件包 package.json（createRequire 解析） 项: 依赖版本 · 来源: 各包声明依赖的 package.json（直接解析优先，回退到模块入口向上查找）

Install command

dsh plugin --profile web add github:NEVSTOP-LAB/dsh-version-inspector
