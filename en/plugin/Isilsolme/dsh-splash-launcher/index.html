Project overview

DSH GUI DeepSeek Harness（dsh）Web GUI 的 Windows 一键启动器：双击即弹出无边框启动动画，后台拉起 dsh web，GUI 真正加载完成后无缝淡入；关闭窗口自动停服务。

生成自包含的 DSH-GUI.exe（黑鲸图标，素材已内嵌为资源）。构建仅使用 Windows 自带的 C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe。 使用

Install command

dsh plugin --profile web add github:Isilsolme/dsh-splash-launcher
