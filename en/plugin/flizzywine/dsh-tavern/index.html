Project overview

dsh-tavern 基于 DeepSeek Harness（DSH）制作的 SillyTavern 类文字游戏 Agent。

SillyTavern 采用提示词工程的思路：每轮动态拼接一个超大上下文，囊括系统规则、内容偏好、对话历史、人物卡、世界书、脚本与变量等信息，再要求模型一口气完成正文生成、历史与设定遵循、格式控制甚至代码生成等复杂任务。

dsh-tavern 改用 Agent 架构。前台主 Agent 专注正文生成，后台 Agent 分步处理候选项、状态总结和世界书召回等小任务，再由程序把结果合并为完整体验。主 Agent 与后台 Agent 各自维护前缀稳定，从而提高缓存利用率、降低费用与等待时间；拆分后的每次生成只解决一个明确问题，也能显著提升输出质量。 产品功能 1. 游玩模式 自由游玩
