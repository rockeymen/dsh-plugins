Project overview

宣传页：yyh-001.github.io/dsh-meme（表情包合集可预览；仓库加 topic dsh-meme-pack + previews/ 即收录） dsh-meme（原 dsh-expression）是 DeepSeek Harness 的表情包插件——找得到、发得出、学得会： 纯文本也能斗图：界面显示表情图片，模型收到的是 [表情: 描述]，无需图片输入能力 AI 自动学图：用户说「入库」时，learnmeme 收录最近一张用户附件（不必填附件 id），自动识别分类/描述 情绪主动发图：先选情绪桶，系统随机抽若干张 caption，模型挑一张贴进回复 像 QQ/微信 一样发图：输入框 😊 悬浮面板点选表情直接发出 零第三方依赖：仅 node:sqlite，装完即用

已发布到 npm（dsh-meme），一行装进任意 DSH profile（如 /.dsh/profiles/web/）：

或从 GitHub / 本地直接装： 注意：pnpm 有「新包安全期」（默认 24h），刚发布的版本会被静默回落到旧版；急用可在 pnpm-workspace.yaml 的 minimumReleaseAgeExclude 里加上 dsh-meme。 配置

dsh plugin --profile web add github:yyh-001/dsh-meme
