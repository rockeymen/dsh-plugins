Project overview

DSH Workspace adds a Workspace tab to the local DeepSeek Harness Web UI. It lets you inspect what an agent touched, review read-only Sub-agent Trace entries, review session artifacts, preview bounded content, inspect Git changes, manage governed local Workspace Memory, and review Memory proposals the Agent creates — all without leaving the conversation. What it is for

Register the built plugin with a local Harness checkout. Run this from the Harness project directory, or adjust the relative path to where this repository is checked out:

The command stores the Web plugin registration in the local Harness profile. Start the Web UI

Install command

dsh plugin --profile web add github:kaiqiangh/dsh-workshpace-plugin
