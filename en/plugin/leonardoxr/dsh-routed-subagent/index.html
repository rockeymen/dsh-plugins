Project overview

Allowlisted model-and-reasoning routing for DeepSeek Harness. Every delegation call must choose both: a configured model policy through model; and one exact adapter-owned effort through reasoningeffort.

The plugin validates the pair against local policy and ctx.llm.resolveCallConfig() before creating a child. Arbitrary provider/model passthrough is never accepted. Install Configure

Target the routed-subagent row in your profile patch. models and rootModels are required.

Install command

dsh plugin --profile web add github:leonardoxr/dsh-routed-subagent
