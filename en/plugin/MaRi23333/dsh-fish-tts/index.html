Project overview

dsh-fish-tts English: dsh-fish-tts is a third-party TTS plugin for the DeepSeek Harness Web GUI — Fish Audio API only, bring your own key: a per-message "Read aloud" action, an auto-read toggle in the composer, and a settings page for model / voice / encrypted API key / proxy. Bilingual UI (zh/en). See 简介

首次使用：打开 Settings → 语音朗读，填模型、音色、API Key（Fish Audio 的 key），必要时填代理，保存后用「试听」验证。所有设置在保存后立即生效，无需再次重启。

Install command

dsh plugin --profile web add github:MaRi23333/dsh-fish-tts
