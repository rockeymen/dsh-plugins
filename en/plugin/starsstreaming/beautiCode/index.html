Project overview

为 DeepSeek Harness 添加图片与视频背景，也支持 Codex Desktop。 可以是一张壁纸，也可以是一部番剧、一个壁纸，或者一段陪你度过漫长工作的风景。 它是什么？

beautiCode 是一个本地背景工具，主要面向 DeepSeek Harness和Codex。

npx beauticode-dsh 会从 npm 下载插件并写入你的 DSH profile，不需要 pnpm，也不需要再执行 dsh plugin add。已把 dsh 装到 PATH 时，第二行也可以写成 dsh web。

Install command

dsh plugin --profile web add github:starsstreaming/beautiCode
