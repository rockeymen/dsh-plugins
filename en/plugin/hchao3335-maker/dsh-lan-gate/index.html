DSH intranet access plug-in

hchao3335-maker/dsh-lan-gate · tools

A DSH intranet access plug-in allows LAN devices to securely access the local DSH plug-and-play gateway: local approval, device token, current limiting, mobile phone adaptation, and zero dependence on a single file.

Project overview

让同一局域网内的手机、平板、其他电脑通过网页访问本机 DeepSeek Harness（DSH），并且首次访问需要本机批准。

执行完，你应该能看到这个文件： \lan-gate\lan-gate.mjs 第 2 步：注册插件（改一行配置文件）

打开文件： \profiles\web\cordis.patch.yml 如果文件不存在，就新建一个； 如果文件里是 []（空配置），把 [] 整个替换成下面内容； 如果文件里已经有内容，把下面这段追加到末尾。 把 name: 里的路径换成你第 1 步实际放置的完整路径，规则如下： 系统 · 写法 · 例子 系统: Windows · 写法: file:///盘符:/完整路径 · 例子: file:///D:/deepseek-harness-master/.dsh/lan-gate/lan-gate.mjs 系统: macOS / Linux · 写法: file:///完整路径 · 例子: file:///home/me/.dsh/lan-gate/lan-gate.mjs ⚠️ 最容易踩的坑（Windows）：必须写 file:///D:/...，不能写 D:/...。DSH 的插件加载器不会自动把 Windows 路径转成 URL，裸写会报错 ERRUNSUPPORTEDESMURLSCHEME。

Install command

dsh plugin --profile web add github:hchao3335-maker/dsh-lan-gate
