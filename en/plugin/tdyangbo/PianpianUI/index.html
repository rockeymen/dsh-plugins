Lin Pianpian theme UI plug-in

tdyangbo/PianpianUI · skills

Lin Pianpian theme UI plug-in for DeepSeek Harness. Use the character Lin Pianpian from "Aihong: Ten Diaries of a Broken City" as the translucent background of the page, and support transparency and depth adjustments.

Project overview

在聊天页面点击右下角 UI 按钮，可以打开调节面板。 Opacity：调节图片透明度。向右拖动，图片更明显；向左拖动，图片更淡。 Depth：调节背景深度。向右拖动，背景更深、更有层次；向左拖动，界面更亮、更柔和。 Reset：恢复默认显示效果。

Install command

dsh plugin --profile web add github:tdyangbo/PianpianUI
