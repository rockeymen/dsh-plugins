Project overview

DeepSeek API 余额、分模型 Token 用量与费用估算，常驻 DSH 侧边栏。

启动 DSH 后，可在 设置 -> 模型 的 DeepSeek 卡片中保存 API Key；也可以让 DSH 进程从环境变量 DEEPSEEKAPIKEY 读取。 2. 获取项目

若 DSH 由计划任务管理，请重启原任务，保留它已有的环境变量、权限和后台窗口设置： 3B. macOS

Install command

dsh plugin --profile web add github:ArcanePivot/dsh-api-balance
