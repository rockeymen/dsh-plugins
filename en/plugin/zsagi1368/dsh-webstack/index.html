Project overview

WebStack is a DSH plugin distributed as the npm package dsh-webstack. Add it through your DSH plugin mechanism (bundle manifest / cordis patch list):

The package ships prebuilt ESM in lib/, a cordis patch descriptor at dsh-webstack/cordis.patch.yml (empty = coexist mode), and declares the platform packages as peer dependencies: required: @deepseek-ai/cordis, @deepseek-ai/dsh-web optional (capability-probed): @deepseek-ai/dsh-settings, @deepseek-ai/dsh-tools, @deepseek-ai/dsh-credentials, @deepseek-ai/dsh-llm

Node.js >= 22.19. Zero native modules; runtime dependencies are limited to @deepseek-ai/schemastery. Configuration

Install command

dsh plugin --profile web add github:zsagi1368/dsh-webstack
