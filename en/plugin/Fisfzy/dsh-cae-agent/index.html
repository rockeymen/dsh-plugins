Project overview

一个 DSH（DeepSeek Harness）的 Cordis 插件，通过 原生工具直接操作本机正在运行的 Abaqus/CAE 会话，覆盖完整建模链（几何、材料、网格、接触、分析步、载荷、边界、作业、ODB）。它是将 CAE-Agent-Hub 的 Abaqus 集成迁移为 DSH 原生插件，取代了原先的 MCP 桥接方案。源代码为 TypeScript，按 dsh-plugin-dev 规范开发。 版本： 0.2.1（plugin/ 内另有 v0.2.1 tag） 它做什么

Install command

dsh plugin --profile web add github:Fisfzy/dsh-cae-agent
