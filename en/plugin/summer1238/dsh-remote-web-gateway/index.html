Project overview

简体中文 · English DSH Remote Web Gateway 手机也能继续用 DeepSeek Harness。 扫个码，电脑上的 DSH 随身带走。 链接不是权限 · 一次性配对 · GitHub 身份验证 · 每台设备独立授权、随时撤销 无需远程桌面 · 无需 SSH · 无需公网 IP / 端口转发 电脑上的 DSH 还在干活，你人已经走了？

你真正想要的其实很简单： 打开手机，继续使用电脑上正在运行的那个 DeepSeek Harness。 DSH Remote Web Gateway 就是干这个的。

手机看到的是 DSH。 不是一个需要疯狂缩放和拖动的 Windows 桌面。 你只是想在手机上继续用 DSH，真的需要这么折腾吗？ 为了看一眼 Agent，真的要远程整个 Windows？

Install command

dsh plugin --profile web add github:summer1238/dsh-remote-web-gateway
