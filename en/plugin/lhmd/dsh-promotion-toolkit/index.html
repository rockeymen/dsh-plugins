Project overview

DSH Promotion Toolkit 把你的任何想法，变成每个平台原生的宣发内容。 它解决什么问题

DSH Promotion Toolkit 是一个 DeepSeek Harness 原生插件：把产品、开源项目、文章、课程、活动、个人观点，甚至一段还没整理好的想法，变成可以直接发布的多平台宣发内容。

目前覆盖 17 个平台：xiaohongshu、zhihu、wechat、wechatmoments、weibo、bilibili、douyin、kuaishou、x、threads、linkedin、reddit、tiktok、youtube、medium、facebook、instagram。 用自己的仓库做案例

Install command

dsh plugin --profile web add github:lhmd/dsh-promotion-toolkit
