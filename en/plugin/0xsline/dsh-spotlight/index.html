Project overview

Install the bundle into your DSH Web profile. From npm:

Then start DSH Web and press ⌘K or Ctrl+K: Usage

1. Open Spotlight with the global shortcut, or type /spotlight in the DSH Web composer and pick the entry from the slash menu. 2. Type to filter commands and actions. 3. Use Arrow Up/Down and Enter, or click a result. 4. Click Shortcut in the footer to record a different key combination. 5. Click Reset to restore the platform default.

Install command

dsh plugin --profile web add github:0xsline/dsh-spotlight
