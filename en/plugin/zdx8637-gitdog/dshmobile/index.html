Project overview

dshmobile — DeepSeek Harness 手机远程客户端 开箱即用：一条命令装插件 → 扫码 → 手机接着干。不是把 DSH Web 暴露到公网的 Remote Access，而是为 DSH 建立一个真正的 Remote Client——不需要懂 Tailscale、隧道、 端口、NAT 或任何网络概念，不需要修改 DSH，装完即用，跨平台。

在手机上远程控制本机 DeepSeek Harness（DSH）：扫码配对 → 设备 → 会话树 → 对话、 审批、提问应答、模型切换、文件浏览。 电脑端以 DSH 插件形态分发（plugins/dshmobile-plugin/，npm 包 @zdx8637/dshmobile-bridge）：Web 左侧栏底部箭头弹窗，常驻二维码—— 微信扫=下载 App、相机扫=跳 App、App 内扫=登录/授权，一个码全搞定。 界面一览

仓库不包含任何真实凭据，以下内容永远只在本地/私有渠道存在： relay 账号密码、服务器 SSH 凭据：测试脚本通过环境变量 TESTPASS、 RELAYHOST、RELAYSSHPASS 注入；文档中一律以 等占位。 dsh-remote/bridge/config.json（含账号密码）不入库，模板见 config.example.json。 Android 签名：release.keystore 与签名口令不入库；口令写在本机 dsh-mobile/local.properties（dshmobile.storePassword / keyAlias / keyPassword） 或环境变量 DSHMOBILE，app/build.gradle.kts 从这两处读取。 relay 运行时 .env、SQLite 数据（data/）、构建产物（dist/、nodemodules/）均被忽略。

Install command

dsh plugin --profile web add github:zdx8637-gitdog/dshmobile
