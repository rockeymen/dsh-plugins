Project overview

DeepSeek Harness（DSH）Web 插件：在对话里划选任意文本 → 点击「提问」→ 右侧面板问答。

基于dsh-better-sidebar开发的第三方拓展Tab页面。实现类codex侧边提问/claude code的/btw功能

重启 dsh web（host 半改动需要重启；client 改动浏览器硬刷新即可）。 使用

Install command

dsh plugin --profile web add github:ChenRuoT/dsh-sidebar-qa
