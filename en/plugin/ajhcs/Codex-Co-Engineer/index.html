Project overview

Codex-Co-Engineer is a public, Codex-first control plane for the standalone DeepSeek Harness and the official Grok Build CLI. Codex is the chief engineer and operator; these are bounded peer workers. The worker kinds are exactly deepseekagent and grokbuild; version 2 has no Prime Intellect integration or runtime dependency.

The stable plugin and MCP identifier is plumbob-harness-control. The public product name is Codex-Co-Engineer. Keeping the technical identifier stable allows existing Codex configurations to migrate without a server-name break. Release contents
