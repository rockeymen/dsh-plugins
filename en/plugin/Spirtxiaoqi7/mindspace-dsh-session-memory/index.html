Project overview

Mindspace Session Memory for DeepSeek Harness

This is a community plugin and is not an official DeepSeek project. The repository artwork is supplied by the project owner and is used only to identify this repository. Memory-governance foundation (introduced in 0.2.0)

The contribution is deliberately tree-out: one installable dual-face DSH bundle owns the Host service, sidecar persistence, prompt/tool integration, extraction hook, Typert descriptor, Remote, and settings UI. It does not replace DSH compaction semantics or require an upstream source patch, making the memory-governance layer independently installable, auditable, and removable. Confirmed/pending profile and categorized preferences Session role preset and visible memory audit

Install command

dsh plugin --profile web add github:Spirtxiaoqi7/mindspace-dsh-session-memory
