Project overview

Turtle UI The very first UI of dsh in a Friday afternoon

This repository contains the former packages/ui/tui implementation, its unit and terminal snapshot tests, and a dsh profile bundle patch. The TUI owns terminal presentation and input; DeepSeek Harness owns the agent, model, tools, persistence, and dsh launcher. Development

Keep this repository and DeepSeek Harness as siblings:

Install command

dsh plugin --profile web add github:turtle1999/turtle-ui
