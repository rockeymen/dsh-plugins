Project overview

dsh-hindsight Official-grade DeepSeek Harness memory plugin backed by Hindsight.

Give your DSH agent real cross-session memory: recall past decisions, remember new facts, inspect memory health — through a self-contained Cordis plugin. No dsh-mnemon, no orchestrator, no bundled storage engine. Just a thin HTTP client over the Hindsight REST API your server already exposes. Why

Requires Node ≥ 20 and DeepSeek Harness ≥ 0.1.1-rc.2.

Install command

dsh plugin --profile web add github:Ryu6Zero/dsh-hindsight
