Project overview

🛩️ DshCockpit 把 DeepSeek Harness 变成一台常驻后台的 Agent 驾驶舱

欢迎扫码进群，讨论使用问题、反馈建议，或聊聊 Agent 桌面化的玩法。 ✨ 为什么选择 DshCockpit？

双击挂载 → 把 DshCockpit 拖进「应用程序」→ 在启动台/访达双击启动。 ⚠️ 首次打开会提示「已损坏」或「无法验证开发者」：当前 macOS 包尚未签名公证（暂无 Apple Developer 证书），这是 Gatekeeper 的正常拦截，应用本身没坏。任选其一放行即可： - 图形界面：先双击一次（弹出警告点取消）→「系统设置 → 隐私与安全性」→ 滚到底部点「仍要打开」→ 再点「打开」。 - 终端一行（推荐，最快）： 放行一次后即可永久正常启动。后续接入 Apple 签名公证后此提示会消失。 方式三：从源码运行（推荐给开发者/尝鲜者）

Install command

dsh plugin --profile web add github:Lxiayu/DshCockpit
