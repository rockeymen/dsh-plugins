Project overview

1. Download DSH-Hotplug-Hub-win-x64-setup-v1.0.1.exe from the Releases page. 2. Double-click and choose an install location (default %LOCALAPPDATA%\Programs\DseamWorld). 3. The installer auto-creates desktop / start-menu shortcuts and launches when finished.

Silent install: Option 2 — Portable Windows: unzip DSH-Hotplug-Hub-win-x64-portable-v1.0.1.zip, then double-click DSH-Hotplug-Hub.exe (WebView2 runtime DLLs are included in the same directory). Linux: tar -xzf DSH-Hotplug-Hub-linux-x64-portable-v1.0.1.tar.gz, then run ./dsh-hotplug-hub. macOS: unzip DSH-Hotplug-Hub-macos-x64-portable-v1.0.1.zip, then double-click Start-DSH-Hotplug-Hub.command. Option 3 — From source

Requires Node.js 18+ (LTS recommended), pnpm, and the dsh CLI. hotpack Format

Install command

dsh plugin --profile web add github:ARFCON/dsh-hotplug-hub
