Project overview

现有方案把 DSH 当成一个黑盒 Docker worker 来调用——拿不到插件生态、每次事件冷启动、规则写死在 prompt 里、调 prompt 只能推 PR 等 CI。

评审者在 PR 评论首行触发（非首行不触发，避免引用他人评论误触）： 命令 · 作用 · 最低信任 命令: @dsr review · 作用: 重新评审 · 最低信任: untrusted 命令: @dsr explain · 作用: 解释某文件改动 · 最低信任: untrusted 命令: @dsr diagnose · 作用: 读失败 CI 定位原因 · 最低信任: trusted-read 命令: @dsr fix · 作用: 改代码并跑校验 · 最低信任: trusted-write + allow-write 命令: @dsr rules · 作用: 打印生效规则 · 最低信任: untrusted

Node 22.19+ / 24+ / 26，pnpm 11.x，对齐上游 DSH 的 engine floor。

dsh plugin --profile web add github:chaojixinren/dsh-reviewer-bot
