Project overview

梁相是 DeepSeek Harness 的 WebUI 插件。每天一道梁案：使用 DSH 烧掉的 Token 凝成香火，一炷夯或拉；社区香火汇成梁位，显出今日梁子。日终之后，结果收入梁祠。

先完全退出 WebUI。设置 → 插件市场 → 搜 liangxiang。没有插件市场时先装 dshmarket，步骤见 部署指南。也已列入 1024 Store 和 awesome-deepseek-harness。

Install command

dsh plugin --profile web add github:liang-today/dsh-liangxiang
