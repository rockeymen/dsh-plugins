Project overview

「安全审计模式」会话：13 个安全工作流技能 + 5 个扫描工具 方式二：门禁自动审计（进程级） 自动审计：轮询发现新预设/新插件 → 有界采集源码 → 宿主模型审计（免认证）， 已审计且未变化的插件自动跳过。 批量/状态：全局工具 dshsecurityscanplugins / dshsecurityscanstatus。 GUI：设置 →「安全审计」面板（状态/报告/一键重审；中英双语跟随系统语言）。 甄别记忆：历轮审计的误报/设计项/已修复项记入基线（audit-baseline.json）， 每次审计注入提示词，模型不重复报告已知项 —— 显著降低误报率。

报告摘要表 + 风险审计详情（AI 生成，仅供参考） 配置 门禁（@dsh.so/dsh-security-gate）
