Project overview

A DSH web plugin: a Session Manager in Settings — manage every conversation on this machine in one place.

Option 2: Let an agent install it — tell your DSH agent:

The agent downloads the repo, places it into the profile's nodemodules, and registers it in dsh.profile.bundles.

Install command

dsh plugin --profile web add github:Zephyr-vibe/dsh-archived-sessions
