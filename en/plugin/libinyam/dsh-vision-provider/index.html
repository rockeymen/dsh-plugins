Project overview

dsh-vision-provider gives DeepSeek Harness selectable vision choices under one DeepSeek + Vision provider:

Select only one combination in Harness. The vision model named in that selection is used behind DeepSeek:

The vision model does not run as the final answer model. Instead, it appears as part of a selectable DeepSeek combination. DeepSeek still performs reasoning, tool use, and final response generation. This is a community project. It is not an official DeepSeek or OpenAI package. Why v0.3.0 exists

Install command

dsh plugin --profile web add github:libinyam/dsh-vision-provider
