Project overview

dsh-clean-desktop-shell DeepSeek Harness 的纯净桌面壳（DSH 插件形态）

dsh-clean-desktop-shell 是一个 DSH 插件形态 的纯净桌面壳：它给已经跑起来的 DSH Web（默认 http://127.0.0.1:3080）套一层原生桌面窗口——系统托盘、单实例，像普通桌面软件一样使用。不做任何视觉改造：不加毛玻璃、不改界面，纯粹是"窗口壳"。

与生态里其他桌面端方案的最大区别： · 其他桌面端（如 dsh-desktop 系列） · 本插件 形态 · 其他桌面端（如 dsh-desktop 系列）: 独立 Electron 应用，自带独立 profile · 本插件: DSH 插件，挂载进现有 profile Profile · 其他桌面端（如 dsh-desktop 系列）: 新建 desktop profile，插件/配置要重装 · 本插件: 复用现有 web profile，零迁移 视觉改造 · 其他桌面端（如 dsh-desktop 系列）: 自绘标题栏 / 毛玻璃等 · 本插件: 零改造，纯净窗口壳 跟随上游 · 其他桌面端（如 dsh-desktop 系列）: 固定版本 · 本插件: 跟随 0.1.1-rc.2 核心亮点 ① 像双击桌面应用一样，一键启动 DSH

Install command

dsh plugin --profile web add github:Icather/dsh-clean-desktop-shell
