Project overview

本项目基于 deepseek-ai/deepseek-harness 开发，沿用其 Cordis 插件体系。主要扩展包括： dsh-georag：知识检索、关系扩展、空间查询和知识事件存储插件。 dsh-wenshan：知识演化与野外助教两种 agent 模式的工具和提示词。 dsh-wenshan-intake：资料收录、知识图谱接口和浏览器页面插件。 presets 与 wenshan.cordis.yml：问山的 DSH preset 和产品挂载配置。 功能 知识演化：收录文字、PDF、Word、图片、录音和常见 GIS 文件，生成知识草稿，人工确认后再发布。 野外助教：只读正式知识库，支持概念检索、邻接关系、位置、气象和行程查询。 可交互图谱：搜索、筛选、拖动和定位节点，按需读取笔记正文。 本地持久化：原始资料、提取结果、草稿、发布记录分开保存，重启后可恢复。 权限隔离：野外助教没有资料写入和知识发布工具。 运行环境

当前启动脚本面向 Windows 10/11，需要： Node.js 24，或 Node.js 22.19 及以上版本 pnpm Python 3.11

支持的主要格式： 类型 · 格式 类型: 文字 · 格式: TXT、Markdown、CSV、TSV 类型: 文档 · 格式: PDF、DOCX 类型: 图片 · 格式: JPG、PNG、WebP、HEIC、TIFF 类型: 录音 · 格式: MP3、WAV、M4A、OGG、FLAC、AAC 类型: GIS · 格式: GeoJSON、GPX、包含 Shapefile 或 GDB 的 ZIP 审核并发布

Install command

dsh plugin --profile web add github:xuedai-mayi/dsh-wenshan
