Project overview

一个 DSH 插件：把 agent 变成 Galgame 引擎兼编剧，游戏本体是一个文件——角色卡 + 世界书 + 剧本 + 规则 + 状态全部塞进这一串提示词里。引擎（游玩）与编辑器（改卡面）共用同一个文件， 游戏结束把状态写回文件，接着就改文件。 它提供什么 能力 · 说明 能力: 模式系统提示词 · 说明: 注入「开机协议 → 玩/不玩 → 引擎模式 → 结束写回 → 编辑模式」的完整流程约束 能力: galgameread · 说明: 加载卡面文件（默认 galgame.md）；不存在时返回内置 starter 供创建 能力: galgamewrite · 说明: 全量写回卡面文件：编辑改卡面与游玩写状态共用这一个入口；校验首行 # 标题 能力: galgameask · 说明: 向玩家提问/呈现选择（游戏内选项按钮、模式询问、存档确认）

三个工具自包含（宿主平面），依赖已有的 ctx.tools / ctx.systemPrompt / ctx.userQuestions （web 配置文件自带 UI 提问面板），无其它运行时依赖。 模式流程（插件注入的系统提示词）

或每次调用时用 file 参数临时指定（galgameread / galgamewrite 均支持）。 示例 examples/starter.galgame.md —— 内置 starter（雨夜旅店），第一张卡的起点； 卡面不存在时 galgameread 的返回里就带 starter 全文，确认后 galgamewrite 一次写入。 开发
