Project overview

让 AI agent 以视觉稿为起点，在浏览器里生成和编辑语义化 uGUI、模拟运行时状态与交互，并显式构建为 Unity Prefab 的 DSH agent preset。v0.24 的定位是视觉驱动的 uGUI 语义生成器：生产交付与预览/测试数据严格分离。 实机演示

过程：agent 产出 DSL → 浏览器模拟交互 → 显式构建 Unity Prefab（演示录制于早期版本；v0.24 的生产/Preview 双产物规则以本文为准）。

重启 DSH 并刷新现有 Web 页面后，可在 plugins/dsh-ugui-tools/ 运行 npm run test:runtime-psd，确认当前 127.0.0.1:3080 已启用语义分析协议 v3 和进度路由；随后新建「UGUI制作模式」会话，先让 agent 执行一次 uguisetup 创建工作台场景（UIDslWorkbench），即可开始使用。 使用

Install command

dsh plugin --profile web add github:BaronCyrus/dsh-ugui-preset
