Project overview

DeepSeek Harness UX A calmer Web experience for long-running work in DeepSeek Harness.

DeepSeek Harness is already an extensible coding-agent harness. This community edition concentrates on the part people watch and operate while the agent is working: session recovery, progress, multi-turn reading, actions, files, and workspace navigation.

It is not a different agent. It preserves the upstream plugin architecture, agent loop, tools, permissions, sandboxing, and main-model input. The changes are intentionally concentrated in the Web presentation layer. This is an unofficial, community-maintained project and not a DeepSeek distribution. DeepSeek Harness and related names belong to their respective owners. Why use it?

Install command

dsh plugin --profile web add github:ayuanwong/deepseek-harness-ux
