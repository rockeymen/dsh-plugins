Project overview

Use your own Claude and ChatGPT/Codex subscriptions as model providers in DeepSeek Harness — the same OAuth sign-in the Claude Code and Codex CLIs use. No API key. Install

Restart dsh, then sign in to whichever subscription you have:

Each opens the vendor's own sign-in page and stores the resulting OAuth credential locally. Tokens refresh on their own; you sign in once. Route · Provider · Credential Route: claude · Provider: claude-code-oauth · Credential: /.dsh/claude-code-oauth.json Route: codex · Provider: codex-oauth · Credential: /.dsh/codex-oauth.json

Install command

dsh plugin --profile web add github:DevViking-Persike/dsh-subscriptions
