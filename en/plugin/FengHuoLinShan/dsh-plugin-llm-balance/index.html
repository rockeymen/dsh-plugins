Project overview

多 provider 模式开箱即用：provider 清单自动来自内置表 + llm-pi-ai settings，key 从 DSH credentials 解析（llm-pi-ai 路由的 apiKeyEnv，或内置默认 DEEPSEEKAPIKEY / MOONSHOTAPIKEY / KIMICODINGAPIKEY / OPENCODEGOAPIKEY）；openai-codex 不需要 apiKeyEnv / baseURL（ChatGPT OAuth 由 Codex Connect 管理）。 旧的单 provider 写法（provider + apiKeyEnv）完全兼容：顶层响应字段仍按 config.provider 条目返回。

所有字段均为宽松校验：refreshMs / timeoutMs 非数字或非正数、provider / apiKeyEnv 非字符串或空串、baseURL 非字符串，一律回退默认值，不会导致插件启动失败（零依赖实现 normalizeConfig，语义等价于官方 Config schema 的非法值回退）。 自测 卸载

Install command

dsh plugin --profile web add github:FengHuoLinShan/dsh-plugin-llm-balance
