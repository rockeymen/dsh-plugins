Project overview

dsh-computer-use DeepSeek Harness 的 Computer Use 插件 —— 给 harness-desktop 增加"虚拟鼠标真人操作"能力： AI 生成独立光标，像人一样看屏幕、移动、点击、输入，替用户操作电脑。

脚本做的事（也可手动）： 1. ln -sfn "$DSHHOME/profiles/web/nodemodules/dsh-computer-use" 2. 在 $DSHHOME/cordis.patch.yml（dsh 的机器级用户 patch 层）insert 插件注册

可选配置（$DSHHOME/cordis.patch.yml 中覆盖）： 👁 视觉兜底（可选）

Install command

dsh plugin --profile web add github:988hj7tczd-oss/dsh-computer-use
