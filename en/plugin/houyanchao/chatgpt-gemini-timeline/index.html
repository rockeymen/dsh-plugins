Project overview

Timeline 专为 ChatGPT、Gemini、DeepSeek 等 AI 平台开发的超级提效插件 时间轴导航 · 收藏文件夹 · 提示词库 · 对话导出 · 公式复制 · 宠物动画 · 数据备份 DeepSeek Harness

Timeline 是专为 ChatGPT、Gemini、DeepSeek 等 AI 对话页面打造的浏览器提效插件。它不改平台原有界面，只在页面里补上长对话真正缺的能力：时间轴导航、收藏整理、提示词库、对话导出、公式复制和数据备份。

公式复制、代码运行和 Mermaid 图表能力不依赖特定 AI 平台。只要页面中存在可识别内容，扩展会尽量提供对应操作。 数据与隐私

Install command

dsh plugin --profile web add github:houyanchao/chatgpt-gemini-timeline
