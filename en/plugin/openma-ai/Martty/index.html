Project overview

Martty 在终端中呈现完整的 agent 工作过程，包括流式回复、推理、工具调用、 subagent、Plan、token 用量和持久化会话。图片可以从文件或剪贴板加入 prompt； 工具输出、Markdown、代码块和图片预览都使用终端原生交互。

回合运行时可以继续排队消息，也可以立即 steer 当前 agent。会话通过 /new、 /resume 和 --session-id 管理，workspace、模型、权限和界面选择会随会话恢复。

常用操作： 按键 / 命令 · 行为 按键 / 命令: enter · 行为: 发送消息；回合运行时排队 follow-up 按键 / 命令: ctrl+x · 行为: 立即 steer 当前 agent 按键 / 命令: esc · 行为: 中断当前回合并保留草稿 按键 / 命令: / · 行为: 打开命令与参数候选 按键 / 命令: /model · /agent · 行为: 选择模型和 Agent Preset 按键 / 命令: /permission · shift+tab · 行为: 选择或轮换权限模式 按键 / 命令: /image · /clip · 行为: 添加本地图片或剪贴板图片 按键 / 命令: !cmd · 行为: 在 workspace 的会话级本地 shell 中执行命令 按键 / 命令: /help · /keys · 行为: 查看命令与快捷键 插件系统
