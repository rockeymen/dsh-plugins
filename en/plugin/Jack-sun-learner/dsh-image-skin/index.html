Project overview

语法检查：node --check lib/client.js lib/host.js；宠物脚本注意 PowerShell 5.1 需要 UTF-8 with BOM 才能正确解析中文注释。 已知说明 宠物窗口位置使用 Win32 SetWindowPos 物理坐标定位（WPF 的 Left/Top 在幽灵显示器/虚拟桌面场景会落到屏幕外）。 背景图方案：token 覆盖把应用面板底色变半透明 + body 背景挂图（叠加深色渐变遮罩保证文字对比度）。若某面板不支持半透明会显得不跟随，属预期。
