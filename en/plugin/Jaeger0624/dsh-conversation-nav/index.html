Project overview

Codex 桌面版风格的 DeepSeek Harness Web GUI 对话轮次导航插件。

纯客户端插件（host 半面 no-op），零依赖手写单文件 bundle，无构建步骤： 数据源：官方 ctx.sessions 会话快照（ConversationSnapshot，含每条用户消息的 data.time epoch 毫秒） 挂载：shell.overlay 官方槽位（点击穿透层，刻度与悬浮卡自行恢复 pointer-events） 锚点：官方 data-chat-anchor-key 行属性定位跳转 性能：事件驱动（scroll 捕获 / resize / ResizeObserver / 快照订阅），无常驻定时器、无全文档 MutationObserver 标记存储：localStorage["dcn:marks: "]，数据结构预留 color/note 扩展字段

Install command

dsh plugin --profile web add github:Jaeger0624/dsh-conversation-nav
