Project overview

A DeepSeek Harness (DSH) plugin: install it into a profile alongside your own plugins. Push from host to browser. The host can start a conversation; every other channel (fetch, RPC) requires the browser to ask first. If your plugin's UI should react the moment something happens host-side (a setting changed, a build finished, a notification arrived), this is that channel.

Requires a DeepSeek Harness checkout and a profile (here web):

Then (re)start the harness; the host half loads at boot. Browser plugins consume the client service with ctx.get('eventRelay'), nothing to wire up beyond installing this package. Producers (host plugins) Consumers (browser bundles)

Install command

dsh plugin --profile web add github:joao-paulo-santos/dsh-event-relay
