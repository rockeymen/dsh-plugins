Project overview

dock-git DSH 生态中最好的 Git 历史可视化插件 —— 没有之一。 泳道式提交图、分支/标签徽标、三栏 diff、暂存提交推送、远端管理，把 VSCode 的 Git 面板直接搬进 DSH 工作台。在 DSH 里看仓库、管分支、推代码，dock-git 就是终极武器。

Install command

dsh plugin --profile web add github:AKS1st/dock-git
