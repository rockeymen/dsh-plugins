Project overview

从 Releases 下载最新的 DSH-Desktop-Setup-x.x.x.exe 并运行。

本地 HTTP API 没有鉴权，这是上游的设计——Origin 栅栏防的是 DNS rebinding，不是本地进程。任何以你的用户身份运行的进程都能访问它，但这类进程同样能直接读取 dsh 落盘的凭据，所以实际的额外风险只在"本机已被攻陷"这一前提下成立。栅栏的准确范围见上游 connection 文档。 开发

dev 模式默认从 ../deepseek-harness 解析上游仓（可用 DESKTOPDSHREPO 覆盖）；DESKTOPDSHMODE=npm 切换到捆绑的 npm 包。冒烟在前置条件缺失时自动跳过。 已知补丁

Install command

dsh plugin --profile web add github:qinyre/dsh-Desktop
