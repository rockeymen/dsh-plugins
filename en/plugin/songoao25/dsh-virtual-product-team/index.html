Project overview

Prerequisites: DeepSeek Harness installed (dsh available in PATH).

Then start a new conversation, pick Product Team Mode in the mode picker, and simply say: "I have an idea…". Note: DSH only allows switching modes in a blank conversation, so start a new one first. Uninstall

Install command

dsh plugin --profile web add github:songoao25/dsh-virtual-product-team
