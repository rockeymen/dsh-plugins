Project overview

你让模型写了一段中文。读起来很顺，但总觉得哪里不对。dsh-humanizer 是 DeepSeek Harness 的一个插件，管的就是这个"哪里不对"。

1. 禁止略读。每个工件逐格填，每格引用原文。不许用"已检查""无异常"填空。 2. 禁止概括。不写"整体偏 AI 味"这种总评，要落到某一章、某一层、某一句话。 3. 禁止打卡式。改写要逐条引用工件的某一行，复核要真的调 humanizevalidateartifact。 4. 禁止"是/否"式判断。写不出原因，等于没判断。 5. 禁止英文思考。思考、字段、标签、理由一律中文，原文术语除外。 6. 禁止跳章。诊断有固定顺序，缺一章不准进改写。 7. 禁止整体化判断。十五层一层层过，十维一维维过，不许合成一个判断。 8. 禁止配额化。这是最重要的一条：把任何手法做成每章配额，配额就是新指纹。 9. 禁止一次做完。一次一步，做完报"第 N 步完成，下一步第 N+1 步"。 十步

装完重启 web。bundle 层栈在 boot 时合成，Node half 改动需要重启才生效。 使用

Install command

dsh plugin --profile web add github:DEEP-IOS/dsh-humanizer
