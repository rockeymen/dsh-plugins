Project overview

1. LLM 自动判断、自动修复——已知问题确定性自动修复（无逐项确认）；0 问题自动只读验收 （输出"✅ 验收通过"+证据清单）；残留问题 LLM 自动诊断根因并修复。 2. 交互 = 看清完整 CoT + 随时打断——完整推理链 markdown 实时渲染；Ctrl-C 打断运行中的 agent，输入指引后回车，agent 按指引继续（上下文跨轮携带）。 3. 只有 LLM 真正卡住/需要决策时才问用户（缺 API key、不确定的破坏性操作）——否则绝不把 决策扔给你。全绿跑完自动出结论，5 秒后自动退出。 界面（python3+curses，零第三方依赖；无终端时自动回退逐步模式）： 使用流程：

stage 的行为： 先检测：已有 web 实例在跑（如生产 3080）→ 打印警告"第二个实例共享 /.dsh，只读查看"； 要求你 --yes 明确确认才启动；不带 --yes 直接拒绝并退出； 目标端口被占 → 直接报错让你换 --port； --keep 后台跑并打印日志路径与停止命令（kill $(lsof -tiTCP: -sTCP:LISTEN)）。

回滚后旧版本（含本地 fix）完整保留在回滚槽；新快照的问题可以慢慢查，不影响生产。 手动兜底（ab.sh 不可用时）： 场景 G · prepare 失败 → 排查
