Project overview

DSH 大肥鱼 🐋 住在 Windows 桌面上、由 DeepSeek Harness 真实工作状态驱动的 Agent 伴侣。

照常启动 DSH WebUI。插件默认启用，大肥鱼会由 DSH 自动拉起；不要手动打开 Helper。 5. 找到设置入口

1. 启动 DSH。 2. 在 DSH 中开始一个项目任务。 3. 大肥鱼根据 DSH 的真实事件切换动作和状态卡。 4. 切换到其他窗口继续工作；大肥鱼仍然保持在桌面最上层。 5. DSH Host 真正退出后，大肥鱼自动退出。

Install command

dsh plugin --profile web add github:QCYTSN/dsh-dafeiyu
