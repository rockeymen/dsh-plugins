Project overview

DSH Web GUI 插件：在新会话（hero）屏幕的输入框下方显示一个 GitHub 风格的 token 用量热力图 —— 当前自然年（1月–12月）每天的 token 用量，颜色深浅表示用量多少；同一行展示今日 / 本月 / 累计 token 用量。

A DeepSeek Harness web plugin: a GitHub-style daily token-usage heatmap of the current calendar year (Jan–Dec) rendered below the composer input card on the new-session screen only, with today / this-month / all-time totals on the same line. 界面 / What you get

需要 web profile（@deepseek-ai/dsh >= 0.1.0-rc.6）与 pnpm。

Install command

dsh plugin --profile web add github:KIDLi1412/dsh-token-heatmap
