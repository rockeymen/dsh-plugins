Project overview

The model comes to your cursor, both ways. Cues react to what you've already written and surface a fix or a sharper line inline, unprompted. Blanks act on demand: end a line with and the model fills in the rest. No chat window, no copy-paste, no context switch.

GitHub-hosted asset (renders inline): YouTube (GitHub won't inline-embed it — link a thumbnail instead): ->

Rows with are blanks: you ask, the model fills in. Rows without are cues: the model speaks up on what you wrote, no prompt. Quickstart

Install command

dsh plugin --profile web add github:opencues/opencues
