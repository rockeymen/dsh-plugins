Project overview

DeepSeek Pet 是一个嵌入 DeepSeek Harness 网页的交互式桌宠插件。它会跟随当前任务、 工具调用、上下文占用和活跃会话自动切换 DeepSeek 表情，并通过呼吸、弹跳、倾斜、 视差和淡入动画呈现 Live2D 风格效果。

环境要求：Node.js 22.19 或更高版本，以及 Python 3 和 Pillow。 npm run assets：从源图生成透明 WebP 表情并嵌入客户端代码； npm run build：生成 lib/index.js 和 lib/client.js； npm test：运行状态映射、交互和插件装载测试。

Install command

dsh plugin --profile web add github:keleus/deepseek-pet
