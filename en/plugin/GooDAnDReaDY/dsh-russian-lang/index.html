Russian localization for the DeepSeek Harness web UI: ru dictionaries for core namespaces and a third option in the native language list (Settings - General - Language).

Project overview

Непереведённые ключи показываются по-английски (штатный fallback ядра), пустых мест в интерфейсе не появляется. Как это работает

Реестр локалей живёт в браузере: плагин докладывает русские словари в чужие namespace'ы через ctx.locale.register(ns, 'ru', dict) — конфликт возможен только если пара (namespace, язык) уже занята, а ru не занимает никто.

Требует websocket-client (pip install websocket-client) и Chrome на /usr/bin/google-chrome для smoke.py. По умолчанию ходит на https://192.168.1.111:3082; переопределяется через DSHURL.
