Project overview

Restart the Web UI afterwards. Configure Web GUI (recommended)

The plugin config only ever references keys by name (e.g. MYPROVIDERAPIKEY). The values live in the dsh Credentials service or $DSHHOME/.credentials.yaml — never in the plugin config.

Two local-only routes back the card: GET /dsh-key-rotation/status (key state, rotation counters, last 5 characters of each key) and PUT|DELETE /dsh-key-rotation/key (store or drop one key value). Both refuse anything that is not a same-origin request from loopback. Structure Security notes Key values never leave your Credentials store; the plugin config only holds env/credential names. switchCodes are error classification strings, not expressions — no secrets involved.

Install command

dsh plugin --profile web add github:GooDAnDReaDY/dsh-key-rotation
