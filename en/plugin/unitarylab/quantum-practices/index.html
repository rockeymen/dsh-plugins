Project overview

&middot; English What is this? Quantum-Practices is a DeepSeek Harness tool bundle for quantum algorithm best practices. It provides structured, reviewable guidance to DeepSeek Harness agents through a read-only model-facing tool.

As a DeepSeek Harness plugin, it registers one read-only quantumpractices tool for listing, searching, and reading packaged quantum algorithm practice guides from an immutable build-time catalog.

For most users, install Quantum-Practices into the DeepSeek Harness profile you use, then ask your agent to consult Quantum-Practices before answering quantum algorithm questions.

Install command

dsh plugin --profile web add github:unitarylab/quantum-practices
