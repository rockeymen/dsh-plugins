Project overview

一个以设计流程为核心的 PowerPoint skill。PPTX 的实际生成由已发布的 pptx-designer Python 标准库 负责；skill 负责需求确认、结构设计、视觉方案、生成编排和最终视觉验收。

FreeStyle 的 generateppt(query=...) 和 generateppt(content=...) 是同一个模式的两种输入方式，不是两条独立 的生成引擎。无论选择哪种模式，正式交付都必须经过 PNG 视觉检查。

推荐决策： 不确定时使用 Build Mode；只有在明确追求速度或 必须服从现有模板时，才选择 FreeStyle 或 VI Build Mode。 Skill 的核心价值

Install command

dsh plugin --profile web add github:sunchaokun/PPT-Design-Skill
