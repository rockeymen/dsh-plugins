Project overview

给 HR / 猎头用的一套 AI 招聘工作流：逼问式梳理岗位真实要求 → Boss直聘 + 猎聘双通道每日寻源初筛 → 打招呼 → 约面试 → 候选人台账 → 日报。 另有市场人才盘点、简历评估，以及从飞书邮箱按需收取猎聘 / BOSS 的简历附件。

然后： /recruit-init —— 初始化工作区（首次一次） /recruit-grill —— 梳理某个岗位的要求 /recruit-daily —— 处理今天的招聘（日常也可以直接说「处理今天的招聘」） /recruit-mapping —— 深度盘点某岗的市场人才 /resume-review —— 评估本地简历，或收取飞书邮箱的猎聘 / BOSS 简历附件后评估 /interview-schedule —— 约面试：日历 + 视频会议 + 拉面试官，档案台账同步 /ask-viy —— 不知道该用哪个？问它 方式三：DeepSeek Harness 插件（任意工作区都能用这套招聘 skill）

（web 是 Web 界面 profile；headless 等其他 profile 同理，把 web 换成名字即可。）

Install command

dsh plugin --profile web add github:Viy1204/recruiting-copilot
