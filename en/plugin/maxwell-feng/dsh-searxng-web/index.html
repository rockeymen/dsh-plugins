Project overview

(Replace web with your profile, e.g. tui.) Published from CI with Sigstore provenance; the package ships a prebuilt lib/, so nothing needs to be compiled or allowlisted on install. From GitHub

The repository commits the compiled lib/ output, so git installs also load without any build step or pnpm allowBuilds allowlist. Upgrading

0.2.x configurations keep working unchanged — every field added since is optional with identical defaults. Since 0.3.0 configuration is validated at load time (Schemastery schema), a mistyped key fails the boot with an actionable error instead of being silently ignored. 0.4.0 adds the optional baseUrls failover list; single-baseUrl setups are unaffected.

Install command

dsh plugin --profile web add github:maxwell-feng/dsh-searxng-web
