Project overview

三泳道（输入 / 模型 / 工具）时间线，展示每个回合的：轮次、步骤、耗时、工具调用、token 统计（含缓存命中）。 文件管理

DSH 的 profile 是一个「插件 bundle 栈」。本项目的 web profile 由下面 5 个 bundle 组成： bundle · 作用 bundle: @deepseek-ai/dsh-base · 作用: DSH 核心 bundle: @deepseek-ai/dsh-web-app · 作用: 网页 UI（也承载 /api RPC 与 WebSocket） bundle: @liustack/modlens · 作用: 图像识别/OCR（手机端看图要用） bundle: dsh-better-sidebar · 作用: 侧边栏增强 bundle: dsh-remote-control · 作用: 本仓库的插件：给手机提供 /remote/ 文件接口 方式 A：官方命令（推荐）

把本仓库 web-profile/package.json 复制到 /.dsh/profiles/web/，把 dsh-remote-control 的 file: 路径改成你本机的绝对路径，然后：

Install command

dsh plugin --profile web add github:SCSpotato/dsh-remote
