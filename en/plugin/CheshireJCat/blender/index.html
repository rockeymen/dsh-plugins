Project overview

No Blender add-on or control port is required: each operation launches a local Blender background process. Requirements DeepSeek Harness 0.1.0-rc.6 Node.js 20+ Blender 4.3+ available as blender on PATH, or configured with an absolute path Python 3.10+ for the optional reference-analysis helpers Install from npm

The setup command creates a private .venv inside the installed package and installs OpenCV, NumPy, Pillow, and SciPy. Skip it only if you do not need reference, wireframe, multiview, texture, or animation-analysis helpers.

To install a pinned GitHub release instead: Develop from source

Install command

dsh plugin --profile web add github:CheshireJCat/blender
