Project overview

DeepSeek Harness Web GUI （dsh web）的 Catppuccin 主题插件。

它内置 Catppuccin 的四个主题——Latte、Frappé、Macchiato、Mocha—— 把整个界面的配色都换成对应的 Catppuccin 色板；并在 设置 → 常规 → 外观 下方提供一行 Catppuccin 快捷切换，选择会自动保存、下次启动自动恢复。 特性 🎨 四个主题：Latte（浅色）、Frappé / Macchiato / Mocha（深色） 🧩 接入官方主题系统，与内置浅色 / 深色 / 跟随系统主题平级 🎯 全界面配色覆盖（162 个配色变量），不只是一两个强调色 ⚙️ 设置页一行切换，选择自动保存、重启自动恢复 🌐 中英文双语文案（跟随系统语言） 预览
