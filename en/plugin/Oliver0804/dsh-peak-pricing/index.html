Project overview

A DeepSeek Harness Web plugin that puts one line under the composer: which DeepSeek pricing period is in force right now, how long it lasts, and what this session has cost so far. Green dot — off-peak. A cheap moment to start a long run. Orange dot — peak. Everything costs exactly twice as much. The countdown is how long the current rate lasts, to the second. The amount is what this session has spent, each increment priced at the rate in force when it arrived.

Restart dsh web, and the row is there. To confirm the plugin layer mounted:

Prices are CNY per million tokens. The table lives in src/pricing.ts as a plain constant — when DeepSeek announces new numbers, that is the only thing to edit.

Install command

dsh plugin --profile web add github:Oliver0804/dsh-peak-pricing
