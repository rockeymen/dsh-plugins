Project overview

仓库已内置 GitHub Actions 工作流（.github/workflows/sync-plugins.yml），每 6 小时自动： 1. 从 GitHub topic dsh-plugin 拉取最新插件快照 2. 用 scripts/build-seo.py 重新生成全部页面（含 sitemap、feed、73 个插件详情页） 3. 自动提交变更

纯静态，无框架、无构建步骤、无后端： 技术 · 用途 技术: HTML · 用途: 页面结构 技术: CSS · 用途: 设计系统（CSS 变量 + 媒体查询） 技术: 原生 JS · 用途: 全部前端逻辑（无框架） 技术: Python 3 · 用途: 构建脚本（数据同步 + 页面生成） 技术: GitHub Actions · 用途: 自动同步数据 本地预览 重新生成页面

dsh plugin --profile web add github:dsh-plugin/dsh-plugin.github.io
