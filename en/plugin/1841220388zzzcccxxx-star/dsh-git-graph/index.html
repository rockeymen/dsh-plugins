Project overview

🌏 中文 · English 🧭 一句话定位：DSH 生态里开箱即用的 Git 可视化工具。 在 DeepSeek Harness 对话界面内直接嵌入 GitHub 风格的提交历史图、分支管理、代码 Diff 与 VSCode 风格未提交改动面板——AI 开发时不用再切到别的 Git 客户端。

DeepSeek Harness（DSH）Web GUI 的嵌入式 Git 仓库图谱可视化插件。

打开 http://127.0.0.1:3080 ，在任意会话页内点「Git 图谱」标签（位于「轨迹」标签旁）即可查看。 🖱️ 使用 操作 · 说明 操作: 会话页「Git 图谱」标签 · 说明: 在该对话内查看图谱（跟随当前对话工作区） 操作: 分支组标题 · 说明: 点击折叠 / 展开该分支 操作: ☑ 分支过滤 · 说明: 勾选 = 显示该分支，不勾 = 完全隐藏 操作: 图谱顶部「未提交改动」区块 · 说明: 已暂存/更改/未跟踪一览（含未跟踪文件），点击行展开 diff；☑ 分组可隐藏某组；点击顶栏或组标题折叠 操作: 提交行 · 说明: 点击查看详情，Ctrl+点击与另一提交对比 操作: 提交行右键 · 说明: git 操作菜单 操作: 底部状态栏「未提交改动」 · 说明: 点击滚动到顶部改动区块 操作: ↻ 刷新 · 说明: 重新加载仓库数据 🛠️ 开发
