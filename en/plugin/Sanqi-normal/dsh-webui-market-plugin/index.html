Project overview

An in-harness community plugin market for the dsh web GUI: browse the awesome-dsh-plugin.com catalog and install/uninstall plugins into a profile from Settings → Plugins → Plugin Market. 推荐 Recommended

本插件为社区独立实现，推荐优先使用网站官方实现 dsh-market（由 awesome-dsh-plugin.com 维护者开发，功能一致、维护更活跃）。

Install command

dsh plugin --profile web add github:Sanqi-normal/dsh-webui-market-plugin
