Project overview

dsh web 对话界面插件：将文本回复之前的连续运行时信息（工具调用、思考、重试等）收纳进可展开的折叠框，文本回复以聊天气泡呈现，设置面板可配置。独立仓库分发，宿主源码零改动（以 bundle 补丁层替换宿主 ui-conversation 行）。

统一使用宿主官方插件管理命令 dsh plugin --profile （pnpm 转发 + 自动把声明 dsh.bundle 的依赖加入 dsh.profile.bundles 层列表）。本项目不提供、也不需要任何包装脚本。

浏览器端 localStorage dsh.chat-focus.fold.（服务端任何工具都触达不到）：在 dsh 页面 F12 Console 执行 Object.keys(localStorage).filter(k=>k.startsWith('dsh.chat-focus.')).forEach(k=>localStorage.removeItem(k))，或直接清除 dsh 站点数据。会话记录零污染（插件仅 UI 渲染，不写 session log）。 与 dsh-web-ui-all（皮肤）共存

Install command

dsh plugin --profile web add github:supergameboy/dsh-chat-focus
